## 1. 브랜드 정체성

- **브랜드명**: Korean With Ji (koreanwithji.com)
- **슬로건**: ~~Learn Korean like a baby~~ → **"Learn Korean like a grown-up"**
  - baby를 의도적으로 지우고 grown-up으로 대체하는 비주얼 자체가 브랜드 핵심 메시지다.
- **카테고리**: 성인 학습자를 위한 **Active learning** 기반 프리미엄 한국어 학습 플랫폼 (셀프 스터디 + AI 튜터)
- **티칭 페르소나**: Ji는 teacher이지만 **coach / guide** 색깔이 짙다. "한국어만 가르치는 사람"이 아니라 "한국어를 효과적으로 배우는 법을 설계하고 그 방식으로 한국어를 가르치는 사람"이다.

## 2. 핵심 교육 철학 (시장 통념과의 정면 대비)

| 시장 통념 (immersion 강의 대다수) | Korean With Ji 포지션 |
|---|---|
| "Learn like a baby". 무분별한 immersion, 노출, 반복으로 자연 습득되기를 기다림 | "You're not a baby. Erase that phrase." 성인 두뇌는 **논리와 구조**에 wired돼 있다 |
| 단어와 구문 암기 + drama, K-pop 노출 | **Language Core** 먼저. 언어의 framework부터 세운다 |
| Passive immersion 강조 | **Active learning** 강조 |
| Grammar는 무서운 것, 최소화 대상 | Grammar = **언어의 OS**. 암기하지 말고 이해하고 활용해서 internalize |
| 영어에서 한국어로 직역하며 출발 | **Translation Trap** 정면 비판. 한국어로 *생각하기* 위한 시스템 |
| 학문적 jargon, 문법 용어 그대로 사용 | Ji의 자체 용어와 비유로 디코딩 |

## 3. 학생에게 주는 약속 (Promise)

1. **Translation Trap 탈출**: 머릿속에서 영어로 문장을 짓고 한국어로 옮기는 습관을 차단한다.
2. **Language Core 구축**: 단어를 외우기 전에 "한국어가 어떻게 작동하는가"의 framework를 먼저 세운다. 문장을 다루다 보면 단어는 따라온다.
3. **한국인의 언어적 사고방식 습득을 위한 기반 마련**: 한국어로 *생각하는* 단계 진입이 fluency로 가는 첫걸음이다.
4. **Input → Process → Output 모델**로 학습을 자동화한다.

## 4. 타깃 페르소나 (1차 ICP)

- 영어권 성인 학습자 (글로벌, USD 결제)
- K-pop, K-drama로 한국어에 끌려 입문
- 단어와 phrase는 어느 정도 알지만 **한 문장도 못 만들고 한 문장도 못 알아듣는** 상태
- 한 번 이상 좌절했지만 **그만두지 않은 15%** (UBC + BYU 연구: 85%는 Korean 101 이후 dropout)
- "더 빨리, 더 똑똑하게" 배우고 싶은 욕구. baby처럼 5~6년 기다릴 의향이 없다.

### 타깃의 조건 (운영 원칙으로 직결)
- 한국인이 아니다. 해외 학습자, 영어권 중심.
- 결제도 해외 기반(USD). 한국 플랫폼과 한국 결제 시스템은 쓸 이유가 없다.
- 따라서 도구는 **글로벌 SaaS 표준**으로 고른다.

## 5. Origin Story (신뢰 근거 자산)

- 17세에 기본적인 영어 실력만 가진 상태로 캐나다에 단신 이주 (foster family 경험 포함)
- 6개월 만에 청취와 대화가 가능해짐. 공부하는 과정에서 본인만의 학습 시스템을 스스로 만들게 됨
- 같은 시스템을 스페인어에 재적용해 검증 (지금은 많이 잊었지만 스페인어권 여행에 불편함이 없는 수준)
- 그 시스템을 reverse-engineer해서 **모국어인 한국어**를 외국인이 배우게끔 재설계
- 미션: K-pop, K-drama 시대인데도 한국 사회가 여전히 외국인에게 닫혀 있는 문제를 **언어 장벽 해체**로 푼다

### 이 스토리가 설득력을 갖는 논리
1. 한국어는 영어 원어민에게 가장 어려운 언어군에 속한다 (미국 국무부 FSI 기준 Category V, super-hard).
2. 반대로 한국인에게도 영어는 똑같이 어렵다.
3. 영어권에서 태어났거나 어릴 때 이민 간 교포는 영어를 자연스럽게 익힌다. Ji는 그들과 다르다. **한국에서 나고 자란 토종 한국인**이다.
4. Ji는 거의 성인(grown-up)이 된 17세부터 영어를 제대로 시작해 끝까지 직접 뚫었다. 즉 **학생과 같은 길을 먼저 걸어본 가이드**다.

## 6. 차별화 요소 (경쟁사 대비)

1. **철학적 차별화**: "Learn like a grown-up". 시장의 baby 메타포를 정면 반박하는 희소 포지션. 유아적이고 유치한 기존 한국어 resource를 정면으로 밀어낸다.
 - "문법"을 villanize 시키는 시장 통념 정면 반박.
  > 문법 공부없이 "자연스럽게" 한국어를 익혀야 빠르게 유창해진다 (X) → 문법을 "외우려고만" 하고 "틀릴까봐 안절부절"하는 게 아니라 문법을 "활용"해서 언어의 체계를 "이해"하고 internalize 시킨다. (O)
2. **방법론적 차별화**: Language Core + Input/Process/Output 프레임워크 (Ji 고유 용어), Comprehensible Input 적용
3. **언어적 차별화**: jargon 없는 직관적 비유. 어려운 문법 용어를 Ji식 표현으로 재명명
4. **기술적 차별화**: AI 튜터 24/7 답변 (Skool AI Bot, RAG 기반). 경쟁사 어디에도 없다
5. **인격적 차별화**: 원어민 + 다개국어 학습자 + 코치 정체성의 결합

## 8. Brand Tone (학생에게 말할 때의 대본 톤)

> 이 절이 **강의 대본 톤의 단일 출처**다. Draft를 쓰는 에이전트는 여기 적힌 규칙대로 쓴다.
> 근거 자료 2종:
> (1) Ji 본인의 Draft. `Level_1/1_How_Korean_works`, `Level_2/1_은는_이가`, `Level_2/2_TSV_Sentence_Structure_1_-_The_Rule_of_Three`의 `01_Ji_draft`
> (2) Ji가 닮고자 하는 instructor. Olleh rebelz의 `Korea's Two Number Systems Explained`, `Why Does Korean Have Spaces`

### 8-1. 지향점 한 줄

**Concise, easy to understand, logical, 군더더기 없음.** 같은 내용을 가르치더라도 문장에 쓰이는 단어 수는 최대한 적게, 내용은 알차게. 그러면서도 쉬운 단어로 이해하기 쉽게.

짧게 쓰는 것이 목적이 아니다. **밀도를 높이는 것**이 목적이다. 단어를 줄이되 내용을 줄이지 않는다.

### 8-2. Ji 대본에서 뽑아낸 톤 규칙 7가지

1. **숲 먼저, 나무 나중.** 레슨을 열 때 큰 그림과 그 레슨의 논리를 먼저 준다. 세부는 그 다음이다. ("나무를 보지 말고 숲을 보라")
2. **규칙이 아니라 이유를 준다.** STLOHV를 순서로 외우게 하지 않고 "다음 것이 존재하려면 무엇이 먼저 있어야 하는가"라는 논리로 설명한다. 학생이 규칙을 잊어도 논리는 남는다.
3. **Ji 고유 용어와 시각 비유를 만들고, 그것이 공식 용어가 아님을 밝힌다.** STLOHV, TSV, Rule of Three, 어간에 붙는 branch/leaf/fruit 식물 비유가 그 예다. "이건 내가 만든 말이라 구글에 검색해도 안 나온다"고 정직하게 말한다. 이게 신뢰를 만든다.
4. **영어와 반드시 대조한다.** she studies의 s, "I'm NOT in love with her VS I'm not in LOVE with her"의 강세 이동, 스페인어 me gusta 같은 대조로 학생이 이미 아는 것에 새 개념을 붙인다.
5. **정직하게 한정한다.** "only half-true", "tends to be", "이건 공식 문법 규칙은 아니지만 원어민으로서 99% 그렇다고 느낀다". 과잉 일반화를 하지 않는 것이 오히려 권위를 만든다.
6. **불안을 먼저 차단한다.** "don't worry", "지금은 참고용이다", "나중에 자세히 다룬다", "헷갈리면 이 레슨으로 돌아와라". 성인 학습자의 이탈은 대부분 불안에서 나온다.
7. **성인으로 대우하고, 어려운 것을 앞당겨 주고, 해낸 것을 짚어준다.** "방금 중급에서 배우는 compound verb를 배웠다. 자랑스러워해도 된다."

### 8-3. Olleh rebelz에서 가져올 것 5가지

1. **훅으로 연다.** 규칙 나열이 아니라 의외의 사실이나 질문으로 시작한다. ("이 변화를 처음 도입한 사람이 한국인도, 아시아인도 아닌 스코틀랜드 사람이었다면?")
2. **짧은 문장, 구어체, 리듬.** 한 문장에 한 생각. 문어체 장문을 쓰지 않는다.
3. **최소 대조쌍으로 의미 차이를 즉시 보여준다.** 설명 대신 예시 두 개를 나란히 놓는다. (나물 좀 다오 / 나 물 좀 다오)
4. **스스로 과잉 정보를 잘라낸다.** "이 이상은 완전한 overkill이다"라고 말하고 끊는다. 아는 것을 다 쏟지 않는 것이 실력이다.
5. **좌절을 인정하되 프레임을 바꾼다.** "이 혼란은 설계 결함이 아니라 기능이다."

문화 레퍼런스와 유머(K-pop 가사 속 말장난 등)를 쓰되, 설명을 대체하지 않고 설명 뒤에 붙인다.

### 8-4. 문장 단위 체크리스트

- 한 문장에 한 가지 생각만 담는다.
- 같은 것은 같은 단어로 부른다. 변화를 주려고 동의어를 바꿔 쓰지 않는다.
- 짧고 흔한 단어를 고른다. utilize가 아니라 use.
- 지우면 잃는 것이 없는 문장은 지운다.
- 이미 한 말을 다른 표현으로 반복하지 않는다.

### 8-5. 하지 말 것

- Learn like a baby 메타포를 긍정적으로 쓰지 않는다. 브랜드가 정면으로 부정하는 표현이다.
- 학문적 문법 용어를 정의나 디코딩 없이 던지지 않는다.
- "그냥 외워라"로 끝내지 않는다.
- 학습자를 어린애 취급하지 않는다. 성인의 논리적 이해력을 전제로 쓴다.
- 근거 없이 단정하지 않는다. 확실하지 않으면 확실하지 않다고 말한다.

## 9. 학습법 백본: Fluent Forever

브랜드의 교육 철학은 감이 아니라 **기억과학과 언어학 연구에 근거를 둔다.** 그 근거의 단일 출처가 아래 두 문서다.

- `02_product/01_raw/02_ext_sources/01_공부법/Fluent Forever_학습법 정리.md` (책 내용 정리)
- `02_product/01_raw/02_ext_sources/01_공부법/Fluent Forever_사업 적용.md` (이 사업에 어떻게 적용할지)

### 9-1. 왜 이 책인가
Ji가 직관적으로 잡은 포지션이 이 책의 핵심 주장과 거의 1:1로 맞물린다.

| Korean With Ji | Fluent Forever 대응 |
|---|---|
| Learn like a grown-up | 성인은 못 배우는 게 아니다. 입력량만 맞추면 패턴 인식과 학습 전략 우위로 오히려 더 빠르다 |
| Translation Trap 탈출 | Don't translate. "단어의 교향곡" (번역은 단어에서 음악을 떼어낸다) |
| Language Core 먼저 | 발음에서 단어, 문법, 문장으로 가는 토대 우선 설계 |
| Input → Process → Output | Comprehensible Input → SRS 카드화 → 글쓰기와 말하기 |
| Active learning | 복습하지 말고 회상하라. DIY 카드. Output |
| Grammar는 OS, internalize | 언어 기계에 이해 가능한 입력을 먹인다. 드릴로는 단계를 건너뛸 수 없다 |

즉 이 책은 Ji의 주장에 **과학적 정당성**을 붙여주는 이론적 탄약고다. coach/guide 페르소나에 authority를 더한다.

### 9-2. 브랜드 운영에 실제로 반영하는 것
- **레슨 설계**: 4MAT으로 개념을 가르친 뒤 "이걸 네 것으로 만드는 법"(이미지 기억, 니모닉, SRS 카드, Output 과제)을 붙인다.
- **발음을 진짜 먼저**: 최소대립쌍 듣기 훈련과 따라하기 입 훈련을 각 레슨 별 Exercise에 섹션에 넣는다. 발음 방법은 Hangul 섹션에 포함되어있다. "발음 먼저"가 시장 통념과의 또 하나의 대비점이다.
- **빈도 기반 정렬**: 테마별이 아니라 실제로 자주 쓰는 구조와 단어부터 배치한다.
- **카드를 주지 않고 만드는 법을 가르친다**: 책의 "남의 덱은 효과 없다, DIY가 핵심"과 완성된 강의를 파는 사업모델의 충돌을 이 프레이밍으로 푼다.

### 9-3. 그대로 베끼지 않는다
1. 책의 표현과 예시를 그대로 쓰지 않는다. 개념과 원리만 가져와 한국어 맥락과 Ji식 비유로 재창작한다. 직접 인용하면 출처를 밝힌다.
2. 책 예시는 유럽어 중심(성, 동사변화)이다. 한국어는 조사, 어순, 존댓말, 불규칙활용이 핵심이므로 전부 한국어에 맞게 변환한다.
3. 책에 없는 Ji만의 가치를 얹는다. 원어민의 직관과 문화 설명, AI 튜터 24/7, 그리고 체계화된 커리큘럼. 책은 "스스로 하라"가 전제지만 Ji는 그 길을 깔아준다.

## 10. Draft와 카피 작성 시 지켜야 할 것

- Comprehensible Input을 적극 활용한다. 예문, 예시 대화를 상황에 맞는 비주얼 영상과 pair시킨다.
- 한국어 예문은 이전 레슨까지 다룬 문법만 사용해 작성한다.
- 문법 용어를 그대로 던지지 않는다. Ji식 명칭과 비유로 먼저 디코딩한다.
- "외워라"로 끝내지 않는다. 항상 "왜 이렇게 작동하는가"를 먼저 준다.

## 적용 지식

### CLAUDE.md의 작동 원리와 컨텍스트 엔지니어링 [02:09]
`CLAUDE.md`는 Claude Code가 세션을 시작할 때 가장 먼저 확인하고 통째로 읽는 프로젝트의 기억 장치이자 지침서다. 로딩 순서상 시스템 프롬프트(system prompt) 다음에 위치하며, 사용자의 개별 프롬프트보다 먼저 읽히는 사전 지시서 역할을 한다. 하지만 공식 문서에 따르면 이는 맥락(Context)을 제공하는 것이지 강제(Enforcement)하는 것이 아니다. 모호하거나 충돌하는 지시가 있을 경우 Claude가 이를 무시할 수 있으므로, 구체적인 컨텍스트 엔지니어링(Context Engineering)을 통해 AI가 지켜야 할 규칙을 명확히 전달해야 한다.

### 나쁜 패턴 vs 좋은 패턴 [06:03]
`CLAUDE.md` 작성 시 피해야 할 나쁜 패턴과 권장되는 좋은 패턴은 다음과 같다.

1.  **길이 관리**: 300줄 이상의 너무 긴 파일은 중요한 규칙이 노이즈에 묻히게 만든다. 공식 문서에서는 200줄 이하를 권장하며, 실무적으로는 60줄 내외가 적당하다. 내용이 많아지면 과감하게 삭제(ruthlessly prune)하거나 모듈화해야 한다.
2.  **지시의 구체성**: "깔끔한 코드를 작성하세요"와 같은 모호한 지시는 효과가 없다. 대신 "함수는 30줄 이하로 작성하세요", "새 파일 만들기 전에 나한테 확인하세요"와 같이 Claude 스스로 지켰는지 검증 가능한 구체적인 행동을 지시해야 한다.
3.  **구조화**: 프로젝트 규모가 커짐에도 `CLAUDE.md` 하나에 모든 규칙을 넣으면 성능이 저하된다. 주제별로 파일을 분리하여 관리하는 것이 중요하다.

### Auto Memory 최신 스펙과 관리법 [04:01]
`CLAUDE.md`가 사용자가 직접 작성하는 '업무 매뉴얼'이라면, 오토 메모리(Auto Memory)는 Claude가 세션 중 학습한 패턴을 스스로 기록하는 '업무 일지'다.
- **로드 방식**: `MEMORY.md` 파일은 처음 200줄만 메모리에 로드된다. 초과분은 Claude가 별도 파일로 분리하며, 필요할 때만 참조한다.
- **관리 명령어**: `/memory` 명령어를 통해 현재 기억된 내용을 확인하고 편집할 수 있다. `Open auto-memory folder`를 선택하면 `~/.claude/projects/` 경로에 저장된 `.jsonl` 및 `.md` 파일들을 직접 수정하거나 오래된 내용을 삭제할 수 있다.

### 실전 활용 사례: 최고의 레버리지 전략 [09:04]
투자 대비 효과가 가장 큰 네 가지 패턴은 다음과 같다.

1.  **검증 방법 제공**: Claude가 작업 후 스스로 결과를 확인할 수 있도록 테스트 명령어(test command)나 성공 기준을 명시한다. 스스로 에러를 고치는 루프를 형성하게 되어 품질이 2~3배 향상된다.
2.  **도메인 용어 정의**: 비즈니스 로직에서 혼동될 수 있는 용어를 명확히 정의한다.
    ```markdown
    ## 도메인 용어
    - 주문(Order): 고객이 한 번에 결제하는 주문 묶음(배달비 총액 포함)
    - 주문항목(OrderItem): 주문 안의 개별 메뉴 (짜장면 1개 등)
    - 가게(Store): 실제 주문을 받는 개별 매장
    ```
3.  **@IMPORT 활용**: 프로젝트 내 기존 문서를 중복 작성하지 않고 참조한다.
    ```markdown
    # CLAUDE.md
    프로젝트 개요와 사용 가능한 명령어는 @README.md 참조
    npm 스크립트 목록은 @package.json 참조
    ```
4.  **팀 공유 학습 시스템**: `CLAUDE.md`를 `Git`으로 관리하며 팀원들이 발견한 Claude의 실수와 해결책을 한 줄씩 추가한다. `Pull Request`를 통해 규칙을 머지하면 팀 전체의 경험이 축적되어 같은 실수를 반복하지 않게 된다.

## 주의사항

- **컨텍스트 한계**: `CLAUDE.md`가 너무 길어지면 토큰(token) 소모가 늘어날 뿐만 아니라 Claude의 지시 준수율(adherence)이 떨어진다. 200줄을 넘기지 않도록 주의해야 한다. [06:10]
- **충돌 방지**: 여러 개의 규칙 파일 간에 서로 다른 지침이 있을 경우 Claude가 임의로 하나를 선택할 수 있다. `/memory` 명령어로 로드된 파일 목록을 확인하고 충돌 여부를 점검해야 한다. [03:29]
- **환경 변수**: `Windows` 환경에서는 경로 설정이나 환경 변수 문제로 인해 `CLAUDE.md`가 제대로 로드되지 않을 수 있으므로 주의가 필요하다. [12:02]

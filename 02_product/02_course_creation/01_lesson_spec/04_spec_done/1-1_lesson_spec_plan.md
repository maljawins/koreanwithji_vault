# 1-1 lesson_spec 작업 계획

## 목표

Ji의 `1-1_topic_shaped_feedback.md`를 **강의 내용에 대한 결정**으로 삼아, 출처 비교 자료를 OUTLINE 작성에 바로 쓸 수 있는 `1-1_lesson_spec.md`로 바꾼다. 1-1의 현재 공식 status는 `topic_raw`다. `topic_shaped` 파일과 Ji 피드백은 존재하지만, 진행표에는 아직 반영되지 않았다.

## 작업 방식

1. **입력과 결정 대조:** `range_set_review.xlsx`의 확정 사용 구간, `topic_raw`의 원문, `topic_shaped`의 주제별 비교에 Ji 피드백을 대조한다. 원문을 다시 복사하지 않고 각 결정에 Ref_No와 줄을 붙인다. 설명 선택은 Ji 피드백을 따르며, 피드백이 정하지 않은 내용은 임의로 확정하지 않는다.
2. **Ji Draft 흐름을 참고해 내용 확정:** 큰 그림과 초반의 `사랑해` 맥락 예시, 긴 치킨 문장과 SOV·STLOHV, 어순의 유연성과 강조, 조사와 부사, 어간·어미와 식물 비유, 문장 연결, 큰 그림 재확인을 설명할 소주제로 검토한다. 이는 Ji Draft에서 참고할 흐름이지 lesson_spec에서 확정한 영상 순서가 아니다. `TEACHING_POINTS`에는 소주제별 **가르칠 핵심 내용, 설명 깊이, 예문 후보, 출처, 제외할 내용**을 적는다. 소주제의 최종 순서와 무엇을 어떻게 설명할지는 OUTLINE에서 정하고, 실제 영상 대사는 DRAFT에서 쓴다.
3. **경계 명시:** STLOHV는 표준 지도이며 절대 순서가 아님을 밝힌다. `은/는`은 topic marker로 부르고 `이/가`는 도입하지 않는다. `을/를`은 목적어 표시 역할까지만 설명한다. 명사 앞 수식어, 상세 활용법, 1대1 수업의 Q&A, 고급 맥락 예문은 제외한다. 부사 위치의 “always” 같은 단정도 쓰지 않는다. 다음 레슨이 어휘 학습이라는 기존 문장은 삭제 대상으로 처리한다.
4. **명세서 작성:** `GOAL`은 “한국어 문장이 정보를 배치하고, 명사 뒤 표지와 동사 끝 형태로 의미를 더하는 큰 그림을 이해한다”로 잡는다. `SKELETON`은 한 줄의 전체 지도, `NEW`는 이번에 소개할 개념, `PREREQ`는 실제 앞 레슨에서 배운 내용, `BUDGET`은 **예문을 보여 주기 전까지 배워야 할 내용의 한계**, `OUT_OF_SCOPE`는 뒤 레슨에서 자세히 다룰 내용으로 채운다. 긴 예문과 맛보기 형태는 ‘구조 관찰용’인지 ‘학생이 직접 만들 표현’인지 구분한다. `SOURCES`에는 사용한 raw 경로를 적고, `RAW_DIGEST`에는 기존 [1-1_topic_raw.md](/C:/vault/koreanwithji_vault/02_product/02_course_creation/01_lesson_spec/02_topic_raw/Level_1/1_How_Korean_works/1-1_topic_raw.md)를 가리켜 발췌를 중복 저장하지 않는다.

## OUTLINE으로 넘기기 전 검사

- Ji 피드백의 추가·제외·예시·설명 깊이 결정이 `TEACHING_POINTS` 또는 `OUT_OF_SCOPE`에 모두 반영됐는지 대조한다.
- 주소 비유와 동사 앞 강조는 설명을 돕는 비유·경향으로 표시한다. 시간·주어의 순서 변경, 조사 용어, 부사 위치, 불규칙 어간, `먹는데`의 뜻은 원문과 조건을 확인해 절대 규칙이나 일대일 번역으로 쓰지 않는다.
- 예문 후보를 `BUDGET`과 예비 대조한다. 아직 배우지 않은 형태가 들어간 예문은 뜻과 구조를 보여 주는 관찰용으로 표시하거나 더 쉬운 예문으로 바꾼다. OUTLINE에서 예문의 배치 시점이 정해지면 `BUDGET`을 다시 확인한다. 핵심 판단이 남으면 `OPEN`에 근거와 함께 남기고 Ji의 결정을 받아 해결한다.
- 검사를 통과하면 `topic_shaped`의 Ji 피드백 반영 근거와 `lesson_spec` 완료 근거를 진행표에 **순서대로** 기록한다. OUTLINE에서는 Skeleton → Flesh에 따라 소주제의 순서와 각 소주제를 무엇으로 어떻게 설명할지 설계한다. CLEAR로 레슨 전체를 점검하고 4MAT은 핵심 개념 묶음에만 적용한다. 실제 영상 대사는 DRAFT에서 작성한다.

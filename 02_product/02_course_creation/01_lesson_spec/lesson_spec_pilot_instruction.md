# lesson_spec 파일럿 작업지시서

> Hangul·Numbers·Level 1·Level 2의 44개 정식 레슨을 실행하는 순서다. 매핑된 raw는 파일관리 534개와 Hangul 외부자료 4개다.
> 판단 기준은 [[course_plan]], status 기록법은 [[lesson_spec_tracking]], 용어는 [[glossary]]를 따른다.
> 최종 갱신: 2026-09-27

## 한 레슨을 시작할 때

1. V7에서 레슨 번호·제목·주제를 확인하고 바로 앞뒤 레슨의 제목·주제도 읽는다. 제목만 보고 세부 내용을 만들어내지 않는다.
2. 해당 레슨의 Ji Draft가 있으면 먼저 읽는다. Ji가 영상에서 풀려던 핵심 설명과 비유를 확인한다.
3. 트랙별 index와 tracking의 `파일관리`·`외부자료`에서 매핑된 모든 Ref_No·상대경로를 모은다. 실제 파일이 없거나 index와 다르면 중단하고 보고한다.
4. 각 파일이 `duplicate_material_selection.xlsx`의 중복 묶음에 속하는지 확인한다. 중복 여부는 파일명만으로 확정하지 않고 실제 본문을 대조한다.

## `range_set` 작성

1. V7 제목 → brainstorm 참고 → Ji Draft → 모든 매핑 raw의 본문 순서로 읽고, 이번 영상이 **직접 설명할 내용**을 제안한다. 그다음 앞선 내용의 짧은 복습과 다른 레슨에서 자세히 설명할 내용을 나눈다. `01_range_set/<레벨>/<레슨>/<레슨 ID>_range_set_review.md`에 근거와 Ji가 결정할 경계를 기록한다.
2. `range_set_source_spans.xlsx`의 `파일판정`에서 해당 레슨의 모든 Ref_No를 필터링한다. Ji Draft는 파일 전체 `사용`으로 기록돼 있다. 다른 자료의 `사용 후보 / 제외 후보 / 보류`는 탐색 초안이므로 원문을 직접 확인해 `사용 / 사용 안 함`으로 고친다. 사용하지 않으면 그 파일에 맞는 구체적인 이유를 남긴다. 후보가 아예 없거나 근거가 약한 파일도 생략하지 않는다.
3. 중복 매핑 파일은 `duplicate_material_selection.xlsx`의 묶음 ID로 연결 레슨을 보고, **같은 원문**의 각 대목을 어느 레슨에서 직접 설명할지 교차 검증한다. Ji Draft 외의 단독 매핑 파일은 자료 전체를 자동 포함하지 않는다. Amira의 동일 수업은 녹화 레슨 → PPT+Script 통합본 → Script 순서로 살피고 하위 자료의 고유 내용을 확인한다.
4. `사용구간`에서 해당 Ref_No의 시작·끝 줄과 실제 Markdown 본문을 대조한다. **Ji Draft는 예외적으로 매핑된 파일 전체를 `사용` 한 구간(1~마지막 줄)으로 기록한다.** 추론한 레슨 설명 범위와 어긋나 보이는 대목은 자르지 말고 카드에 별도 Ji 확인 요청을 남긴다. 다른 자료의 자동 탐색 후보는 제목이나 한 문장만 골랐을 수 있다. 필요한 설명의 앞뒤 문단, 조건·예외·부정 예문까지 포함하고, 다른 레슨의 상세 설명이 끼면 나눈다. 떨어진 대목은 구간을 분리한다. 확정한 행의 `검증 상태`를 바꾼다.
5. XLSX를 현재 기준으로 삼아 카드의 `매핑 자료 전체 · XLSX 판정 현황` 표를 맞춘다. 해당 레슨의 **모든 Ref_No**를 한 번씩 싣고 Ref_No에는 실제 raw 사본을 여는 상대경로 링크를 건다. 각 행에 `사용여부`, 모든 사용구간의 시작·끝 줄, 줄별 주제, `파일판정`의 `판정 이유`를 넣는다. 구간이 없으면 `선택 구간 없음`을 쓴다. 여러 구간은 줄·주제를 같은 순서로 나열한다. 기본 주제는 `사용구간`의 `원문 위치`를 쓰되, 그것이 `Lesson Overview` 같은 위치명·긴 문장·URL에 그치면 해당 원문 줄을 읽고 짧고 구체적인 주제로 바꾼다. 원문을 읽지 않고 주제를 만들지 않는다. Ji Draft는 전체 줄과 원문 소제목에 근거한 전체 주제 개요를 표시한다. 후보 상태는 확정처럼 쓰지 않는다.
6. 자료표 아래 `Ji에게 필요한 답변`에 Ji가 결정할 질문을 빠짐없이 적는다. 각 질문마다 `Ji가 정할 내용`·`Ji 판단이 필요한 이유`·빈 `Ji 답변`을 둔다. 이유에는 관련 레슨, Ref_No, 원문 대목과 충돌·부족한 근거를 구체적으로 쓴다. 직접 설명 범위, 앞선 내용의 복습, 뒤 레슨으로 넘길 상세 내용, Ji Draft와 범위의 불일치, 자료 부족·출처 충돌이 Ji의 결정 대상이다. 원문 재독, 후보의 적합성·줄 번호 검증은 `Agent가 확인할 사항`으로 분리한다. Ji가 이미 적은 답변·검토 결과는 표를 다시 맞출 때 보존한다. 특히 Level 2-8은 매핑된 두 Amira 파일이 제목의 `Rule of Three 우회`를 직접 설명하는 근거가 부족하므로 Agent가 원문을 확인한 뒤 자료 재매핑 또는 레슨 범위 조정에 대한 Ji의 방향 결정을 받는다.
7. 카드 표와 XLSX의 레슨별 Ref_No 목록·행 수·상태·선택 구간·판정 이유를 대조하고 모든 링크가 실제 raw 사본을 여는지 확인한다. Ji 의견으로 판정을 바꿀 때는 원문 검증 → XLSX 수정 → 카드 표 재반영 순서로 처리한다. 표만 고쳐서 별도 판정본을 만들지 않는다.

파일럿 44개 카드와 538개 Ref_No 작업표는 **제안 초안**이다. 이 단계의 생성만으로 `range_set`이 완료되지 않는다. 모든 Ref_No가 최종 판정되고 정확한 구간의 원문 대조, Ji의 설명 경계 검토, 진행을 막는 `OPEN` 해결이 끝난 레슨만 tracking을 `range_set`으로 올린다. Ji에게 명확한 개별 구간을 일일이 승인받지 않는다.

## `topic_raw` 작성

1. Ji가 확인한 카드와 XLSX `파일판정`의 최종 `사용` 행에 연결된 `사용구간`만 raw에서 읽어 `02_topic_raw/`의 레슨 파일 `RAW_DIGEST`에 원문 그대로 붙인다.
2. 각 발췌에 Ref_No·상대경로·원문 제목·줄 번호를 붙인다. 요약, 번역, 출처 혼합, Ji식 재서술은 여기서 하지 않는다.
3. 발췌와 실제 원문을 문자 그대로 대조한다. 범위 밖 문장, 제목만 있고 본문이 없는 구간, 필요한 조건·예외 누락이 있으면 `range_set`으로 돌아가 고친다.
4. 모든 사용 구간이 발췌됐고 출처·문자열 대조를 통과한 뒤에만 tracking을 `topic_raw`로 올린다.

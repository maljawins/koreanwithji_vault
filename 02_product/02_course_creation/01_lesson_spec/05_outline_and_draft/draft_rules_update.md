# DRAFT 작성 규칙 업데이트안

> 적용 대상: 승인된 OUTLINE을 실제 대사·화면·모션으로 바꾸는 단계. 이 파일은 Drop-off Zone의 검토안이며, 기존 정본을 아직 바꾸지 않는다. OUTLINE에서 먼저 결정할 조건은 [[outline_rules_update]]를 가리킨다. 대본 톤은 [[01_brand#8. Brand Tone (학생에게 말할 때의 대본 톤)]]을 따른다.

## 1-1 작성 계획과 초안에서 확인된 빈틈

| 기존 계획과 초안의 상태 | DRAFT 규칙에 필요한 보완 |
|---|---|
| [[1-1_draft_plan#작성 순서]]는 BEAT마다 한 가지 내용을 정하지만, 도입의 학습 약속이 실제 대사에 들어갔는지와 각 BEAT가 그 약속에 기여하는지는 검사하지 않는다. 1-1 초안은 “어디에 정보가 놓이는지 보라” 이후 동사 끝 형태를 여러 종류 소개한다. | 시작에 What·Why·Success를 실제로 말하고, 소주제 전환과 마무리에서 같은 목표를 다시 연결한다. |
| 계획은 `BUDGET`을 확인하지만, 학생이 만들어야 할 것이 없다는 사실과 학생이 기억해야 할 구분의 수를 별도로 검사하지 않는다. | BEAT를 늘리면서 생긴 새 용어·형태·비유의 부담을 다시 세고, OUTLINE의 `핵심 / 예고 / 이월` 결정을 지킨다. |
| [[1-1_draft_plan#DRAFT에 적을 단위]]는 답을 미리 보여 주지 말라고 하지만 질문 화면의 뜻풀이·라벨·강조색까지 검사하도록 하지 않는다. 1-1 초안의 마지막 질문은 여러 번 본 문장과 뜻풀이가 남은 화면에 있다. | 질문 대사, 생각할 틈, 화면의 정답 단서 숨김, 정답과 이유를 한 묶음으로 작성·검사한다. |
| 계획은 대사와 모션을 맞추라고 하지만 **모든 발화 단서가 최종 대사에 실제로 있는지** 대조하는 절차가 없다. 1-1 초안에는 `pieces ... fit together`, `leave things unsaid`처럼 대사에 없는 모션 기준 문구가 남았다. | 완성 대사를 기준으로 화면 트리거를 전수 대조하고 낭독 후 다시 맞춘다. |
| 계획은 소리·뜻·구조를 한 화면에서 연결하도록 한다. 1-1 초안의 첫 긴 문장 화면은 자연스러운 뜻·어절 뜻·직역·그림이 동시에 전면에 나온다. | 이해 단서는 유지하되 학생이 그 순간 볼 한 요소를 시각적으로 우선시하고 16:9에서 실제로 읽히는지 검사한다. |

## 추가할 작성 규칙

### A. 학습 약속을 대사로 실현한다

승인된 OUTLINE의 What·Why·Success를 대본 시작에서 학생이 바로 알아들을 말로 전달한다. 훅을 썼다면 훅에서 발견한 현상이 왜 오늘의 내용으로 이어지는지 **대사에** 넣는다. 화면 제목이나 제작 메모만으로 대신하지 않는다.

각 소주제의 첫 BEAT에는 `지금까지 본 것 → 이번에 볼 부분 → 이것이 목표에 주는 도움` 중 필요한 연결을 짧게 적는다. 형식을 기계적으로 반복하지 않는다. 마무리에서는 도입의 성공 기준으로 돌아와 학생이 실제로 확인한 단서를 말한다. `왜 이 내용을 배우는가`가 끝에 가서야 처음 드러나지 않도록 한다.

### B. 범위를 BEAT 단위로 다시 검사한다

각 BEAT 옆에 `중심 목표에 기여하는 한 가지 / 새로 기억할 말이나 형태 / OUTLINE의 핵심·예고·이월 결정`을 기록한다. 같은 기능을 보여 주는 예문이 늘어나더라도 학생에게 요구하는 새 판단이 늘어나는지 확인한다. `나중에 배운다`, `지금 외우지 않아도 된다`는 대사만 추가해 과밀한 내용을 해결한 것으로 보지 않는다.

승인 OUTLINE과 `lesson_spec`의 범위 때문에 목표에 비해 과밀하다고 판단되면, DRAFT에서 임의로 설명 범위를 바꾸지 않는다. 어떤 BEAT가 왜 부담인지, 핵심·예고·이월 중 무엇으로 바꿀지 Ji에게 제시하고 앞 단계의 결정을 맞춘다. Ji가 확정한 범위 안에서는 대사·화면을 압축한다.

### C. 적용 질문을 실제로 작동하게 만든다

OUTLINE에서 정한 적용 질문은 DRAFT에서 다음 순서로 완성한다.

1. **질문:** 익힌 단서를 다른 배치 또는 최소 변형에 적용하게 한다. 새로운 문법이나 어휘 지식을 시험하지 않는다.
2. **생각할 틈:** 대본에 명시한다. 정답을 말하거나 강조하기 전에 잠깐 멈춘다. 녹음 전 임의의 초 단위 타임코드는 만들지 않는다.
3. **질문 화면:** 한국어와 상황 이해에 필요한 정보는 남긴다. 정답 어절의 영어 뜻, 역할 라벨, 색, 화살표 등 답을 알려 주는 단서는 이때 가린다.
4. **피드백:** 정답을 보인 뒤 어떤 조사·어순·동사 단서로 판단했는지 설명한다. 단순히 정답 어절만 읽고 끝내지 않는다.

완료 검사에서는 질문이 처음 예문을 다시 따라 읽는 활동에 그치지 않는지, 학생이 답을 보기 전에 실제로 생각할 수 있는지 확인한다.

### D. 한 화면에서 볼 정보와 모션을 대사에 맞춘다

각 BEAT의 화면 지시는 `시작 상태 → 실제 대사 속 트리거 문구 → 등장·강조·퇴장 → 끝 상태`로 적는다. 트리거는 **최종 대사에 있는 정확한 표현** 또는 한국어 발화로 지정한다. 대사가 바뀌면 같은 BEAT의 화면 글자·뜻·발화 단서를 바로 다시 대조한다. 대사에 없는 인용 문구, 표시되지 않는 요소, 답을 미리 밝히는 강조가 남으면 제작 인계 전 고친다.

새 한국어 예문에는 [[lesson_design_method#3. Comprehensible Input (이해 가능한 입력)]]에 따른 소리·글자·어절 뜻·구조·직역의 연결을 유지한다. 그러나 **지금 설명하는 한 요소**가 먼저 보이도록 글자 크기·위치·명암·강조 순서를 정한다. 자연스러운 번역과 직역은 서로 다른 역할로 표시하고 뜻의 핵심 차이를 지우지 않는다. 16:9 정지 화면에서도 핵심 글자가 읽히는지 확인한다. 전체 영어 자막은 [[1-1_draft_plan#DRAFT에 적을 단위]]의 기존 결정을 따른다.

### E. 정확성과 낭독을 최종 대사 기준으로 확인한다

비유와 실제 문법 설명, 경향과 항상 성립하는 규칙, 자연스러운 영어 뜻과 직역을 구분한다. 의미 차이나 말높임을 단순한 강약 차이로 소개할 때는 근거와 사용 상황을 확인한다. 불확실한 풀이를 화면 문구로 확정하지 않는다. Ji의 말투와 단어 선택은 [[01_brand#8. Brand Tone (학생에게 말할 때의 대본 톤)]]을 따르고, 소리 내어 읽은 뒤 바뀐 대사에 맞춰 화면을 다시 맞춘다.

## 제작 인계 전 완료 검사

| 확인할 것 | 통과 증거 |
|---|---|
| 학습 약속과 맥락 | 도입 대사에 What·Why·Success가 있고 훅에서 본문으로 이어지는 말, 주요 전환, 같은 목표로 돌아오는 마무리가 있다. |
| 범위 | 모든 BEAT가 목표와 연결되며 새 학습 부담이 OUTLINE의 깊이 결정과 맞는다. 범위 변경이 필요한 문제는 Ji 결정 전 임의로 고치지 않았다. |
| 적용 질문 | 다른 배치 또는 최소 변형을 묻고, 대본에 생각할 틈이 있으며, 질문 화면에는 정답 단서가 없다. 피드백은 정답의 근거를 말한다. |
| 화면 | 한국어 소리·글자·뜻·구조·직역이 맞고, 한 순간의 시각적 초점이 분명하며 16:9에서 읽힌다. |
| 동기화 | 모든 모션 트리거가 최종 대사에 있고, 낭독 뒤 바뀐 대사와 화면을 다시 대조했다. |
| 정확성 | 예문 뜻, 용어, 비유, 한정 표현을 원문 근거와 `BUDGET`에 맞춰 확인했다. |

이 업데이트안은 1-1 DRAFT 초안을 자동으로 수정하지 않는다. 실제 규칙 정본 반영과 1-1 재작성은 Ji의 검토 후 별도 작업이다.

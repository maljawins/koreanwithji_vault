# OUTLINE 작성 규칙 업데이트안

> 적용 대상: `lesson_spec → OUTLINE` 단계. 이 파일은 Drop-off Zone의 검토안이며, 기존 정본을 아직 바꾸지 않는다. 내용·범위의 정본은 [[course_plan]]과 해당 `lesson_spec`, 교수 설계법의 정본은 [[lesson_design_method]]이다.

## 1-1에서 확인된 빈틈

| 기존 문서에서 확인한 내용 | 부족한 검사 | OUTLINE에서 막아야 할 결과 |
|---|---|---|

## 추가할 작성 규칙

### A. 도입의 학습 약속을 먼저 확정한다

OUTLINE 첫머리에 다음 세 문장을 **학생에게 전달할 내용**으로 적는다. 실제 영어 대사는 DRAFT에서 쓴다.

1. **What:** 이번 영상에서 볼 핵심 지도 또는 판단 하나는 무엇인가.
2. **Why:** 이 지도를 알면 학생이 실제 한국어 문장을 읽거나 이해할 때 무엇이 달라지는가.
3. **Success:** 영상 끝에 학생이 이미 배운 단서를 사용해 **무엇을 알아볼 수 있는가**. `이해한다`처럼 확인할 수 없는 말만 쓰지 않는다. 문장 만들기나 후속 레슨의 활용법을 요구하지 않는다.

도입 예시를 쓰면 `예시에서 발견한 현상 → 오늘의 지도 → 학생에게 생길 이익 → 첫 본문 예시`의 연결을 한 줄씩 계획한다. 도입과 마무리가 같은 약속을 가리키는지 확인한다. `GOAL`은 영상의 핵심 설명이고 worksheet 수행 목표가 아니라는 [[course_plan]]의 구분을 유지한다.

### B. 소주제마다 중심선과 학습 부담을 검사한다

소주제마다 아래 네 가지를 OUTLINE에 남긴다.

| 필드 | 적을 내용 |
|---|---|
| 중심선 연결 | 이 소주제가 도입의 What·Why·Success 중 무엇을 돕는가. 직전 소주제에서 왜 여기로 오는가. |
| 학생이 새로 구분할 것 | 새 용어·형태·대조·비유 중 실제로 기억해야 할 것과 단순히 보여 줄 것을 구분한다. |
| 깊이 결정 | `핵심 설명 / 짧은 예고 / 뒤 레슨으로 이월` 중 하나를 정하고 이유를 적는다. 예고라면 학생에게 어떤 한 가지 사실만 남길지 정한다. |
| 범위 근거 | 해당 `lesson_spec`의 `GOAL`, `NEW`, `PREREQ`, `BUDGET`, `OUT_OF_SCOPE`와 출처를 확인한다. |

소주제가 학습 약속에 기여하지 않거나 새 구분이 지나치게 쌓이면 압축·이월 후보로 표시한다. 이미 승인된 `lesson_spec`의 설명 경계를 바꿔야 한다면 OUTLINE에서 조용히 삭제하거나 새 범위를 확정하지 않는다. 근거와 학생에게 생길 영향을 적어 Ji의 범위 결정을 받은 뒤 앞 단계부터 맞춘다. `BUDGET` 검사에는 **만들기를 시키는가**뿐 아니라 **알아보려면 새로 무엇을 기억해야 하는가**도 포함한다.

### C. 답이 보이지 않는 적용 질문을 설계한다

OUTLINE에는 중심 학습 약속을 확인할 **최소 한 개의 짧은 적용 질문**을 넣는다. 다음을 모두 명시한다.

- 학생이 판단할 대상: 이미 설명한 예문과 **다른 배치 또는 최소한의 변형**을 사용한다. 처음 문장을 그대로 다시 가리키는 질문만으로 끝내지 않는다.
- 요구할 행동: 배운 단서로 장소·대상·행동·표지 등 이번 목표에 해당하는 것을 **알아보기**로 한정한다. 새 어휘나 아직 가르치지 않은 활용을 요구하지 않는다.
- 질문 화면: 답을 드러내는 색, 화살표, 역할 이름, 해당 어절의 영어 뜻을 **답을 생각하는 동안** 어떻게 가릴지 정한다. 한국어 문장과 상황 이해에 꼭 필요한 정보는 남긴다.
- 피드백: 잠깐 생각할 틈 뒤 정답을 보여 주고, **어떤 단서를 보고 찾았는지** 한 문장으로 설명한다.

기존 문장으로 돌아오는 정리는 유지할 수 있다. 다만 그 정리를 새로운 배치에 대한 적용 질문의 대용으로 계산하지 않는다.

### D. 화면 정보의 우선순위를 OUTLINE에서 정한다

각 예문의 첫 노출과 재등장에 대해 `지금 볼 핵심 / 계속 보일 이해 단서 / 이 순간에는 약하게 둘 정보 / 확인 질문 동안 가릴 정답 단서`를 적는다. [[lesson_design_method#3. Comprehensible Input (이해 가능한 입력)]]에서 요구하는 소리·글자·어절 뜻·구조·직역의 연결은 유지한다. 동시에 여러 정보층을 같은 크기와 강조로 내놓지 않는다. 16:9 화면에서 필요한 정보를 읽을 수 없으면 배치와 장면 분할을 다시 설계한다.

## DRAFT로 넘길 때의 완료 조건

- 도입의 What·Why·Success와 마지막 확인 질문이 같은 학습 약속을 검사한다.
- 모든 소주제에 중심선 연결, 새 학습 부담, 깊이 결정, `lesson_spec` 근거가 있다.
- 핵심 설명·짧은 예고·이월을 구분했고, 범위 변경이 필요하면 Ji의 결정 지점을 표시했다.
- 적용 질문의 대상, 가릴 정답 단서, 생각할 틈, 피드백을 정했다.
- 첫 화면과 재등장 화면의 정보 우선순위를 정했으며 대사와 모션의 실제 구현은 DRAFT에 인계했다.

이 업데이트안은 1-1의 소주제 순서를 자동으로 바꾸거나 승인된 OUTLINE을 소급 수정하지 않는다. 실제 반영 위치는 Ji가 검토한 뒤 정한다.

# 2-7 · TSV Sentence Structure #6 - Common Expressions · 설명 범위 검토

> Agent가 매핑 원문과 구간을 대조해 사용 여부를 잠정 판정했다. Ji가 설명 경계를 검토하기 전이므로 tracking은 raw_mapped다.

## 판단 출발점

- **V7 제목:** `TSV Sentence Structure #6 - Common Expressions`.
- **V7 brainstorm 참고:** 한국어의 상당수의 Idiomatic expression들이 TSV형태로 되있음  - 그 사람은 눈이 높아  - 그 사람은 입이 싸  - 그 사람은 머리가 좋아  - 그 사람은 인기가 많아
- **Ji Draft:** Ji-2-7-1.
- **매핑 원문:** 1개 Ref_No. 사용 1개, 사용 안 함 0개, 선택 구간 1곳. 자료 판정의 정본은 [[range_set_source_spans.xlsx]]이다.

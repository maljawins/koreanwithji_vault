# 2-8 · Context markers #3 - Bypassing Rule of Three · 설명 범위 검토

> Agent가 매핑 원문과 구간을 대조해 사용 여부를 잠정 판정했다. Ji가 설명 경계를 검토하기 전이므로 tracking은 raw_mapped다.

## 판단 출발점

- **V7 제목:** `Context markers #3 - Bypassing Rule of Three`.
- **V7 brainstorm 참고:** Context markers (거든, 잖아, 네, 지 등)는 대화의 '맥락'을 짚어서 Rule of Three를 기능적으로 우회한다.  직접 표현 불가능한 상황을 맥락 표지자로 해결하는 방법 제시. 예: 아/어요로는 단정 불가능한 감정 → 잖아로 '맥락적 암시' 기능 활용  - 예: 너는 슬퍼 (X) 너는 슬프잖아 (O)
- **Ji Draft:** 매핑 없음.
- **매핑 원문:** 2개 Ref_No. 사용 0개, 사용 안 함 2개, 선택 구간 0곳. 자료 판정의 정본은 [[range_set_source_spans.xlsx]]이다.

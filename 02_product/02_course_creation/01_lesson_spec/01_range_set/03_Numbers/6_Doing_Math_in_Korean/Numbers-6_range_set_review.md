## 판단 출발점

- **V7 제목:** `Doing Math in Korean`.
- **V7 brainstorm 참고:** 더하기, 빼기, 나누기, 곱하기, 배, 분의, etc

## Ji 결정

- 검토 근거: [[Numbers-6_range_set_feedback]].
- 사칙연산의 한국어 명칭을 간략히 직접 설명한다. YT-Numbers-6-1의 수학 관련 부분을 사용한다.
- 다만 해당 원본은 사칙연산의 영어 이름만 언급하고 한국어 명칭은 제시하지 않는다. 발췌만으로는 Ji의 설명 범위를 뒷받침할 수 없다.

## Agent가 확인할 사항

- 4개 Ref_No의 실제 파일과 5개 구간의 시작·끝 줄을 확인했다.
- Ji Draft가 없고 매핑 4개에는 기본 사칙연산의 한국어 명칭이 없다. 더하기·빼기·곱하기·나누기를 이 단계의 원문 발췌로 지어내지 않는다.
- **미해결:** Ji가 선택한 설명 범위의 직접 원본 근거가 없다. 자료 보강이 필요하다.

## 판단 출발점

- **V7 제목:** `SOV Sentence Structure`.
- **V7 brainstorm 참고:** Object marker 을/를, action vs descriptive verbs, prohibition: "descriptive verbs cannot have objects"

- **매핑 원문:** 19개 Ref_No. 사용 10개, 사용 안 함 9개, 선택 구간 19곳. 자료 판정의 정본은 [[range_set_source_spans.xlsx]]이다.

## Ji에게 필요한 답변

1. **Ji가 정할 내용:** 목적격 조사 설명에 은·는/이·가를 어느 정도 비교하고 상세 비교는 2-1로 넘길까?
   - **Ji 판단이 필요한 이유:** V7과 현재 카드의 중심은 을·를이다. 주제·주격 조사를 자세히 설명하면 2-1과 중복된다.
   - **Ji 답변:** 아직까지 이,가를 언급하지 않는다. 은,는에 대한 간략한 설명은 1-1에서 다뤘으니 설명을 생략한다. 자세한 건 2-1에서 다루겠다고 예고한다. 이번 레슨은 을,를에 대한 설명위주로 다룬다.

2. **Ji가 정할 내용:** 상태동사는 목적어를 못 쓴다는 설명을 어떤 수준과 표현으로 다룰까?
   - **Ji 판단이 필요한 이유:** V7에 이 문장이 직접 적혀 있다. 예외 없는 절대 규칙으로 가르치기 전 Agent가 원문·예문 정확성을 검증하고 Ji가 설명 방식을 결정해야 한다.
   - **Ji 답변:** Ji-1-7-1의 설명 수준 유지. Descriptive verb에 을,를을 쓸 수 없다는 건 "예외없는" 규칙이다.

기타 사:
- 를 contraction의 '나를 = 날', '저를 - 절', '너를 = 널', '것을 = 걸' 설명 시 pronoun에 대해 1-12에서 자세히 배우게 될 것이라는 언급을 함께 해준다.

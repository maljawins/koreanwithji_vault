## Ji의 설명 경계 결정

Ji가 남긴 판단과 이 단계에서 반영한 답변이다.

1. **Ji가 정할 내용:** SOV·STLOHV와 목적어 조사 을·를을 도입 영상에서 어디까지 직접 설명하고 1-7로 넘길까?
   - **Ji 판단이 필요한 이유:** V7은 구조 큰 그림과 조사 예고를 적었지만 Ji-1-1-1에는 STLOHV와 을의 상세 설명이 있다. 1-7과 직접 설명이 겹친다.
   - **Ji 답변:** 을·를은 문장의 목적어를 표시하는 역할만 설명한다.
2. **Ji가 정할 내용:** 부사와 동사의 어간·어미·활용을 여기서 직접 설명할까, 구조 예고만 하고 1-5로 넘길까?
   - **Ji 판단이 필요한 이유:** Ji-1-1-1의 178줄 이후에 부사, 192줄 이후에 동사 형태가 길게 나온다. 현재 제안은 “큰 그림”이다.
   - **Ji 답변:** Ji-1-1-1의 현재 설명 깊이를 유지한다.
3. **Ji가 정할 내용:** Ji Draft 후반의 문장 종류·speech level·문장 연결은 큰 그림으로만 예고하고 후속 레슨에서 설명할까?
   - **Ji 판단이 필요한 이유:** Ji-1-1-1의 후반에는 현재 경계표에 없는 세부 설명이 이어진다. 1-2·1-17·1-19 등 후속 레슨과 중복된다.
   - **Ji 답변:** Ji-1-1-1의 현재 설명 깊이를 유지한다.

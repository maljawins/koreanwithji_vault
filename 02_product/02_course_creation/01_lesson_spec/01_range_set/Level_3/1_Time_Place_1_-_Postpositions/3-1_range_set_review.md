## Ji가 정할 내용

- **설명 경계:** V7 제목과 brainstorm을 기준으로 한 이번 영상의 직접 설명 범위를 승인하거나 수정한다. 원문 후보를 모두 영상에 넣는다는 뜻은 아니다.
- **Ji 판단이 필요한 이유:** 직접 설명·복습·후속 레슨의 경계가 정해져야 관련 구간을 최종 판정할 수 있다.

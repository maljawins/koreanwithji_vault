# 발췌 텍스트와 학습 범위 확정

[range_set_review.xlsx](../01_lesson_spec/01_range_set/range_set_review.xlsx)에 설정된 구간에서 실제로 가져올 텍스트를 확정한다. 레슨별 범위는 [학습 범위 기록](../lessons/학습범위.md) 한 파일에 남기며, OUTLINE과 대사는 이 기록을 읽고 작성한다.

## 기존 작업을 이어받는 기준

1차 range_set은 레슨별로 가져올 원문 구간을 정하는 작업으로, 다음 기준과 절차에 따라 진행되었다.

1. **레슨의 중심 설명 확인:** 현재 커리큘럼의 `Ji 레슨 Title`로 중심 주제를 잠정 정하고, `Ji 레슨 주제 (brainstorm)`와 Ji Draft로 Ji의 설명 의도를 확인했다. 구상 메모를 확정 지시로 보거나 자료 한 개의 목차를 그대로 레슨 범위로 삼지 않았다.
2. **매핑된 자료 대조:** 해당 레슨에 연결된 모든 자료의 본문을 `Ref_No`별로 살펴보고, 여러 출처가 공통으로 다루는 설명 대상을 중심 후보로 좁혔다. 설명 방식이나 원인 해석이 달라도 관련 구간을 출처별로 남겼다. 일부 자료에만 있는 조건·예외·예문도 직접 설명에 필요하면 보조 후보로 남겼다. 자료가 하나뿐이면 커리큘럼·Ji Draft와 대조했고, 공통 주제가 없거나 설명 의도가 충돌하면 Ji의 판단을 받도록 했다.
3. **레슨 사이의 설명 경계 검토:** 직접 설명할 내용을 먼저 정한 뒤 앞뒤 레슨과 같은 원본이 연결된 다른 레슨을 확인했다. 각 대목을 `직접 설명 / 보조 근거 / 짧은 복습 / 다른 레슨의 상세 내용`으로 나누고, Ji가 이번 레슨에서 직접 설명할 내용·복습할 내용·다른 레슨으로 넘길 상세 내용의 경계를 검토하도록 했다. 중복 매핑 여부만으로 사용 범위를 확정하거나, 다른 자료에 같은 주제가 있다는 이유로 관련 구간을 제외하지 않았다.
4. **출처에 맞는 구간 선택:** Ji Draft는 매핑된 파일 전체를 하나의 사용구간으로 두었다. 그 외 자료는 전체를 자동 포함하지 않고, YouTube·녹화 레슨의 Teaching Points와 HTSK·Web 등의 설명 본문에서 관련 대목을 찾고 필요하면 해당 Transcript를 확인했다. 실제 사본의 줄 번호로 구간을 정하고, 설명에 필요한 조건·예외·부정 예문과 문맥을 보존했다. 별도 외부자료는 Ji가 레슨과 범위를 지정했을 때만 사용하고, 이미 매핑된 Hangul 외부자료 사본은 해당 자료 목록을 따랐다.
5. **한 엑셀에 판단 기록:** `range_set_review.xlsx`에 레슨·`원문 Ref_No`·자료명·사용 여부·줄 범위·선택된 줄의 주제·최초 판정 이유를 기록했다. 떨어진 구간은 별도 행으로 두고, `원문 Ref_No`에는 실제 사본을 여는 링크를 연결했다. Ji는 설명 경계·자료 부족·충돌을 검토하고 `Ji 검토여부`와 `Ji feedback`에 직접 표시·의견을 남기는 방식으로 진행했다. Agent가 `O`를 대신 넣거나 빈칸을 승인으로 해석하지 않으며, 명확한 개별 구간마다 Ji의 승인을 요구하지 않는 기준이었다.

현재 엑셀의 구간과 Ji 의견을 이어받고 처음부터 재선정하지 않는다. 이전 단계 승격·진행표 갱신 절차를 현행 필수 단계로 되살리지 않는다.

후보·보류 행에 대응 줄을 적어도 사용이 확정된 것은 아니다. 새 발췌에는 `사용` 행과 Ji가 명시적으로 지정한 범위만 쓴다. Ji의 검토 표시·feedback과 최초 판단 기록은 보존한다.

## 1. Teaching Point와 실제 발화 연결

- `원문 Ref_No`로 해당 사본을 찾고 `Teaching point 줄`·`해당 주제`에 상응하는 **실제 설명 멘트**를 `해당 Transcript 줄`에 적는다. 열 위치 대신 헤더 이름으로 읽는다.
- 줄 번호는 영상 시간이나 요약의 줄 번호가 아니라 **해당 Ref_No 사본의 파일 줄 번호**다. 떨어진 구간은 `67–73, 81–83`처럼 구분한다.
- YouTube와 실제 녹화 레슨은 대응 Transcript를 직접 읽어 설명 순서·비유·예문·조건·예외를 확인한다. 단어가 겹친다는 이유만으로 대응한다고 확정하거나 영상 전체를 일괄 지정하지 않는다.
- Ji Draft·HTSK·Web·PPT와 Script 통합본처럼 별도 Transcript가 없는 문서는 `별도 Transcript 없음; 본문 <줄 범위>줄`로 적고 지정 본문을 사용한다. Ji Draft는 매핑된 원문 전체를 읽어 설명 의도를 확인한다.
- 녹화가 없어 재구성된 자료나 AI 생성 Script는 실제 발화로 표시하지 않는다. Amira는 실제 녹화 레슨 → PPT+Script 통합본 → Script 순으로 확인하되, 같은 수업의 독립 근거처럼 세지 않는다. Day 20 AI 생성 Script는 Ji 말투의 근거로 쓰지 않는다.
- `사용 안 함`은 `발췌 안 함`, 줄 범위가 없는 후보·보류는 `범위 미정: Teaching point 줄 없음`으로 표시한다. 대응 발화를 확정하지 못하거나 원문이 없으면 원인을 적고 `확인 필요`로 남긴다. 추정 줄 번호를 확정값처럼 쓰지 않는다.

## 2. 선택 원문 텍스트 정리

`사용` 행의 확정 Transcript 구간을 발췌한다. 별도 Transcript가 없는 문서는 지정 본문을 가져온다. 기존 [topic_raw 폴더](../01_lesson_spec/02_topic_raw/)의 해당 레슨 발췌를 재사용한다. 새 발췌는 실제 매핑과 같은 레벨·레슨 폴더의 `<레슨 ID>_topic_raw.md`에 두며, 기존 파일 수정은 승인된 레슨 작업 범위 안에서만 한다.

발췌마다 `Ref_No`·실제 사본 경로·줄 범위·원문 텍스트를 함께 남기고 문자 그대로 대조한다. 요약·말투 교정·출처 통합은 하지 않는다. 서로 다른 설명은 출처별로 보존한다. 조건·예외·대화 맥락을 자르거나 관련 없는 다음 주제를 섞지 않는다. 기존 발췌와 현재 범위가 다르면 현재 원문과 Ji 의견으로 차이를 확인한다.

## 3. 누적 학습 범위 기록

[현재 커리큘럼](../00_curriculum_and_index/Korean%20Course%20Curriculum%20Map_Final_V7.xlsx)의 실제 순서와 관련 앞 레슨의 기록·산출물을 대조한다. 제목·구상 메모·앞 레슨의 NEW 계획만으로 실제 배웠다고 단정하지 않는다. 이전 진행표의 상태값은 과거 이력이며 새 제작의 통과 조건이 아니다.

| 구분 | 확인할 것 |
|---|---|
| NEW | 이번 레슨에서 새로 설명할 개념과 설명 깊이 |
| PREREQ | 앞 레슨에서 실제로 다룬 내용과 근거가 되는 레슨·산출물 |
| BUDGET | 예문에서 사용할 수 있는 문법·표현. 앞 레슨과 이번 대사의 해당 시점까지 설명한 것만 포함 |
| OUT_OF_SCOPE | 이번에 자세히 다루지 않을 내용과 확인된 후속 레슨. 소개만 하는 것과 활용까지 가르칠 것을 구분 |

네 항목과 근거·미정 사항은 [lessons/학습범위.md](../lessons/학습범위.md) **한 파일**에 레슨별로 기록한다. 새 레슨 작업 전에는 해당 레슨과 관련 앞 레슨의 항목을 읽는다. 이전에 넘긴 내용이 이번 NEW가 되는지, BUDGET이 실제로 늘었는지 확인한다. 번호가 높아졌다는 이유로 앞의 모든 문법을 배웠다고 간주하지 않는다.

수정 근거와 실제 Ji 검토 상태를 남긴다. OUTLINE·대사에는 이 기록을 가리키고 네 항목의 별도 사본을 만들지 않는다. 별도 lesson_spec이나 레슨별 범위 파일도 추가하지 않는다.

## 아직 배우지 않은 내용이 필요한 경우

- 예문에는 아직 배우지 않은 문법을 사용하는 것을 지양한다. 배운 표현으로 같은 설명이 가능하면 그 표현을 쓴다.
- 설명에 꼭 필요하면 나오기 전에 학생에게 알리고, 지금 이해할 개념과 뜻만 짧게 설명한다. 상세히 다룰 레슨은 현재 커리큘럼에서 확인해 안내한다. 자세한 활용 규칙이나 문장 만들기를 함께 요구하지 않는다.
- 후속 레슨 번호를 확인할 수 없으면 번호를 만들어 넣지 않는다. 안내할 주제와 확인할 사항을 제작 메모에 남긴다. Ji가 미정을 지시한 번호는 그 지시를 따른다. 1-2 샘플의 honorific 안내 `lesson #`는 의도된 빈칸이므로 보존한다.
- 예문이 이해되지 않는 문제는 면책 문구만 붙여 넘기지 않는다. 상황·뜻·설명 깊이를 조정하고, Ji가 정해야 할 범위 충돌이면 근거와 함께 묻는다.

OUTLINE에서 한 번, 실제 대사에서 한 번 더 예문이 나오는 시점과 범위를 확인한다. 필요한 보완은 각 산출물에 반영하고 기존 원본·발췌·주제별 정리는 보존한다.

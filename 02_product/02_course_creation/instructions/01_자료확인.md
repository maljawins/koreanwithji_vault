# 자료 매핑 확인

`01_raw`의 어떤 자료가 이번 레슨에 매핑되었는지 확인한다. 기존 매핑 확인은 완료된 작업이다. 매 레슨마다 자료 선택을 처음부터 다시 하지 않는다.

## 확인 방법

1. [range_set_review.xlsx](../01_lesson_spec/01_range_set/range_set_review.xlsx)의 `Sheet1`에서 `Ji level`·`Ji lesson`으로 해당 레슨을 찾는다. 열 위치 대신 헤더 이름으로 읽는다.
2. `원문 Ref_No`와 연결된 실제 사본으로 매핑을 확인한다. 같은 제목이라도 레슨별 사본과 번호가 다를 수 있다.
3. `사용여부`·`Ji 검토여부`·`Ji feedback`을 읽는다. 후보·보류와 빈 검토 칸을 승인으로 바꾸지 않는다. Ji의 `O`와 의견을 대신 입력하지 않는다.

엑셀만으로 매핑을 확인할 수 있으면 이 단계를 마친다. 아래 자료 목록은 링크가 열리지 않거나 번호·경로가 맞지 않을 때만 확인한다. 실제 사본과 대조해 자료가 없는지, 연결만 잘못되었는지 구분한다. 매핑되지 않은 자료를 임의로 추가하지 않는다.

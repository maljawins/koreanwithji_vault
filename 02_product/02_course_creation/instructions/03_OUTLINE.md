# OUTLINE 작성

소주제의 순서와 무엇을 어떻게 설명할지 정해, [대사 작성](04_대사.md)에 넘긴다. 자료와 범위를 확인한 준비 메모도 이 파일 안에 둔다.

## 교수법 근거

- 주 근거: [4MAT 영상 변환본](../../../05_teaching/4MAT/teaching_Preston%20Chin_How%20To%20Explain%20Anything%20To%20Anyone%20%28The%204MAT%20Method%29.md), [CLEAR 영상 변환본](../../../05_teaching/CLEAR/teaching_Vinh%20Giang_How%20to%20Explain%20Anything%20To%20Anyone%20%28CLEAR_method%29.md). 설명 방법뿐 아니라 실제 사례와 적용 조건을 읽는다.
- 보조 대조: NotebookLM으로 만든 [4MAT 정리](../../../05_teaching/4MAT/Preston%20Chin_Mastering%20the%204MAT%20Presentation%20Method.md), [CLEAR 정리](../../../05_teaching/CLEAR/Vinh%20Giang_How%20to%20Explain%20Anything%20to%20Anyone%20%28The%20CLEAR%20Framework%29.md). 두 제작 방식의 자료를 구분하고, 같은 설명을 독립된 근거 여러 개로 세지 않는다.
- 적용 방식: [대사 샘플](../examples/)의 1-1은 큰 그림과 기준 예문, 1-2는 관계에 따른 표현, 2-1은 핵심 역할에서 이어지는 차이, 2-2는 앞선 개념과 조건 변화의 연결을 참고한다. 주석과 실제 대사를 함께 읽고 참고한 파일·절 또는 구간을 준비 메모에 남긴다.

아래는 교수법 자료와 샘플을 한국어 코스에 맞게 응용한 기준이다. Ji가 검수한 강의 내용을 바탕으로 학생이 설명을 이해하고 판단하는 과정을 설계한다.

## 설명 흐름 설계

- [자료 확인](01_자료확인.md)과 [학습 범위 확인](02_학습범위.md)의 결과를 바탕으로 레슨의 큰 그림에서 필요한 세부로 이어지는 순서를 잡는다. Skeleton·Flesh라는 이름이나 반복 구조를 고정 규칙으로 사용하지 않는다.
- 도입에서 열 주제, 소주제별 핵심 설명·비유·대화 상황, 앞뒤 소주제의 연결, 마무리에서 되짚을 내용을 정한다. 무엇을 왜 여기서 설명하는지 흐름을 읽을 수 있어야 한다.
- 출처의 설명 논리·예문·조건을 비교해 이번 레슨에 맞게 선택·조합한다. 원문과 Ji의 확정 방향을 근거로 하고, 차이가 있는 설명을 확인 없이 같은 주장으로 합치지 않는다.
- 이 단계에서 자료를 한 번 보충하거나 덜어낸다. 추가 근거는 원본 위치로 연결한다. 기존 발췌와 주제별 정리를 다시 만들거나 덮어쓰지 않는다.
- 아래 기준으로 4MAT·CLEAR 적용을 기획하고, [대사 지시서](04_대사.md)에서 실제 설명으로 구현한다. 각 요소의 답이나 적용 질문을 모든 소주제에 일률적으로 채우지 않는다.
- 실제 발화 문장은 대사 단계에서, 구체적인 화면·모션은 완결된 대사 뒤 [BEATS](05_BEATS.md)에서 작성한다. 이 단계에는 설명을 이해시키는 데 필요한 시각화 아이디어를 남긴다.

## 레슨 전체의 기본 흐름

**앞선 지식 불러오기 → 익숙한 영어·일상 비유로 연결 → 예문에 적용 → 조건을 바꿔 비교 → 선택 이유 설명 → 핵심 관계 다시 묶기**

레슨 전체는 이 흐름을 기본으로 설계한다. 도입에서는 앞선 학습이나 관련 경험과 함께 이번 설명이 해결할 문제를 열고, 마무리에서는 전체 핵심 관계를 다시 묶는다. 레슨 성격에 따라 연결·적용·비교의 대상과 설명 순서는 조금 달라질 수 있다. 비교하면서 이유를 바로 설명할 수 있으며, 여섯 단계를 소주제마다 처음부터 반복하지 않는다.

| 레슨 성격 | 흐름을 구체화하는 방향 |
|---|---|
| 문법·표현 | 상황과 예문을 연결하고, 형태·상대·문맥 등의 변화가 해석과 표현 선택에 미치는 영향을 설명한다. |
| 한글 | 글자·소리의 연결과 읽는 과정을 중심으로, 필요한 소리·글자 차이를 비교한다. 적용 사례는 글자·음절·단어 등 해당 범위에 맞춘다. |
| 숫자 | 수의 구성·읽기·사용 상황을 연결하고, 이번 범위에서 달라지는 조건을 비교한다. |
| 공부법·코스 Intro | 현재 학습 경험과 이번 안내를 연결하고, 공부 방법·실행 이유·상황별 조정을 설명한다. |

연결과 비교에 쓸 내용은 Ji의 기존 자료에서 찾는다. 한글·숫자·학습 안내는 해당 성격에 맞는 사례로 흐름을 구현한다.

## 4MAT·CLEAR 적용 기획

### 4MAT: 핵심 개념 묶음의 이해와 판단

학생이 함께 이해해야 하는 개념과 선택을 하나의 묶음으로 잡는다. 예를 들어 은/는·이/가의 역할과 문맥에 따른 선택이 한 묶음이며, 축약형마다 새 묶음을 시작하지 않는다. 네 기능의 순서는 고정하지 않고 레슨의 기본 흐름 안에 배치한다.

| 기능 | OUTLINE에서 정할 것 |
|---|---|
| Why | 이번 설명이 학생의 어떤 문제를 해결하는지, 실제 사례에서는 왜 그런 해석·선택을 하는지 정한다. 해결할 문제는 레슨이나 개념 묶음을 열 때, 해석·선택 이유는 해당 예문을 풀이하는 자리에 배치한다. |
| What | 무엇이며 어떤 역할을 하고 무엇과 구분되는지 정한다. 예문을 이해하는 데 필요한 정의와 경계를 잡고, 용어 소개만으로 끝내지 않는다. |
| How | 기준 사례에서 무엇을 보고 어떤 과정을 거쳐 이해하거나 사용하는지 정한다. 목표에 따라 읽기·식별·해석·표현 선택 중 필요한 과정을 보여준다. |
| What if | 형태·상대·문맥·사용 상황 등 조건이 달라지면 판단이 어떻게 달라지거나 유지되는지 정한다. 기준 사례와 변화된 사례를 연결한다. |

Why의 두 질문은 코스용 응용이다. 필요성이 도입이나 예문 상황에서 이미 드러나면 별도의 장점 설명을 반복하지 않는다. 해석·선택에 필요한 이유는 자료가 제공하는 범위에서 설명하며, 모든 형태의 역사적 발생 이유까지 만들지 않는다. How와 What if가 한 비교에서 함께 구현되면 같은 설명을 다시 배치하지 않는다. 별도 퀴즈나 새 활동을 매번 추가할 의무는 없다.


2-1 샘플에 적용하면
[2-1의 리사 예문](C:/vault/koreanwithji_vault/02_product/02_course_creation/examples/2-1_Ji_draft_CLEAR_4MAT_annotated_.docx)은 이 방식을 잘 보여준다.

| 기능 | 설명에서 할 일 |
|---|---|
| **Why: 해결할 문제** | 두 문장이 모두 “Lisa is American”으로 번역돼도 전달하는 초점이 같지는 않다는 문제를 연다. |
| **What** | 은/는과 이/가가 표시하는 역할을 설명한다. |
| **How + 선택 이유** | “리사는 미국 사람이에요”와 “리사가 미국 사람이에요”가 각각 어떤 질문에 답하는지 연결해 풀이한다. |
| **What if** | 조사만 바꿨을 때 초점과 어울리는 질문이 어떻게 달라지는지 비교한다. 이후 다른 예문에서도 같은 관계를 이어 보여준다. |


### CLEAR: 레슨 전체의 설명 점검

| 요소 | OUTLINE에서 정할 것 |
|---|---|
| Calibrate | [학습 범위 기록](../lessons/학습범위.md)을 바탕으로 출발점과 이번 설명 깊이를 맞춘다. 지금 이해할 것과 뒤로 넘길 것을 실제 설명량에 반영한다. |
| Link | 영어·일상 경험·앞 레슨 중 새 개념을 이해할 연결 고리를 고른다. 스페인어처럼 모르는 언어를 비교에 쓰면 뜻과 필요한 구조부터 풀어 이해할 수 있게 한다. 비유의 닮은 점과 차이도 정한다. |
| Envision | 말만으로 어려운 역할·구조·변화를 무엇으로 보여줄지 아이디어를 남긴다. 구체적인 화면 구성은 BEATS에서 발전시킨다. |
| Abstraction | 충분히 설명한 뒤 학생이 가져갈 핵심 관계와 판단 기준을 쉬운 말로 압축한다. 필요한 조건과 한정은 유지한다. |
| Repeat | 레슨 마지막에 다시 연결할 전체 핵심 관계를 정한다. 소주제 중간의 상기와 구분하고, 마무리에 새 설명이나 활동을 추가하지 않는다. |

적용 기획에는 핵심 개념 묶음, 사용할 예문·비유·비교와 근거, 구현할 설명 위치를 짧게 남긴다. 아래 설명 흐름의 해당 절을 가리켜 같은 내용을 두 번 쓰지 않는다. 기획을 읽으면 학생이 무엇을 보고 왜 그렇게 이해하거나 선택하는지, 조건이 달라져도 그 이해를 어떻게 이어갈지 알 수 있어야 한다.

## 양식과 저장 위치

`lessons/<레벨>/<레슨 폴더>/<레슨 ID>_outline.md`에 저장한다. 경로는 코스 폴더 기준이며, 레벨·레슨 폴더는 실제 원본 매핑과 맞춘다. 아래 내용을 한 파일에서 읽을 수 있으면 된다. 내용에 맞게 소제목은 조정한다.

```markdown
# <레슨 ID> <레슨 제목> OUTLINE

## 준비 메모
- 사용한 자료·기존 Ji 의견과 원문 위치
- 참고한 교수법 자료와 대사 샘플의 파일·절 또는 구간
- 이미 배운 것·이번 설명·예문 수준·뒤로 넘길 내용 중 필요한 판단
- 원문으로 확인한 보완 사항과 Ji 결정이 필요한 사항

## 4MAT·CLEAR 적용 기획
- 레슨 성격과 이번 설명이 해결할 문제
- 핵심 개념 묶음, 사용할 예문·연결·비교의 근거와 아래 설명 위치
- 필요한 시각화 아이디어와 마지막에 다시 묶을 핵심 관계

## 설명 흐름
### Intro
### <소주제>
- 무엇을 어떻게 설명할지, 대화 상황과 근거, 다음 소주제와의 연결
### Closure
```

소주제 순서와 연결, 설명할 내용의 근거가 충분하면 완결된 대사 초안을 작성한다. Ji가 승인한 레슨 작업 범위 안에서 진행하며, 매 단계나 개별 Teaching Point마다 승인을 새로 요구하지 않는다. Ji의 방향 결정이 필요한 문제가 있으면 해당 부분을 확인한다.

## 4MAT·CLEAR 적용 기획

4MAT의 단위는 **동사 어간에 현재형과 말투를 붙여 발화로 만드는 전체 개념**이다. 모음 규칙마다 Why/What/How/What if를 반복하지 않는다.

| 부분 | 설명 기능과 구현 |
|---|---|
| Why + Calibrate | 앞 레슨까지 동사는 끝에서 모양이 바뀐다고 들었지만 직접 만들지는 않았다는 출발점을 확인한다. 사전에서 찾은 `먹다`를 그대로 말하면 상대와의 말투가 빠진다는 필요를 보여 준다. |
| What + Link | 영어의 “quiet cat”과 “the cat is quiet”를 `조용한 고양이` / `고양이가 조용해요`에 연결해 상태 동사 개념을 연다. 이어 식물의 어간·현재 자리·`아/어`·말투 비유로 전체 틀을 잡는다. 비유는 Ji의 설명 도구이며 표준 문법 용어라고 하지 않는다. |
| How + Envision | `먹다→먹→먹어→먹어요`를 기준 줄기로 보이게 설명한다. 마지막 모음과 받침을 확인하고 `ㅏ/ㅗ`, 그 외 모음, `ㅡ`, `하다`, `(스)ㅂ니다`를 조건별 사례로 순서 있게 적용한다. 각 묶음 뒤에는 두 화자의 짧은 대화로 실제 사용 맥락을 준다. 화면 배치는 BEATS에서 결정한다. |
| What if + Abstraction | 같은 어간을 친구에게 말할 때와 공손하게 말할 때, 말과 글의 격식이 다른 자리에서 쓸 때 비교한다. `공부하다`처럼 나눌 수 있는 동사와 `친절하다/좋아하다`처럼 같은 방식으로 나누면 안 되는 경우를 통해 범위를 확인한다. 연결어가 붙을 자리만 보여 주고 생산은 요구하지 않는다. |
| Repeat | 끝에서 “다를 떼어 어간, 모음으로 아/어, 관계로 요 또는 격식체”라는 흐름과 상태 동사의 동일한 활용만 짧게 회수한다. 새 활용표나 과제를 마무리에 추가하지 않는다. |

## 설명 흐름

### Intro

한국어 동사의 뼈대를 상기한다. 이번 목표는 단어장 형태를 실제 현재형 말로 바꾸는 것이다. 기본 현재형이 “I eat”과 문맥에 따라 “I'm eating”으로 옮겨질 수 있음을 간단히 보여 주되, `-고 있다`와의 상세 대조는 뒤로 둔다. 동작·상태 동사, 기본 `아/어`, `하다`, 격식체 순서로 길을 예고한다.

### 1. 동작 동사와 상태 동사

`공부하다`는 공부하는 동작, `조용하다`는 조용한 상태. `공부해요/조용해요`가 같은 끝을 갖는 이유를 설명한다. `조용한 고양이`는 형태 차이를 보여 주는 전체 표현으로만 들려주고 명사 앞 활용은 가르치지 않는다. `되다`의 여러 뜻과 `나다/내다`는 설명하지 않는다.

### 2. 사전형에서 어간으로, 현재형 틀로

`먹다`에서 `다`를 떼어 `먹`. 식물 비유에서 어간은 뜻의 중심, 현재형의 시제 자리는 빈 자리, `아/어`는 기본 맥락을 만드는 자리, 마지막 말투가 반말·요체를 만든다. `먹어/먹어요`, `살아/살아요`로 받침 뒤에도 순서가 같음을 보인다. `살아요`에 비해 `살거든요/살잖아요`는 추가 뉘앙스를 지닌다는 Ji의 원문 예시를 듣기 수준으로만 소개하고 만들게 하지 않는다. 비유를 실제 형태와 일치시켜 설명하고 “현재형은 반드시 지금 진행 중”이라고 말하지 않는다.

### 3. 마지막 모음이 ㅏ·ㅗ이면 아

받침 있는 `닫다→닫아요`, `놓다→놓아요`. 받침 없는 `가다→가요`, `보다→봐요`에서 소리가 겹치거나 합쳐지는 차이를 듣게 한다. 원문 `놓아요`와 일반 발화 축약형의 관계는 새 범위로 넓히지 않는다. `가요? / 네, 가요` 대화는 물음 전체를 만드는 법 대신 이미 배운 활용을 듣는 예시로 둔다.

### 4. 그 밖의 모음이면 어, 모음이 이어질 때의 모습

받침 있는 `먹다→먹어요`. `서다→서요`, `켜다→켜요`, `보내다→보내요`, `세다→세요`는 기본형에서 `어`가 소리상 겹쳐 보이지 않는 결과를 비교한다. `고치다→고쳐요`, `배우다→배워요`는 두 모음이 합쳐지는 예다. 대사에서 `보내요`와 `배워요`를 두 사람이 실제로 쓰는 상황에 놓되 어휘 뜻을 먼저 준다.

### 5. ㅡ와 하다

`바쁘다→바빠요`, `예쁘다→예뻐요`, `끄다→꺼요`로 `ㅡ`가 사라지고 앞 음절 모음 또는 기본 `어`가 나타나는 사례를 보여 준다. 모든 어휘에 적용되는 완전한 표를 약속하지 않는다. `하다→해요`, `공부하다→공부해요`, `조용하다→조용해요`. 선택된 `YT-1-5-1` Transcript 108줄의 `되다→돼요`는 형태만 짧게 덧붙인다. `공부하다`는 `공부를 해요`로도 말할 수 있지만 `친절하다`와 `좋아하다`를 똑같이 나누지 않는다고 설명한다. 조사 체계는 분석하지 않는다.

### 6. 앞을 살짝 보는 두 가지 길

`좋아하다→좋아해요`, `싫어하다→싫어해요`를 합성 동사의 예로 짧게 보여 주고 조합 규칙은 뒤로 둔다. `좋아해서`와 `좋아하고`는 연결 방식이 서로 다른 것을 보여 주는 한 쌍의 완성된 표현으로만 듣게 한다. 긴 문장 만들기를 요구하지 않는다.

### 7. 격식체 `(스)ㅂ니다`

일상 공손체 `요`와 발표·공지 같은 격식체의 용도를 구별한다. 어간에 받침이 없으면 `ㅂ니다`: `하다→합니다`, `보내다→보냅니다`, `세다→셉니다`, `쓰다→씁니다`, `고치다→고칩니다`. 받침이 있으면 `습니다`: `먹다→먹습니다`, `좋다→좋습니다`, `적다→적습니다`. `니다요`를 덧붙이지 않는다. 하나의 상황에서 공손한 `요`와 격식체가 모두 가능할 수 있음을 말하되 절대 비율을 만들지 않는다.

### Closure

식물 비유의 어간·현재 자리·기본 끝·말투를 회수하고 `먹어요/먹습니다`, `공부해요/합니다`, `조용해요`를 묶는다. 한 번에 익혀야 할 단위가 많다는 점을 인정하고 지금은 형태 선택의 기준을 잡았다고 분명히 한다. 다음 레슨 번호는 커리큘럼 시트 간 차이가 있어 대사에서 단정하지 않는다.

## 4MAT·CLEAR 적용 기획

핵심 묶음은 **상대에게 건네는 짧은 말에서도 말투를 유지하고, 마지막 음절에 따라 요/이요를 고르는 것**이다. BTS의 이름·어휘·응답 목적이 바뀌어도 같은 판단을 이어간다. 단어마다 별도의 네 단계 설명을 만들지 않는다.

| 기능 | 구현 위치와 설명 |
|---|---|
| Why | Intro에서 영어처럼 이름만 답하면 존댓말이 빠질 수 있다는 문제를 연다. §1에서 이름이 같아도 관계에 맞는 끝이 필요한 이유, §2~4에서 받침과 말하는 목적에 따른 선택·유지를 실제 예문으로 풀이한다. |
| What | §1에서 단어의 뜻과 상대에게 전달하는 말투를 구분하고, §2에서 요/이요의 형태 선택을 정리한다. |
| How | §1~2의 같은 BTS 사진에서 답을 고치는 과정과 마지막 음절을 확인하는 과정을 함께 보여준다. 새 어휘는 뜻을 먼저 제공한다. |
| What if | §1의 관계 변경, §2의 비티에스→방탄소년단·커피→책, §3~4의 답하기→되묻기를 비교한다. 끝소리가 바뀌면 형태가 바뀌고, 대화 목적만 바뀌면 말투 기준은 유지됨을 설명한다. |

- Calibrate·Link: 한글·받침과 앞 레슨의 말투에서 출발한다. 영어의 한 단어 답을 연결 고리로 사용하고, 긴 질문은 영어로 들려준다.
- Envision 아이디어: 같은 BTS 사진 아래 두 이름의 마지막 음절과 붙는 부분을 나란히 놓는다. 대사에는 이름과 끝소리를 읽어주는 설명을 완성하고, 구체적인 화면은 이후 BEATS에서 정한다.
- Abstraction·Repeat: 중간에는 끝소리 판단을 짧게 상기한다. Closure는 관계·받침·답하기와 되묻기를 한 원리로 다시 연결한다. 전체 요약을 별도 활동으로 늘리지 않는다.

## 설명 흐름

### Intro

앞 레슨에서 누구에게 말하는가에 따라 말투가 달라진다는 점을 불러온다. 영어의 짧은 답은 자연스럽지만 한국어에서는 짧게 말할 때도 존댓말을 놓칠 수 있다는 문제를 연다. 이번에는 이름만 답하기, 요/이요 선택, 짧게 되묻기로 이어진다고 안내한다. 질문은 영어로 주어 응답의 형태에 집중하게 한다.

### 1. 이름만 답할 때 무엇이 빠지는가

- 처음 만난 사람과 BTS 사진을 보는 상황을 유지한다. “Who are they?”에 영어로 “BTS”라고 답하는 것과 한국어로 비티에스라고만 답하는 것을 연결한다.
- 비티에스요로 고쳐 대화를 완성한다. 단어가 전달하는 대상은 같고, 요가 상대에게 맞는 공손한 말투를 남긴다는 이유를 풀이한다.
- 같은 사진을 반말을 쓰기로 한 가까운 친구와 본다면 이름만 짧게 말할 수 있음을 비교한다. 이름만 답하는 모든 상황을 무례함으로 묶지 않는다.
- 전환: 존댓말로 답할 때 붙일 형태가 항상 요로 보이는지, 같은 그룹의 한국어 이름으로 확인한다.

### 2. 같은 그룹의 이름을 바꾸면

- 같은 상대·사진·질문을 두고 이름만 방탄소년단으로 바꾼다. 스에는 받침이 없고 단에는 ㄴ 받침이 있음을 직접 읽어준다.
- 비티에스요와 방탄소년단이요를 만드는 과정을 풀이한다. 받침이 없으면 요, 있으면 이요라는 이번 짧은 응답의 기준으로 압축한다.
- 받침-sensitive는 받침에 따라 붙는 형태가 달라진다는 뜻이라고 쉬운 말로 풀어준다.
- 커피와 책의 뜻을 먼저 소개한다. 영어 질문 “What are you drinking?” / “What is that?”에 커피요 / 책이요로 답하는 두 사람의 대화를 구성하고 마지막 음절로 선택을 설명한다.
- 다른 단어로 넘어가도 처음 기준을 그대로 적용할 수 있음을 보여준다. 모든 동사나 문장에 요/이요를 기계적으로 붙인다는 규칙으로 넓히지 않는다.

### 3. 답을 주는 대신 확인하면

- 이거 = this one을 먼저 소개한다. 상대가 물건을 가리켰는데 어느 것인지 확인하는 “This one?”을 이거요?로 연결한다.
- 내일 = tomorrow를 소개하고 영어 질문 “Do you have time tomorrow?”의 날짜를 확인하는 내일이요?를 구성한다.
- 이제는 정보를 주는 답이 아니라 확인 질문이지만, 관계와 받침에 따라 끝을 고르는 판단은 그대로임을 풀이한다.
- 한국어 질문문 만드는 법이나 이다 활용을 새로 설명하지 않는다.

### 4. ‘누구?’와 ‘어떻게?’로 되물으면

- 누구 = who를 소개한다. 상대의 비티에스요를 못 들은 사람이 누구요?로 다시 묻고, 방탄소년단이요라는 답을 듣는 대화를 구성한다.
- 어떻게 = how를 소개한다. 상대가 영어로 다쳤다고 말한 뒤 어떻게요?로 경위를 묻는 상황을 연다. 두 단어 모두 끝에 받침이 없다는 점을 다시 적용한다.
- 질문 단어의 전체 체계는 후속 Questions 레슨에서 다룬다고 제목으로 안내한다. 짧은 질문을 무제한으로 만드는 규칙까지 확대하지 않는다.

### Closure

처음의 BTS 사진으로 돌아와 비티에스요 / 방탄소년단이요를 다시 묶는다. 단어가 바뀌면 끝소리를 다시 보고, 답에서 되묻기로 바뀌어도 상대에게 맞는 말투를 유지한다는 관계를 압축한다. 이거요? / 내일이요?를 짧게 회수하고 다음 Yes & No 레슨으로 연결한다.

# 1-18 Plain Form · Ji_draft 없는 레슨의 핵심 방향 유추와 적용 검토

- 작성일: 2026-10-22
- 상태: **회의용 적용 제안. Ji의 교수 의도 확정, 학습 범위 확정, OUTLINE·Draft 완성을 뜻하지 않는다.**
- 요청: 보관된 course_plan §3-1·§3-2의 공통 주제 탐색과 중복·단독 매핑 처리 원리를 응용해, 실제 1-18 자료에서 어디까지 방향을 유추할 수 있는지 검토한다.
- 관련 회의: [대사 quality control][meeting]. 확정된 레슨별 학습 범위는 [학습범위.md][scope]에서 관리한다. 이 문서는 범위 정본을 대신하지 않는다.

## 1. 먼저 볼 결론

**1-18은 Ji_draft가 없지만 Ji의 설명 근거가 없는 레슨은 아니다.** Amira Day 23 Part 2에 Ji의 실제 수업을 옮긴 Transcript가 있다. 학생의 질문도 남아 있다. 따라서 이 사례는 ‘외부 자료만으로 설계하는 경우’보다 Ji의 방향을 파악할 근거가 강하다. 녹화 변환본을 읽었으며 원본 영상을 재생해 대조한 것은 아니다.

이번 자료에서 가장 설득력 있게 도출되는 중심 방향은 다음과 같다.

> 학생이 Plain form을 사전형이나 아무에게나 쓰는 말투로 뭉뚱그리지 않도록, 글·혼잣말·상대에게 하는 말에서의 쓰임을 구분하게 한다. 그 바탕 위에서 action verb·descriptive verb·이다의 현재형과 과거형을 만들게 한다. 이후 문법에서도 다시 사용할 형태라는 의미를 짧게 연결한다.

이 문장은 **Agent의 종합 제안**이다. Ji가 과거에 이 문장과 같은 의도로 자료를 골랐다고 단정하지 않는다.

- 근거가 강한 부분: 혼잣말과 상대에게 말할 때의 구분, 현재형에서 action/descriptive의 차이, 이다와 과거형.
- 근거가 있지만 배치·깊이는 제안인 부분: 쓰기 용법을 도입에 넣는 것, 사전형 혼동을 핵심 문제로 여는 것, 인용형의 토대라는 의미를 예고하는 것.
- Ji의 방향 결정이 남은 부분: 기존 선택에 들어 있는 미래형·질문형을 이번 레슨에서 어디까지 다룰지. 추천은 기본 설명을 현재·과거 평서형에 집중하고 나머지는 후속 학습과 연결하는 것이다.

## 3. 예전 지침에서 무엇을 응용했는가

[보관 course_plan][archive] §3-1·§3-2는 참고 자료다. 예전 제작 단계·승인 절차·전체 원문 채택 규칙은 복원하지 않는다.

| 예전 지침의 판단 원리 | 이번에 응용한 방법 | 그대로 적용하면 생길 수 있는 문제 |
|---|---|---|
| 여러 자료의 공통 주제를 찾는다 | 같은 단어보다 ‘같은 학습 질문에 어떤 답을 주는가’를 비교한다. 공통 설명을 중심 후보로, 서로 다른 설명을 보완·대조·충돌 후보로 둔다 | 많이 나오는 문법을 모두 넣으면 미래형까지 자동 확대된다. 모든 자료의 교집합만 남기면 중요한 쓰임과 예문이 사라진다 |
| 중심 설명을 정한 뒤 레슨 경계를 본다 | 제목·brainstorm·실제 Ji 발화로 중심 가설을 세운 뒤, 현재 코스의 앞뒤 주제와 대조해 수정한다 | 처음부터 경계만 자르면 레슨의 이유가 사라지고, 중심만 믿으면 다른 레슨까지 흡수한다 |
| 중복 매핑 자료를 나눠 사용한다 | 같은 본문의 각 구간이 레슨별로 무슨 역할을 하는지 본다. 동일 구간도 한 레슨에서는 직접 설명, 다른 레슨에서는 복습·연결이 될 수 있다 | 같은 자료가 여러 레슨에 있다는 이유만으로 내용이 중복이라고 버리거나, 세 레슨 모두에 전체를 넣게 된다 |
| 단독 매핑 자료에서 관련 내용을 고른다 | 그 레슨에만 연결된 사실을 관련성의 단서로 쓰되, 파일 안의 각 구간이 중심 설명을 완성하는지 별도로 판단한다 | 단독 매핑을 ‘전부 가르치라는 뜻’으로 오해한다. 자료 하나에만 있는 좋은 대조를 공통 주제가 아니라는 이유로 버릴 수도 있다 |

응용의 순서는 **중심 가설 → 자료의 공통점·보완 관계 → 중복·단독 매핑에 따른 역할 검토 → 학생의 이해 순서 제안 → 반대 근거와 미정 사항 확인**이다. 기존 range_set을 처음부터 다시 만드는 절차가 아니다.

### 공통 주제를 판별하는 기준

1. **설명 대상이 같은가:** 예를 들어 ‘Plain form’이라는 제목이 같은지를 넘어 현재형의 action/descriptive 구분을 실제로 설명하는지 본다.
2. **학생의 질문에 어떻게 답하는가:** 활용표는 ‘어떻게 만드나’, 혼잣말 장면은 ‘언제 쓰나’, 상대를 바라보는 장면은 ‘언제 반말이 되나’에 답한다. 서로 다른 주제가 아니라 하나의 이해를 완성하는 관계일 수 있다.
3. **자료를 함께 읽었을 때 설명이 완성되는가:** 공통으로 확인되는 규칙에 한 자료의 좋은 비교를 붙일 수 있다. 반면 주장이나 전제가 다르면 충돌을 기록한다.
4. **현재 레슨에서 필요한가:** 여러 자료가 설명해도 현재 학생에게 필요하지 않거나 후속 학습을 크게 끌어와야 하면 중심에서 내린다.

빈도는 중심 후보를 찾는 단서다. 빈도 자체가 정확성·Ji의 강조점·포함 승인을 증명하지 않는다.

## 5. 중복 매핑과 단독 매핑의 실제 적용

### 5-1. 중복 매핑: Amira Day 23

DMS-0042·0043·0087·0088은 각각 같은 파일을 **1-18 Plain Form, 8-8 아/어버리다, 10-1 Quoting Form #1**에 연결한다. 각 파일의 세 사본은 Ref_No를 제외하면 본문이 같다.

| 원문 구간 | 1-18에서의 역할 제안 | 다른 레슨과의 관계 |
|---|---|---|
| 통합본 48~71줄, Part 1 193줄의 아/어 버리다 설명 | 이번 직접 설명에서 제외 | 8-8의 주제. 같은 수업 안에 있다는 이유로 가져오지 않는다 |
| 통합본 73~95줄, Part 2 74~82줄 중 Plain form 쓰임·현재·과거 설명 | 중심 설명과 설명 순서의 근거 | 10-1에서는 이미 배운 형태를 떠올리는 연결로 재활용할 수 있다 |
| 통합본 118~120줄, Part 2 78·82·86줄의 인용형 연결 | 후속 학습의 토대라는 짧은 의미만 살릴 후보 | 인용형의 상세 설명은 10-1과 관계됨. 해당 레슨의 전체 범위를 이번에 새로 판정한 것은 아님 |
| Part 1의 자유 대화·학습 상담 | 1-18 직접 설명 근거 없음 | Part 1이 같은 수업이라는 사실만으로 Plain form의 근거가 되지 않는다 |
| Part 2 88줄 이후의 다음 연습·일정 상담 | 이번 대사에서 사용하지 않을 내용 | 수업 운영 대화이며 Plain form의 설명 흐름이 아님 |

**응용 판단:** 중복 매핑은 ‘어느 레슨이 이 파일을 소유하는가’의 문제가 아니다. 원문의 각 대목이 이번 레슨에서 어떤 역할을 하는지 판단하는 단서다. 형식적 중복 제거보다 설명 역할의 차이가 중요하다.

### 5-2. 중복 매핑: HTSK Lesson 5

DMS-0193은 같은 본문을 **1-5·1-6·1-12·1-13·1-18·2-4·4-4·4-5**에 연결한다. 여덟 사본의 본문 동일성을 확인했다.

- 1-18의 현재형 비교에는 215~235줄의 action verb, 479~487줄의 descriptive verb 설명이 관련된다.
- 66~162줄의 대명사·호칭, 237~395줄의 긴 과거형 기초, 402~423줄의 겠다, 573~642줄의 있다 용법을 이번에 전부 재교육할 이유는 없다.
- 현행 선택은 215~222·442~457줄이다. 선택 밖 224~235·479~487줄은 이번 검토에서 비교 근거로 읽었으며, 새 발췌 승인으로 처리하지 않는다. 이미 선택된 YT·Amira에서 같은 규칙을 설명할 수 있는지도 먼저 본다.
- 과거형을 설명할 필요가 있어도 ‘과거형 전체를 처음부터 가르치기’와 ‘배운 과거 어간에 다를 붙여 적용하기’는 설명량이 다르다. 실제 선행 대사에서 배운 범위를 확인한 후 결정해야 한다.

### 5-3. 단독 매핑: Go Billy 5개

현행 YouTube index에서 해당 다섯 파일은 각각 1-18에만 매핑되어 있다. 중복자료 목록에 없다는 사실만으로 판단하지 않고 현행 index에서 동일 파일명의 연결을 확인했다.

| 자료 | 이번 레슨에서 맡길 역할 | 자동으로 따라오지 않는 내용 |
|---|---|---|
| YT-1 Abridged | 활용 규칙과 쓰임의 전체 연결, announcement·혼잣말 설명 비교 | 미래형·진행형·인용형 전체 |
| YT-2 Beginner #86 | action/descriptive의 간단한 대조와 형태 적용 | 마지막 긴 대화의 미학습 문법·어휘 |
| YT-3 Full Lessons 17 | 쓰임부터 여는 도입 방식, 부정문에서의 적용 보조 | 모든 시제 예문, 원문 예문 전체 |

**응용 판단:** YT-5는 다른 자료와 ‘활용 규칙’이 많이 겹치지 않아도 매우 유용하다. 그 차이가 바로 ‘언제 어떻게 써야 하는가’를 완성한다. 공통 주제만 남기는 방식이었다면 이 자료의 가치를 놓칠 수 있다.

## 6. 원문의 설명 흐름을 어떻게 응용할 것인가

Amira Part 2는 **용도와 중요성 → 쓰임 사례 → 학생의 인용형 질문 → 활용표 → 쓰임 재질문 → 질문·명령·인용형 예고**로 진행된다. 여기서 쓰임을 먼저 설명하고 학생의 혼동에 답하는 방식은 살릴 가치가 있다. 다만 현재 학생에게는 Amira의 기존 인용형 노출·미래형 지식·실시간 질문이 없으므로 순서를 그대로 복사하지 않는다.

YT-1·YT-2·YT-4는 활용부터 시작하고, YT-3은 사용 상황부터 시작한다. YT-5는 같은 말을 자신에게 하는 경우와 상대에게 하는 경우로 비교한다. 이 차이를 바탕으로 다음 흐름을 제안한다.

| 학생에게 생기는 질문 | 제안하는 설명 | 이 위치에 두는 이유 |
|---|---|---|
| “왜 배고프다·맛있다처럼 요 없이 말하지?” | 짧은 혼잣말 장면과 상대에게 말하는 장면을 비교한다. 모든 요 없는 말이 아무에게나 써도 되는 표현은 아니라는 문제를 연다 | Ji brainstorm의 쓰임 구분과 YT-5의 상황 비교를 결합한다 |
| “그럼 어디서 쓰는 형태야?” | 혼잣말, 친한 상대에게 알림·이야기를 여는 말, 글에서 보는 용법을 구분한다. 글은 짧은 인식 사례로 설명한다 | Amira의 ‘글에만 쓰나?’ 질문에 미리 답하고 무작정 말투 목록을 외우게 하지 않는다 |
| “끝이 다면 사전형을 그대로 쓰면 돼?” | action verb 하다→한다와 descriptive 좋다→좋다를 대조한다. 현재형 규칙, ㄹ 어간, 이다를 이어 설명한다 | 겉모양의 유사성에서 생기는 혼동을 규칙의 필요성으로 연결한다 |
| “과거 일에도 같은 방식이야?” | 실제 선행 학습이 확인되면 했어요→했다·먹었어요→먹었다처럼 과거 어간과 끝을 분리해 적용한다 | 이미 배운 활용을 반복 강의하지 않고 이번에 달라지는 부분에 집중한다 |
| “형태를 만들었으면 언제 골라 쓰면 되지?” | 같은 뜻을 혼잣말과 상대에게 하는 말로 다시 비교한다. 문장 끝과 쓰임을 묶어 되짚고 이후 문법에서도 다시 쓸 것임을 짧게 알린다 | 형태 정답만 맞히고 쓰임은 놓치는 결과를 막는다 |

이 표는 **정식 OUTLINE이 아닌 응용 설계안**이다. 예문은 선택 자료에서 출처를 추적하고, 단어 뜻·선행 문법을 확인한 뒤 최종 대사에서 확정한다. CLEAR·4MAT 주석은 이 설계가 실제 대사에서 구현될 때 해당 위치에 붙인다. 표를 채웠다는 이유로 설명 품질이 검증된 것은 아니다.

## 7. 기존 구간과 설명에서 발견한 확인 과제

### 선택 구간의 정확성과 의미 범위

| 위치 | 관찰 | 다음 제작 때 처리할 일 |
|---|---|---|
| range_set 479행, YT-4 | TP 24~33줄은 현재·과거·미래를 포함하지만 대응 Transcript 58줄은 현재형만 설명한다. 과거는 66줄, 미래는 68줄에 있다 | 먼저 이번에 쓸 설명 깊이를 정하고 대응 범위를 바로잡는다. 지금 미래형을 자동 추가하지 않는다 |

### 용어·설명 깊이

- Amira는 Plain form을 Formal Low로 소개하고, YT-1·YT-4는 활용 형태와 speech level을 구분한다. 같은 말을 다른 수준에서 정의하는지 먼저 검토해야 한다. ‘모두 같은 설명’이라고 합치지 않는다. 특히 앞선 1-2의 용어 사용과 맞춰야 한다.
- 자료의 ‘항상’, ‘절대’, ‘only’ 같은 표현은 최종 문법 검증 없이 확대하지 않는다. 글에는 오직 Plain form만 가능하다는 설명, 시선을 피하면 혼잣말이 언제나 괜찮다는 설명 등이 해당한다. YT-5 114줄은 상황에 따라 혼잣말 자체도 실례가 될 수 있다고 덧붙인다.
- Amira의 시오 명령형 분류와 YT의 해라체 설명, 미래 질문형을 action/descriptive로 나누는 설명은 별도 정확성 검토가 필요하다. 이번 중심 방향을 잡는 데 필수적인 설명으로 편입하지 않는다.
- 6-6 brainstorm에는 인용형 상세를 Level 8에서 다룬다는 옛 안내가 있지만 현재 제목상 Quoting Form #1은 10-1이다. 실제 후속 안내에서는 현재 커리큘럼을 확인해야 한다.
- 학습범위.md에 1-18과 필요한 모든 앞 레슨의 실제 학습 완료 근거가 없다. 1-5·1-6·1-10·1-12·1-16·1-17은 관련 계획으로 확인했으며, 학생이 모두 배웠다는 증거로 처리하지 않았다.

이번 검토는 자료의 설명 관계와 근거 상태를 확인한 것이다. 모든 문법 주장과 문화적 일반화를 외부 원전까지 대조한 최종 정확성 검수는 아니다.

## 8. Sol 6.1에 맡길 범위와 다음 검토 방식

[OpenAI 공식 모델 안내][model]는 GPT-6.1 Sol을 복잡한 전문 작업에 사용할 수 있는 모델로 설명하지만, Ji의 교수 의도 유추 정확도를 보증하는 근거는 아니다. 이 사례의 판단은 실제 읽은 자료에 근거하며 모델별 비교 실험은 하지 않았다.

이번처럼 근거가 있으면 Agent에게 **중심 방향 제안, 자료별 역할 배정, 설명 순서 제안, 범위 충돌 발견**까지 맡길 수 있다. 자료에 남지 않은 Ji의 정확한 선택 동기와 우선순위를 사실로 복원할 수는 없다. 특히 이번 사례에는 Ji의 실제 발화가 있어, Ji 자료가 전혀 없는 레슨에 동일한 결과를 보장할 수 없다.

다른 레슨에도 응용할 때 Agent가 기존 OUTLINE 준비 메모에 먼저 남길 내용은 다음 다섯 가지면 된다.

1. 학생이 이번 레슨에서 이해하거나 구분해야 할 핵심.
2. 그 판단을 뒷받침하는 커리큘럼·선택 구간·실제 설명.
3. 각 자료가 맡는 역할: 중심 설명, 이해를 돕는 비교, 조건·예외, 후속 연결.
4. 다른 방향이 가능하다는 반대 근거와 Agent의 추천 이유.
5. Ji가 판단해야 할 핵심 차이만 질문으로 남기기.

Ji가 레슨마다 선택 이유를 처음부터 작성할 필요는 없다. Agent가 근거 있는 제안을 먼저 만들고 Ji가 방향이 어긋난 부분을 고치는 방식으로 부담을 줄인다. 1-18에서는 우선 **‘쓰임 구분 + 현재·과거 평서형을 중심으로, 미래형·질문형의 상세는 뒤로 연결한다’는 강조점**을 검토하면 된다.

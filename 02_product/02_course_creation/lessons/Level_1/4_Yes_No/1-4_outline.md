## 4MAT·CLEAR 적용 기획

4MAT은 `yes/no`를 영어 단어와 일대일로 옮기면 대화에서 놓치는 신호가 생긴다는 **한 묶음의 핵심 개념**에 적용한다. 각 표현마다 네 단계를 다시 시작하지 않는다.

| 부분 | 설명 기능과 구현 |
|---|---|
| Why + Calibrate | 앞의 짧은 응답과 말투를 상기시키고, 친구와 처음 만난 사람에게 같은 “yes”를 말할지 묻는다. 영어의 “yes/no”만 떠올리는 출발점을 확인한다. |
| What + Link | `네/예`, `응/어`, `아니요/아니`를 상대와의 관계에 연결한다. `네`는 yes뿐 아니라 “I'm listening”, “okay”, “pardon?”의 신호로 설명한다. `아니`는 no와 문장 앞의 감정 신호를 구별한다. |
| How + Envision | 하나의 짧은 대화가 호명, 설명 듣기, 되묻기로 이어지는 흐름을 상상하게 한다. 대사에서는 상대·상황을 말로 제시하고 `네`, `네, 네`, `네?`가 소리와 위치에 따라 달라지는 점을 보여 준다. 화면 배치는 BEATS에서 결정한다. |
| What if + Abstraction | 부정 질문 “Aren't you hungry?”에 `네/아니요`가 무엇에 동의·반대하는지 영어로 풀어 확인한다. 기억할 한 줄은 “Listen to what you're agreeing with.” 한국어 부정 질문 만드는 법은 요구하지 않는다. |
| Repeat | 마지막에 관계에 따른 형태, `네`의 듣기 신호, `아니`의 감정, 부정 질문의 동의 대상만 짧게 되짚는다. 새 활동을 추가하지 않는다. |

## 설명 흐름

### Intro

1-3에서 한 단어 답에도 말투가 남는다는 점을 연결한다. 이번에는 yes/no를 말할 상대와 상황이 뜻을 바꾼다는 문제를 연다. 먼저 기본 형태, 다음에 `네`와 `아니`의 대화 기능, 마지막에 부정 질문 순서로 안내한다.

### 1. 기본 형태와 말투

처음 만난 사람과 친한 친구의 같은 질문을 나란히 둔다. 공손한 긍정은 `네`, 조금 더 격식 있는 `예`; 친구 사이의 긍정은 `응/어`. 공손한 부정 `아니요`, 친구 사이의 부정 `아니`. `네`는 이미 공손하므로 `네요`로 만들지 않는다. `아니요`와 `아니에요`는 다른 것이며 후자는 1-11에서 배운다고 짧게 선을 긋는다. `네`가 빠른 말에서 영어 귀에 `데`처럼 들릴 수 있지만 `네`라는 글자와 실제 소리에 집중시키고 발음 기관 설명은 하지 않는다.

### 2. `네`가 대화 안에서 하는 일

상대가 이름을 부르면 `네?` 또는 `네`; 상대가 말할 때 `네, 네`로 듣고 있음을 보임; 부탁을 들으면 `네`로 알겠음을 표현; 전화를 받거나 끝내며 `네`; 못 들었거나 놀라면 올라가는 `네?`. 모두 “yes”라고 번역하면 놓치는 대화 기능을 영어 상황으로 구분한다. 짧은 `네` 자체가 틀린 답이라고 말하지 않는다. 자세한 질문에 관여해 답하고 싶을 때는 내용을 덧붙일 수 있다는 정도만 언급한다.

### 3. `아니`의 두 얼굴

먼저 공손한 거절 `아니요`, 친구 사이 `아니`를 확인한다. 이어 `아니`가 놀람·의심·답답함을 보이거나, 설명·변명으로 넘어가거나, 상대의 주의를 끌 때 문장 앞에 올 수 있음을 보여 준다. 영어로 상황을 설명하고 한국어는 `아니, 이거?`, `아니, 지금?`, `아니, 그게...`, `아니, 잠깐.` 같은 짧은 조각만 사용한다. 뒤따르는 말의 뜻을 먼저 주고 문장 구조를 해석시키지 않는다. 특정 감정마다 고정된 번역을 붙이지 않는다.

### 4. 부정 질문에서 무엇에 대답하는가

영어 질문 “Aren't you hungry?”를 사용한다. 한국어 질문문은 아직 만들지 않는다. “not hungry”라는 내용에 동의하면 `네` = “I'm not hungry.” 반대하면 `아니요` = “I am hungry.” 첫 답 뒤에 영어로 의도를 확인해 오해 가능성을 낮춘다. `아니` 감정 용법과 달리 여기서는 질문 내용에 대한 긍정·부정이다.

### Closure

기본 형태, `네`의 듣기/확인 신호, `아니`의 말문 열기, 부정 질문의 동의 대상 순서로 묶는다. 다음 레슨을 특정해 예고하지 않는다. 커리큘럼 두 시트의 순서 차이는 학습 범위 기록에 남긴다.

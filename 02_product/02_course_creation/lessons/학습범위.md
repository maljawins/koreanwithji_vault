# 레슨별 학습 범위 기록

작성·갱신 기준은 [학습 범위 지시서](../instructions/02_학습범위.md#3-누적-학습-범위-기록)를 따른다. 레슨 작업마다 같은 파일에 항목을 추가한다. 기록되지 않은 레슨의 범위는 미정이다. 앞 레슨의 계획을 실제 학습 완료로 간주하지 않는다.

## 1-3 One word response

- 근거: [기존 1-3 OUTLINE](Level_1/3_One_word_response/1-3_outline.md)의 `자료와 Ji의 결정`·`이미 배운 것과 이번 범위`. 기존 산출물의 판단을 옮겼으며 이번에 레슨을 새로 작성하거나 Ji 검수를 대신하지 않았다.
- Ji 의견: [range_set_review.xlsx](../01_lesson_spec/01_range_set/range_set_review.xlsx)의 `Sheet1`, `Ji-1-3-1` 행 `Ji feedback`. 미학습 이다를 쓰는 질문은 영어로 제시한다.

| 항목 | 기록 |
|---|---|
| NEW | 짧은 명사 응답의 요/이요 선택. 받침 유무와 형태를 연결하고 이거요?·내일이요?·누구요?·어떻게요?로 짧게 되묻는 경우를 설명한다. 모든 단어·동사에 기계적으로 붙이는 규칙으로 넓히지 않는다. |
| PREREQ | 기존 OUTLINE이 확인한 1-1·1-2 샘플 기준으로 한글·받침, 관계에 따른 반말·존댓말, 일상적인 요 말투의 큰 그림. 동사 활용이나 이다 문장 만들기를 익혔다고 전제하지 않는다. |
| BUDGET | 질문은 Ji 의견에 따라 영어로 제시하고 학습할 짧은 응답은 한국어로 쓴다. 비티에스요·방탄소년단이요부터 설명한 뒤 같은 기준을 다른 응답에 적용한다. 이거·내일·누구·어떻게·커피·책은 사용 전에 뜻을 준다. |
| OUT_OF_SCOPE | 이다와 예요/이에요의 본격 활용은 후속 `A is B - To be 이다`, 질문문·질문 단어의 체계는 후속 `Questions`에서 다룬다. 지시어 체계·축약형·‘you’ 대체 표현·높임말과 겸양말 활용으로 확대하지 않는다. 후속 번호는 새 레슨 작업 시 현재 커리큘럼에서 다시 확인한다. |

- 확인 상태: 기존 산출물의 범위 기록을 이관했다. 새로운 Ji 검수·낭독 검수 완료를 뜻하지 않는다. 다음 1-3 수정 때 현재 발췌·앞 레슨 산출물과 재대조한다.

## 1-4 Yes & No

- 근거: [커리큘럼](../00_curriculum_and_index/Korean%20Course%20Curriculum%20Map_Final_V7.xlsx) `Curriculum Map!A21:E21`, [range_set_review.xlsx](../01_lesson_spec/01_range_set/range_set_review.xlsx) `Sheet1!81:97`, [기존 발췌](../01_lesson_spec/02_topic_raw/Level_1/4_Yes_No/1-4_topic_raw.md), `Ji-1-4-1` 원문 1~152줄과 `YT-1-4-1` 등 선택된 Transcript. 앞 레슨은 이 파일의 1-3 기록과 [1-3 대사 초안](Level_1/3_One_word_response/1-3_draft.md)을 대조했다.
- Ji 의견: `Sheet1!K92`. `아니`의 모든 선택 Teaching Point를 쓰되 상황 예문은 최대한 기본 문장으로 바꾸고, 학생에게 문장 문법보다 `아니`의 느낌을 들으라고 안내한다.

| 항목 | 기록 |
|---|---|
| NEW | 관계에 따른 `네/예`, `응/어`, `아니요/아니` 선택. `네`의 긍정 답변 외 듣고 있음·호명 응답·통화·알겠다는 표시·`네?`로 되묻는 용법. `아니`가 단순 부정 외 놀람·답답함·설명 또는 말문을 여는 느낌을 싣는 용법. 부정 질문에는 질문의 부정 내용에 동의하는지 반대하는지로 답을 해석한다. 빠른 발화의 `네`가 영어 귀에 `데`처럼 들릴 수 있다는 점을 짧게 안내한다. |
| PREREQ | 1-2 샘플과 1-3 범위·대사에 나온 상대와의 관계에 따른 반말·존댓말, 짧은 응답에도 말투를 남긴다는 개념. 1-3은 아직 Ji의 최종 검수 전인 샘플이므로 실제 수강 완료로 단정하지 않는다. 문장 만들기, 부정문 구성, `이다` 활용은 전제하지 않는다. |
| BUDGET | 한국어는 배운 짧은 말과 이번에 소개하는 `네/예/응/어/아니요/아니`를 중심으로 한다. 긴 상황과 부정 질문은 영어로 먼저 제시한다. `아니, 이거?`, `아니, 지금?`, `아니, 그게...` 같은 짧은 말은 뜻과 상황을 준 뒤 `아니`의 말맛을 듣는 예문으로만 쓴다. 뒤 문장의 문법을 분석하거나 만들게 하지 않는다. `네?`의 올라가는 소리도 듣는 수준으로 다룬다. |
| OUT_OF_SCOPE | `아니에요`와 `아니다`의 활용은 커리큘럼의 1-11, `이다`는 1-10. 부정 질문문 구성, 전화 인사 표현의 활용, 감탄사 `아니`의 모든 화용 조건과 어원·발음 기관 설명은 이번에 가르치지 않는다. `아니오`는 Amira 자료에 있으나 이번 학생 대사의 기준은 Ji Draft의 `아니요`로 둔다. |

- 확인 상태·미정 사항: 범위는 1-4 샘플 작성을 위한 제안이며 Ji의 대사 검수·낭독 전이다. `아니오`와 `아니요`의 자료 표기 차이, 부정 질문 설명의 난이도는 Ji 검수 항목이다. 원문과 엑셀은 수정하지 않았다.

## 1-5 Verb 101 & Present Tense Conjugation

- 근거: [커리큘럼](../00_curriculum_and_index/Korean%20Course%20Curriculum%20Map_Final_V7.xlsx) `Curriculum Map!A22:E22`와 `레벨1순서update!A9:E9`, [range_set_review.xlsx](../01_lesson_spec/01_range_set/range_set_review.xlsx) `Sheet1!98:139`, [기존 발췌](../01_lesson_spec/02_topic_raw/Level_1/5_Verb_101_Present_Tense_Conjugation/1-5_topic_raw.md), `Ji-1-5-1` 1~45줄, `Ji-1-5-2` 1~472줄과 선택된 YouTube Transcript. 앞 레슨은 이 파일의 1-3·1-4 기록과 실제 1-3 대사 초안을 대조했다.
- Ji 의견: `Sheet1!K98:K99`. `Ji-1-5-1`의 48~105줄 `나다/내다`는 제외하고 2-3에서 다룬다. `Ji-1-5-2`의 설명 깊이는 유지하되 333~353줄의 연결어는 간략히 소개한다.

| 항목 | 기록 |
|---|---|
| NEW | 한국어의 동작 동사·상태 동사를 같은 활용 틀에서 보고, 사전형에서 `다`를 떼어 어간을 찾는다. 기본 현재형이 현재 동작과 평소 습관에 쓰이는 맥락을 비교한다. Ji의 식물 비유로 어간·현재 시제 자리·기본 맥락을 만드는 `아/어`·말투를 연결하고, 다른 끝이 뉘앙스를 더할 수 있음을 듣기 수준으로 소개한다. 어간의 마지막 모음을 보고 `아/어`를 고르고, 받침이 있을 때 더하기와 모음이 이어질 때의 줄어듦을 다룬다: `ㅏ/ㅗ`, `ㅓ/ㅕ/ㅐ/ㅔ`, `ㅣ/ㅜ`, `ㅡ`. `하다→해요`, `되다→돼요`를 제시하고, 동작 명사+하다의 분리 가능성과 상태 동사·합성 동사의 제한을 설명한다. `좋아하다/싫어하다`와 연결어 `아/어서`, `-고`는 구조를 알아보는 정도로 소개한다. 격식체 `(스)ㅂ니다`를 받침에 따라 만들고 일상 `요`체와 쓰임을 대조한다. |
| PREREQ | 1-1의 동사가 문장 끝에서 형태를 바꾼다는 큰 그림과 식물 비유, 1-2의 반말·존댓말·격식체 개념, 1-3의 짧은 응답 말투, 1-4 샘플의 `네/아니요` 사용. 앞 레슨 샘플은 Ji 최종 검수 전이며, `이다/아니다`의 선행 학습은 전제하지 않는다. |
| BUDGET | 어휘는 뜻을 먼저 주고 새 형태는 해당 규칙을 설명한 뒤 사용한다. 질문문·조사·연결어가 들어간 원문 예문은 영어로 상황과 전체 뜻을 주고 이번 목표인 동사 끝만 보게 한다. 2인 대화는 간단한 `공부해요?` / `네, 공부해요`처럼 이미 제시한 형태를 반복한다. 물음의 완전한 문장 규칙은 요구하지 않는다. `하다` 분리 예에서는 `를/을`을 붙인 완성 형태를 제시하되 조사 선택 규칙을 가르치지 않는다. |
| OUT_OF_SCOPE | `나다/내다`는 2-3. `이다/아니다` 활용은 각각 1-10·1-11. 진행형 `-고 있다`, 불규칙 활용 전체, 과거·미래 시제, 조사 체계, 합성 동사 조합 규칙, 연결어로 긴 문장 만들기는 후속 레슨에서 다룬다. `되다`의 여러 뜻·능동/피동 설명은 `Ji-1-5-1`에 제목 메모만 있고 본문 설명이 없어 이번에는 가르치지 않는다. |

- 확인 상태·미정 사항: 샘플 범위이며 Ji의 대사 검수·낭독 전이다. 커리큘럼 `Curriculum Map`은 1-5를 1-4 다음에 놓지만 `레벨1순서update`는 1-10·1-11을 먼저 놓는다. 양쪽 모두 보존하고 이번 샘플에서는 어느 순서에서도 성립하도록 `이다/아니다`를 전제로 쓰지 않았다. 최종 코스 순서는 Ji 결정이 필요하다.

## 1-18 Plain Form

- 상태: **샘플 v1 제작 범위. Ji의 최종 검수 전.** 2026-10-22 Ji의 ‘고안한 방식으로 1-18 샘플 OUTLINE과 Draft 작성’ 요청에 따라 기록했다.
- 근거: [적용 검토](Level_1/18_Plain_Form/1-18_approach_review.md)의 현행 커리큘럼·range_set·원문 대조. 구체적인 자료 역할과 설명 순서는 [OUTLINE](Level_1/18_Plain_Form/1-18_outline.md), 실제 대사와 적용 예문의 출처는 [Draft](Level_1/18_Plain_Form/1-18_draft.md)에 둔다.

| 항목 | 기록 |
|---|---|
| NEW | Plain form 평서형의 혼잣말·친한 상대에게 하는 알림·이야기를 여는 상승 억양·일반 서술의 쓰임 구분. 현재 action verb ㄴ다/는다와 ㄹ 어간, descriptive verb 다, 명사+이다 및 모음 뒤 가능한 이 생략. 과거 어간+다와 명사 이었다/였다. 사전형·평소 반말과의 차이, 문맥에 맞는 나의 사용. |
| PREREQ | 1-2 예시에서 speech level과 Formal Low 소개를 확인했다. 어간·action/descriptive는 1-5 기존 대사·범위에 있지만 최종 검수 전이다. 과거 활용·이다·대명사·질문·명령의 선행 위치는 커리큘럼 1-6·1-10·1-12·1-14·1-17에서 확인했으며 실제 수강 완료로 간주하지 않는다. 샘플 안에서 어간·범주·과거 어간을 짧게 풀고 예문 뜻을 제공한다. |
| BUDGET | 상황 설명은 영어. 배고프다·맛있다·춥다·가다·먹다·하다·살다·놀다·멀다·공부하다·피곤하다·이다·만나다의 필요한 뜻과 형태를 본문에서 설명한다. 나 간다, 맛있어요?, 잘 가, 어제 친구를 만났다, 같이 커피 마셨어는 상황과 뜻을 함께 준다. 상승 억양 사례는 과거형을 가르친 뒤 배치한다. 예문 속 조사·같이·어제는 문장 전체 뜻으로 지원하며 별도 문법 확장을 요구하지 않는다. |
| OUT_OF_SCOPE | 미래형 겠다·ㄹ/을 거다, 진행형, 지/나/가/더라 질문형 상세, 해라체의 전체 문장 유형, 부정 활용의 상세, 인용형의 실제 조립. 미래 관련 4-4·4-5, 질문 관련 1-19·1-20, 인용·생각 관련 6-6·10-1은 현재 커리큘럼의 관련 후속 주제다. 이번 대사에서는 후속 레슨 번호나 옛 ‘다음 수업’ 안내를 말하지 않는다. |

- 구간·승인 상태: 기존 range_set 470~493행의 Ji 검토 칸은 비어 있다. 샘플 요청을 엑셀의 일괄 승인으로 바꾸지 않았다. 미래·질문 상세의 생략은 이 접근법을 시험하는 샘플 구성 선택이며, 기존 사용 구간·Ji 의견·원본은 변경하지 않았다.
- 최종 제작 전 확인: 실제 선행 대사에서 사용 어휘와 형태가 설명됐는지 대조하고, 이번 깊이·말투·억양을 Ji가 검토한다.

Lesson 190: ~(으)나 마나: To be Pointless

Introduction

In this lesson, you will continue to learn about ~(으)나 by looking at another way that it can be used. In this lesson, you will see it used with 말다 to create 하나 마나. Let’s get started.

~(으)나 마나: To be Pointless

In [Lesson 167](https://www.howtostudykorean.com/unit-7/lessons-167-175/lesson-167/), you saw a quick review of the verb 말다 and from [Lesson 167](https://www.howtostudykorean.com/unit-7/lessons-167-175/lesson-167/) to [Lesson 169](https://www.howtostudykorean.com/unit-7/lessons-167-175/lesson-169/), you saw a variety of ways that 말다 is used. For example:

[Lesson 167](https://www.howtostudykorean.com/unit-7/lessons-167-175/lesson-167/): ~ㄹ/을 까 말까
[Lesson 168](https://www.howtostudykorean.com/unit-7/lessons-167-175/lesson-168/): ~거나 말거나
[Lesson 169](https://www.howtostudykorean.com/unit-7/lessons-167-175/lesson-169/): ~ㄹ/을락 말락

You can see that 말다 is often used with certain grammatical principles, where something is attached to a verb, and then followed by 말다 with that same grammatical principle attached. You can also attach ~(으)나 to a verb and then follow that with 말다 + ~(으)나. The resulting grammatical principle looks like this:

~(으)나 마나

In the past two lessons, you saw different ways that ~(으)나 can be used. This usage is specifically the one that was introduced in [Lesson 189](https://www.howtostudykorean.com/unit-8/lessons-184-191/lesson-189/). In this meaning, ~(으)나 indicates that the result will be the same regardless of which option occurs.

~(으)나 마나 indicates the idea that doing something is pointless or unnecessary because the result is obvious. Here is a simple example sentence:

Play[그 얘기는 하나 마나 다 아는 이야기예요](https://www.howtostudykorean.com/wp-content/uploads/2025/11/Lesson190s01.mp3)
= That story is obvious, there is no point even saying it

Here, the speaker is using ~(으)나 마나 to express that the action in the first clause is pointless or unnecessary because the outcome in the second clause is already obvious, unavoidable, or unaffected. Below are many more examples:

Play[이미 망가진 기계는 기증하나 마나 누구도 쓰질 못해](https://www.howtostudykorean.com/wp-content/uploads/2025/11/Lesson190s02.mp3)
= A broken machine, whether you donate it or not, no one can use it anyway

Play[이 전쟁에서는 우리가 항복하나 마나 결과는 똑같아요](https://www.howtostudykorean.com/wp-content/uploads/2025/11/Lesson190s03.mp3)
= In this war, whether we surrender or not, the result will be the same

Play[이 시는 의미를 너무 함축해서 읽으나 마나 이해 못 해요](https://www.howtostudykorean.com/wp-content/uploads/2025/11/Lesson190s04.mp3)
= This poem is so full of implications that it’s impossible to understand even if you read it

Play[이런 가파른 오르막에서는 천천히 가나 마나 금방 지치게 돼요](https://www.howtostudykorean.com/wp-content/uploads/2025/11/Lesson190s05.mp3)
= On a steep uphill like this, whether you go slowly or not, you’ll get tired quickly anyway

Play[이 내리막길에서는 브레이크를 밟으나 마나 속도를 줄일 수가 없어요](https://www.howtostudykorean.com/wp-content/uploads/2025/11/Lesson190s06.mp3)
= On this downhill road, hitting the brakes is useless, you can’t slow down anyway

Play[이 프로젝트는 교육 혁신의 일환으로 추진되는 거라서 성공하나 마나 중요한 의미가 있어요](https://www.howtostudykorean.com/wp-content/uploads/2025/11/Lesson190s07.mp3)
= This project is part of educational innovation, so whether it succeeds or not, it’s meaningful

~(으)나 마나이다

It is also possible to use ~(으)나 마나 at the end of a sentence and predicate it by attaching 이다 to it. This is very conversational, as it requires the listener to assume that the situation given in the first clause is pointless. For example:

Play[그 학생한테 부탁하나 마나야](https://www.howtostudykorean.com/wp-content/uploads/2025/11/Lesson190s08.mp3)
= There’s no point asking that student for a favor

In practice, the speaker would likely follow up this simple sentence by providing the context, but they wouldn’t have to as ~(으)나 마나 technically provides that. For example:

Play[그 학생한테 부탁하나 마나야. 어차피 안 도와줄 거야.](https://www.howtostudykorean.com/wp-content/uploads/2025/11/Lesson190s09.mp3)
= There’s no point asking that student for a favor. He won’t help anyway.

Below are some more examples:

Play[그 은혜는 아무리 애써도 보답하나 마나야](https://www.howtostudykorean.com/wp-content/uploads/2025/11/Lesson190s10.mp3)
= No matter how hard I try, returning that favor is meaningless

Play[맹목적으로 따르나 마나야. 잘못된 길이니까.](https://www.howtostudykorean.com/wp-content/uploads/2025/11/Lesson190s11.mp3)
= Following blindly is pointless. It’s the wrong path.

Play[잠결에 한 말은 신경 쓰나 마나야. 기억도 못 해.](https://www.howtostudykorean.com/wp-content/uploads/2025/11/Lesson190s12.mp3)
= There’s no point caring about what you say in your sleep. Nobody will even remember it.

Play[이 보고서는 내용이 너무 미흡해서 읽으나 마나야](https://www.howtostudykorean.com/wp-content/uploads/2025/11/Lesson190s13.mp3)
= This report is so lacking in content that it’s not worth reading.

Play[그 산하 기관에 문의하나 마나야. 결정 권한이 없거든.](https://www.howtostudykorean.com/wp-content/uploads/2025/11/Lesson190s14.mp3)
= There’s no point in contacting that affiliate agency. They have no authority to decide.

Play[이 구역은 이미 자동 관제 시스템이 작동 중이라서 사람이 개입하나 마나야](https://www.howtostudykorean.com/wp-content/uploads/2025/11/Lesson190s15.mp3)
= Since the automatic control system is already in place, human intervention is pointless

Lesson 44: Let’s/Shall: ~자, ~ㅂ/읍시다, ~ㄹ/을래(요)

Introduction

In this lesson, you will learn about ~자 and ~ㅂ/읍시다, which are two common endings that you can use to suggest that you do something with another person. In addition, you will learn how to use ~ㄹ/을래(요) which can sometimes be used in similar situations. Let’s get started.

Let’s…: ~자 and ~ㅂ/읍시다

By adding ~자 to the stem of a word at the end of a sentence, you can suggest that that action be done together. In English, this typically translates to “Let’s…”

This is a very easy ending to learn because (by the nature of the meaning) it is always added to words in the present tense and no irregulars are affected by its usage. Not only that, ~자 gets added to stems ending in consonants and vowels. For example:

Play[밥을 먹자!](https://www.howtostudykorean.com/wp-content/uploads/2017/03/Lesson44-1.mp3) = Let’s eat!
Play[내일 공원에 가자!](https://www.howtostudykorean.com/wp-content/uploads/2017/03/Lesson44-2.mp3) = Tomorrow, let’s go to the park!

If you want to say “Let’s ***not***do something” you should attach ~자 to ~지 말다, which you learned in [Lesson 40](https://www.howtostudykorean.com/unit-2-lower-intermediate-korean-grammar/unit-2-lessons-34-41/lesson-40/). Remember, if you wanted to say “don’t’ go,” you should say:

가지 말다 = Don’t go

말다 is usually conjugated with an imperative ending. For example:

가지 마
가지 마라
가지 마세요

However, if you wanted to say “let’s *not* go,” you can add ~자 to 말다. For example:

Play[내일 공원에 가지 말자](https://www.howtostudykorean.com/wp-content/uploads/2017/03/Lesson44-3.mp3) = Let’s not go to the park tomorrow
Play[우리 애기를 위해 그것을 사지 말자](https://www.howtostudykorean.com/wp-content/uploads/2017/03/Lesson44-4.mp3) = Let’s not buy that for our baby

Below are many more examples:

Play[무대에 같이 올라가자](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v1.mp3) = Let’s go onto the stage together
Play[쪽지를 서로 보내자](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v2.mp3) = Let’s send messages to each other
Play[물에 알몸으로 들어가자](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v3.mp3) = Let’s go into the water naked
Play[있던 약속을 그냥 저버리자](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v4.mp3) = Let’s just back out of our plans that we had

Play[요새 벌이 조금 공평하지 않아. 내일 그것을 선생님이랑 얘기하자](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v5.mp3)
= Lately, the punishments have been a little unfair. Let’s talk about that with the teacher tomorrow

It is important to note that using ~자 is *informal*, and adding ~요 to ~자 is not done in Korean. Therefore, the sentences above could only be said to people who do not deserve high respect, like your friends or people younger than you.

A slightly more formal way to create this same meaning is to use ~ㅂ/읍시다 instead of ~자. ~읍시다 gets added to stems ending in a consonant, and ~ㅂ시다 gets added directly to stems ending in a vowel. For example:

Play[밥을 먹읍시다!](https://www.howtostudykorean.com/wp-content/uploads/2017/03/Lesson44-10.mp3) = Let’s eat!
Play[내일 공원에 갑시다!](https://www.howtostudykorean.com/wp-content/uploads/2017/03/Lesson44-11.mp3) = Tomorrow, let’s go to the park!

Other examples:

Play[그 규정을 내일부터 시행합시다](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v6.mp3) = Let’s enforce that rule starting tomorrow
Play[연수를 받으러 갑시다](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v7.mp3) = Let’s go to receive the training

This is *slightly*more formal than ~자, but it isn’t incredibly formal either. You commonly hear this form being used in offices – when the boss is speaking to a group of his/her subordinates or when coworkers are speaking to each other (of course, there are many other situations where this could be used – “in an office” is just one example). In these cases, some respect should be given to the listeners so ~ㅂ/읍시다 can be appropriate. However, I would advise against using ~ㅂ/읍시다 when speaking to somebody who deserve a high amount of respect – like your boss or your father-in-law. Instead, I recommend simply asking him a question using the information you learned in [Lesson 21](https://www.howtostudykorean.com/unit1/unit-1-lessons-17-25-2/lesson-21-asking-questions-in-korean-why-when-where-and-who/). For example:

Play[같이 먹고 싶습니까?](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v8.mp3) = Do you want to eat together?

[Want to see how ~ㅂ/읍시다 would be used in a Korean street sign? Watch me breakdown the usage in a YouTube video.](https://www.youtube.com/watch?v=wMRfpE9JdUo)

There is another Korean ending that you can use to say something similar to “let’s…” that you can add the formal ending ~요 to. We will learn about this next.

~ㄹ/을래(요)

I will separate my explanation of ~ㄹ/을래(요) into four usages. Each usage has a slightly different feel so I think this separation is helpful. Notice that (unlike ~자 and ~ㅂ/읍시다) ~요 can be added to this ending to make it more formal. Let’s discuss these four usages.

Usage 1: *To ask if the listener would like to do an action together*

In this usage, the speaker is asking if the listener would like to do an action together. The typical translation for this usage is “Shall we…” For example:

Play[내일 공부하러 독서실에 갈래요?](https://www.howtostudykorean.com/wp-content/uploads/2017/03/Lesson44-15.mp3) = Shall we go to the library tomorrow to study?
Play[서울에 있는 공연을 보러 갈래요?](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v9.mp3) = Shall we go to see the show in Seoul?

I feel that “Shall we…” is not a very common English expression. Although this is the most common translation for “ㄹ/을래요,” the following translation would also be acceptable:

Play[내일 공부하러 독서실에 갈래요?](https://www.howtostudykorean.com/wp-content/uploads/2017/03/Lesson44-15.mp3) = Would you like to go the library with me tomorrow to study?
Play[서울에 있는 공연을 보러 갈래요?](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v9.mp3) = Would you like to go to see the show with me in Seoul?

More examples:

Play[장례식에 같이 갈래요?](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v12.mp3) = Shall we go to the funeral together?
Play[영화를 볼래요?](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v13.mp3) = Shall we see a movie together?
Play[저녁을 내일 먹을래요?](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v14.mp3) = Shall we eat dinner together tomorrow?
Play[회원을 모집해 볼래요?](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v15.mp3) = Shall we try to recruit some members?
Play[벌을 엄격하게 시행할래요?](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v16.mp3) = Shall we enforce the punishment strictly?
Play[경기를 내일까지 연기할래요?](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v17.mp3) = Shall we delay the match until tomorrow?
Play[영어숙어를 같이 외워 볼래?](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v18.mp3) = Shall we try to memorize English idioms together?

It is also possible for this usage to be applied to a sentence that has a question word in it. The translation of “Shall we…” is usually appropriate in these sentences as well. For example:

Play[언제 할래?](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v19.mp3) = When shall/should we do it?
Play[어디 갈래?](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v20.mp3) = Where shall/should we go?
Play[뭐 먹을래?](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v21.mp3) = What shall/should we eat?

Usage 2 *To ask if the listener would like if something happened*

In this usage, the speaker typically threatens the listener with some sort of pain. The English equivalent of this would be something like:

“Do you want me to smack you?”

The two most common words that are used in this situation are:

Play[맞을래?](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v22.mp3) = Do you want to be hit? (Do you want me to hit you?)
Play[죽을래?](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v23.mp3) = Do you want to die? (Do you want me to kill you?)

Both of these are (usually) not used literally, and are simply empty threats from the speaker. These are typically used when the speaker becomes annoyed at somebody, and he/she can express her annoyance by threatening the person.

Usage 3

*To ask if the listener can do something for the speaker*

In this usage, ~ㄹ/을래(요) is typically attached to 주다 (either as a stand alone verb, or as ~아/어 주다 as you learned in [Lesson 41](https://www.howtostudykorean.com/unit-2-lower-intermediate-korean-grammar/unit-2-lessons-34-41/lesson-41/)). For example:

Play[김치를 더 줄래요?](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v24.mp3) = Can you give me more kimchi?
Play[문을 닫아 줄래요?](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v25.mp3) = Can you close the door?

In [Lesson 40](https://www.howtostudykorean.com/unit-2-lower-intermediate-korean-grammar/unit-2-lessons-34-41/lesson-40/), you learned how to use ~(으)세요 (and other imperative endings) to give a command. In effect, using ~ㄹ/을래(요) in this way is simply another way you can ask a person to do something for you. Because it is not a direct command, it sounds a little bit softer than telling a person directly to do something – almost like a request instead of a command.

In practice, the honorific ~(으)시 is often added to 주다 to make the request softer and more formal. In English, I would normally translate this to something that conveys this formality – for example, “Could you please…”. For example:

Play[김치를 더 주실래요?](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v26.mp3) = Could you please give me more kimchi?
Play[문을 닫아 주실래요?](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v27.mp3) = Could you please close the door?

More examples:

Play[환불해 주실래요?](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v28.mp3) = Could you please give me a refund?
Play[에어컨을 틀어 주실래요?](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v29.mp3) = Could you please turn on the air conditioner?
Play[울리는 핸드폰을 받아 주실래요?](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v30.mp3) = Could you please pick up the phone that is ringing?
Play[이것을 다 작성해 주실래요?](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v31.mp3) = Could you please write all of this up for me?
Play[그 파일을 이 컴퓨터로 복사해 주실래요?](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v32.mp3) = Could you please copy that file to this computer?
Play[소망이 무엇인지 말씀해 주실래요?](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v33.mp3) = Could you please tell me what your dream/hope is?
Play[이 숙어가 무슨 뜻인지 설명해 주실래요?](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v34.mp3) = Could you please explain what this idiom means?

Usage 4

*To indicate that the speaker wants to do something*

In theory, this usage is very similar to ~고 싶다 (which you learned in [Lesson 17](https://www.howtostudykorean.com/unit1/unit-1-lessons-17-25-2/lesson-17/)) or just a simple future tense conjugation. Here, the speaker is indicating that he/she will do something or wants to do something. For example:

Play[나는 집에 갈래](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v35.mp3) = I’m going home/I want to go home
Play[나는 집에 갈 거야](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v36.mp3) = I’m going home
Play[나는 집에 가고 싶어](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v37.mp3) = I want to go home

As you know, a regular future tense conjugation and ~고 싶다 can be applied to very complex sentences. Typically, ~ㄹ/을래(요) is only attached to simple sentences like the one shown above. Other examples:

*Also note that ~*안 *or ~*지 않다*can be used to indicate that the speaker doesn’t want to do something.*

Play[나는 그거를 먹을래](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v38.mp3) = I’m going to eat that/I want to eat that
Play[나는 안 할래](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v39.mp3) = I’m not going to do it/I don’t want to do it
Play[나는 안 먹을래](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v40.mp3) = I’m not going to eat/I don’t want to eat that
Play[나는 먼저 할래](https://www.howtostudykorean.com/wp-content/uploads/2016/04/Lesson44v41.mp3) = I’m going to do it first/I want to do it first

That’s it!

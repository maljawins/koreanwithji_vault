Lesson 168: ~거나 말거나: Indifference

Introduction

In this lesson, you will continue to learn about applications of 말다. Specifically, you will see how it can be used with ~거나. Let’s get started.

~거나 말거나: Stating Indifference to a Situation

In [Lesson 58](https://www.howtostudykorean.com/unit-3-intermediate-korean-grammar/unit-3-lessons-51-58/lesson-58/), you learned about ~거나 and how it is used to indicate one action or the other will be done. For example:

Play[주사위를 던지거나 카드 게임을 해도 돼요](https://www.howtostudykorean.com/wp-content/uploads/2025/05/Lesson168s1.mp3)
= You can either roll the dice or play a card game

Play[감기에 걸리면 격리를 하거나 병원에 가야 해요](https://www.howtostudykorean.com/wp-content/uploads/2025/05/Lesson168s2.mp3)
= If you catch a cold, you have to either quarantine or go to the hospital

Play[학교에서 교직원에게 질문을 하거나 도서관에서 정보를 찾을 수 있어요](https://www.howtostudykorean.com/wp-content/uploads/2025/05/Lesson168s3.mp3)
= You can either ask a faculty member a question or find information in the library

In that lesson, I hinted at the use of ~거나 말거나, stating that this form is typically used when doing the action or not doing the action is irrelevant. Let’s dive deeper into this usage into this lesson.

By placing ~거나 말거나 after some sort of action, you can indicate indifference to that particular situation. In a sense, you are indicating that it doesn’t really matter if that action occurs or not. By this logic, it is common to end these types of sentences with some style of “I don’t care” or “it does not matter.” Two common ways that this can be done is with 상관없다 and 신경을 안 쓰다 = these two were introduced in [Lesson 74](https://www.howtostudykorean.com/unit-3-intermediate-korean-grammar/lessons-67-75/lesson-74/) and [75](https://www.howtostudykorean.com/unit-3-intermediate-korean-grammar/lessons-67-75/lesson-75/)). For example:

Play[날씨가 뿌옇거나 말거나 아무래도 상관없어요](https://www.howtostudykorean.com/wp-content/uploads/2025/05/Lesson168s4.mp3)
= Whether the weather is foggy or not, it really doesn’t matter

Play[주사위를 던지거나 말거나 아무래도 상관없어요](https://www.howtostudykorean.com/wp-content/uploads/2025/05/Lesson168s5.mp3)
= Whether I roll the dice or not, it really doesn’t matter

Play[백신을 접종하거나 말거나 어떻든 저는 상관 안 해요](https://www.howtostudykorean.com/wp-content/uploads/2025/05/Lesson168s6.mp3)
= Whether I get vaccinated or not, either way, I don’t care

It is possible to use similar endings in sentences with ~거나 말거나. Some that I like in particular are:

… 중요하지 않다 = … it is not important
… 차이가 없다 = … there is no difference
… 문제가 아니에요 = … it is not a problem
… 관심사가 아니에요 = … it is not a concern
… 개의하지 않다 = … to not mind

Note that 개의하지 않다 is usually contracted to 개의치 않다 as you learned in [Lesson 159](https://www.howtostudykorean.com/unit-7/lessons-159-166/lesson-159/).

Sentences with ~거나 말거나 do not need to end with these types of endings. If the outcome of the clause prior to ~거나 말가나 is irrelevant, the clause after it can be the action that will happen as a result of this irrelevance. For example, look at the two sentences below. The first one ends simply by using one of the common endings described earlier. However, the second states the action that will happen as a result of the first clause being irrelevant.

Play[흐름을 따르거나 말거나 저는 별로 개의치 않아요](https://www.howtostudykorean.com/wp-content/uploads/2025/05/Lesson168s19.mp3)
= Whether I follow the flow or not, I don’t really mind

Play[흐름을 따라가거나 말거나 결국엔 목표에 도달할 거예요](https://www.howtostudykorean.com/wp-content/uploads/2025/05/Lesson168s20.mp3)
= Whether I follow the flow or not, I will eventually reach my goal

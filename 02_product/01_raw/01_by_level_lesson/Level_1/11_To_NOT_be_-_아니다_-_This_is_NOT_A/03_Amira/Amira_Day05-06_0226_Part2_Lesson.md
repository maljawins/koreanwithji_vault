Ji provides detailed feedback on her sentences, correcting common beginner mistakes such as using object markers with descriptive verbs. ## Teaching Points
*   **Descriptive vs. Action Verbs:** Descriptive verbs (adjectives like 좋다) cannot take objects. Therefore, the object marker 을/를 cannot be used with them. Instead, the thing being described is marked with the subject marker 이/가.
*   **The Object Marker 을/를:** Used only with action verbs. Like other particles, it follows the 받침 rule: 을 for words ending in a consonant, 를 for words ending in a vowel.
*   **The Versatility of 하다:** Known as the "verb-maker," it attaches to nouns to create verbs (e.g., 공부 + 하다 = 공부하다). It accounts for a huge portion of the Korean lexicon.
*   **Irregular Conjugation of 하다:** Ji introduces the "plant analogy" (Stem, Branch, Leaf, Fruit) to explain why 하다 becomes 해요. Unlike regular verbs that use 아/어 branches, 하다 uses a unique 여 branch.
*   **Sentence Nuance:** Ji explains how switching to the topic marker (은/는) in a sentence like "I like cats" can imply a contrast (e.g., "...but I don't like dogs").

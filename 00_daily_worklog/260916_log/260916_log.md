## Ref_No 최종 반영

- `01_by_level_lesson`의 Markdown 1,706개를 5종 index와 양방향 대조했다. Ji Draft 76개, YouTube 849개, Amira 438개, HTSK 339개, web 4개다.
- frontmatter를 새로 만든 파일은 1,700개, 기존 frontmatter에 Ref_No를 추가한 파일은 5개, 이미 일치해 유지한 파일은 1개다. 모든 대상 파일이 정확한 Ref_No 하나를 보유한다.
- Ref_No를 제외한 본문·기존 frontmatter·파일명·경로·인코딩·줄바꿈은 보존했다. 삽입 줄과 필요한 frontmatter 구분자를 제거한 내용은 변경 전과 바이트 단위로 일치한다.

## `01_concept_index.xlsx` 생성

- 개념 크기는 **독립 설명 단위**로 정했다. 따로 포함·제외할 수 있는 의미·용법은 나누고, 활용형·예문·세부 조건은 같은 개념의 근거로 기록한다.
- `01_concept_index.xlsx`에 `개념사전` 7열, `자료별개념` 16열, `레슨별범위` 16열을 만들었다.
- 각 시트는 머리글 1행, 표 1개, 전체 필터, 앞 2열 틀 고정으로 구성했다. 종류·등장 방식·범위 판단·Ji 검수는 선택 목록으로 제한했다.
- workbook은 실제 데이터·수식·병합 셀 없이 빈 구조만 담는다. 개념 조사, 근거 기록, 범위안과 Ji 검수는 다음 단계다.
- 저장본을 다시 읽어 시트명·머리글 순서·필터·틀 고정·선택 목록·입력 제한을 확인했고, 3개 시트 머리글을 화면으로 검토했다.

## 개념 조사 전 데이터 점검

- V7와 `레슨진행`은 196개 레슨의 순서·레벨·레슨 번호·제목이 모두 일치한다.
- 파일럿은 Hangul·Numbers·Level 1·Level 2의 44개 레슨·533개 raw 파일로 확인했다. Ref_No와 상대경로는 각각 중복 없이 연결되고, 모든 원본 경로와 frontmatter Ref_No가 일치한다.
- `파일관리`는 V7 레슨 순서 안에서 파일 Ref_No의 숫자 순서가 아닌 문자열 순서다. 예를 들어 `YT-Hangul-1-13` 다음에 `YT-Hangul-1-2`가 온다. 자료 연결에는 문제가 없으며, 비어 있는 `01_concept_index.xlsx`의 `자료별개념`은 조사 입력 시 V7 레슨 → 트랙 → Ref_No 숫자 순번 → 시작 줄 순서로 정렬한다.

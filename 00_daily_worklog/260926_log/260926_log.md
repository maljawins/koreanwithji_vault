## 결정과 근거

- 코스 제작의 현 단계는 **영상에서 직접 설명할 내용과 원문 사용 범위**를 정하는 일이다. 학생의 worksheet·assignment는 영상 제작 후 다룬다.
- 전수 개념 인덱싱은 모호한 개념 정형화와 환각·작업량 문제 때문에 제작 경로에서 제외한다. 중복자료 표도 발췌 정본으로 쓰지 않는다. V7·Ji Draft·매핑된 실제 raw를 함께 보고 레슨별 설명 경계를 잡는다.
- Ji는 `range_set_review.md`에서 **직접 설명 / 앞선 내용의 짧은 복습 / 다른 레슨으로 넘길 상세 내용**을 검토한다. Agent는 `range_set_source_spans.xlsx`에서 Ref_No별 원문 구간을 검증한다. 이 분리가 Ji의 검토량을 줄이면서 원문 출처를 남기는 이유다.
- Amira의 같은 수업 자료는 실제 녹화 레슨 → PPT+Script 통합본 → Script 순서로 확인한다. 하위 자료에만 있는 관련 설명은 별도로 확인한다.

## 산출물과 검증 상태

- [[course_plan]]과 관련 index·파일럿 지시서·tracking 설명을 갱신했다.
- `01_lesson_spec/01_range_set/`에 레슨별 `range_set_review.md` 44개와 단일 `range_set_source_spans.xlsx`를 만들었다. 파일 판정은 **사용 후보 422, 보류 78, 제외 후보 38**이다. DMS는 중복 연결 확인용이다.
- 538개 Ref_No의 실제 경로와 993개 후보 구간의 줄 번호 유효성을 확인했다. **구간의 내용 적합성과 조건·예외 포함 여부는 아직 Agent 재검증 대상**이다. Level 2-8은 매핑된 자료가 제목의 `Rule of Three 우회`를 직접 뒷받침하지 못해 자료 보강이나 범위 수정이 필요하다.
- Ji의 설명 경계 검토 전이므로 파일럿 44개 레슨의 tracking status는 모두 `raw_mapped`로 유지했다. `topic_raw` 발췌는 시작하지 않았다.

## 다음 위치

1. Agent가 후보 구간의 문맥·누락·레슨 간 중복을 원문과 대조하고, 모든 Ref_No를 `사용 / 사용 안 함`으로 확정한다.

3. 조건을 통과한 레슨부터 `range_set`으로 올리고 `topic_raw`에 원문을 발췌한다.

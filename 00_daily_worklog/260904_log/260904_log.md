## STEP 1 결정 12건 확정

Ji가 `brainstorm.md` §J의 미정사항에 대한 답을 한 번에 전달해서, STEP 1의 실행 방식이 전부 고정됐다.

| 항목 | 결정 |
|---|---|
| DP-3 lesson_spec 필드 | 10개 그대로 사용. 작업 중 수정 여지는 열어둔다 |
| DP-4 개념 페이지 | **안 만든다 (A안).** `concept_index.xlsx`만 쓴다. vault 파일이 불필요하게 늘어남 |
| DP-5 진행 순서 | 2안. 파일럿 범위는 Hangul·Numbers·Level 1·Level 2 |
| DP-7 raw 취합 방식 | **조준 발췌.** 단 정확도가 최우선 |
| DP-8 status 관리 | 4단계로 세분: `topic_copy` → `topic_raw` → `topic_shaped` → `spec_done` |
| DP-9 파일명 규칙 | 권장안 전체 채택 |
| DP-10 Ji_draft의 Ref_No | 안 쓴다. 경로로만 표기 |
| DP-11 spec 저장 위치 | `02_product/02_course_creation/02_lesson_spec/` 신설 |
| DP-12 폴더 없는 레슨 2개 | 사실 아님. 재검증 결과 196개 전부 존재 |

승격제(C안)는 "그때그때 승격시키는 건 관리가 번거롭다"는 이유로 기각됐고, `02_course_creation.md` 용어표의 `승격` 항목도 함께 삭제됐다.

**정확도 장치**: DP-7 지시에 맞춰 발췌 규칙 4개를 넣었다. 그중 "발췌문이 원문에 실제로 있는지 문자열 대조"는 에이전트가 지어내는 것을 사람 눈이 아니라 기계로 막는 장치다.

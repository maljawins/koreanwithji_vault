## lesson_spec 생산라인 재설계

초기에 생성했던 `topic_copy` 45개는 Ji가 직접 작성한 V7 `Ji 레슨 주제` 메모를 복사한 것이었다. Ji는 이 메모가 조준 발췌의 정확한 기준이 될 수 없다고 판단했고, `01_topic_copy` 전체를 `_archive`로 옮겼다. 이후 생산라인의 시작점은 V7 주제 복사본이 아니라 개념 조사와 Ji의 레슨별 범위 검수로 바뀌었다.

새 순서는 다음과 같다.

```text
파일별 Ref_No 정비 → raw frontmatter Ref_No 반영 → 01_concept 개념 조사
→ Ji의 레슨별 범위 검수 → topic_raw → topic_shaped → spec_done → OUTLINE → DRAFT
```

`02_ext_sources`와 `03_original_PDF`는 일괄 점검 대상이 아니다. Ji가 특정 레슨에서 사용할 자료와 발췌 범위를 지시할 때만 별도로 확인한다.

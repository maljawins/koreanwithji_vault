## 문서 재편: course_plan 단일화 + 4층 구조

계획 정보가 `course_plan.md`·`brainstorm.md`·`to_do.md` 세 곳에 흩어져 있던 것을 `course_plan.md` 한 곳으로 모았다. Ji가 브랜드 지시한 재편 방향은 셋이다.

1. **`course_plan.md`를 유일한 출처로.** `brainstorm.md`의 작업 규칙(발췌 규칙 5개, Ref_No 사용법, 파일명 규칙, spec 필드 작성 규칙, 실물 예시, concept_index 컬럼)을 전부 이 문서로 옮겼다. `brainstorm.md`는 Ji가 직접 삭제할 예정이라 손대지 않고 남겨뒀다
2. **실시/미실시 사항을 분리.** §3에 날짜별 "끝난 것" 표와 STEP별 "남은 것" 표를 신설했다
3. **3층 → 4층.** outline(층 3)과 draft(층 4)를 별도 층으로 나눴다. 이유: 검수 질문이 다르다("순서가 맞는가" vs "BEAT와 톤이 맞는가"). 한 층으로 묶으면 outline이 틀린 채로 draft까지 다 쓴 뒤에야 발견되고, 그러면 draft를 통째로 다시 쓴다. 층을 나누면 outline에서 먼저 막는다. **폴더는 나누지 않는다** — 한 레슨 폴더 안에 `_outline.md`와 `_draft.md`를 나란히 둔다 (Ji 결정)

`to_do.md`는 "지금 착수한 STEP의 할 일만" 담는 것으로 성격을 좁혔다. 끝난 항목은 `course_plan.md` §3-1 실시 사항으로 옮기고 to_do에서 뺀다. `01_inbox.md`의 to_do 작성 요령 8개도 이 기준으로 다시 썼다.

**index 동기화**: `CLAUDE.md`(§4 brainstorm 행 삭제, course_plan 행 확장), `master_index.md`, `02_product.md`, `02_course_creation.md`, `00_daily_worklog.md`에서 brainstorm 참조를 없애고 "3층"→"4층", "앞으로 할 일"→"지금 할 일"로 맞췄다.

**실측으로 바로잡은 수치 1건**: 옛 `to_do.md`는 "파일럿 44개 중 100줄 이상 `Ji_draft` 파일 37개"라고 적었으나, V7 xlsx와 raw 폴더를 스크립트로 재실측하니 **32개**였다. `course_plan.md`에는 32로 반영했다.

## STEP 순서 개정: 재료 → 개념 → Schema

Ji가 지시한 순서를 그대로 반영했다. 정정을 한 번 거쳤다: 처음엔 "44개 `topic_copy`·`topic_raw`·`topic_shaped`까지 먼저 → 개념 indexing → `topic_shaped` → Schema"였으나, "`topic_shaped`는 개념 indexing과 병행"으로 정정받았다.

**핵심 원칙**: 개념 인덱스 작업을 spec 작성과 **같이** 한다. 나중에 따로 정리하면 레슨마다 제각각 붙은 이름을 사후에 맞추느라 spec을 다시 고치게 된다.

| STEP | 이전 (09-04 확정) | 이후 (09-13 개정) |
|---|---|---|
| 2 | Schema 파일 구성 (template 3종) | **재료 모으기**: 44개 `topic_copy` + `topic_raw` |
| 3 | spec 작성 (파일럿 44개 전체) | **개념 indexing + `topic_shaped` 병행**: 레슨별 raw에서 개념 추출 → 44개 전체 polish(표준명 통일) → 그 표준명으로 TEACHING_POINTS 확정 |
| 4 | OUTLINE → DRAFT | **Schema 파일 구성 + `spec_done`**: template 3종 작성 → L2-01 dry-run → 44개 필드 채움 |
| 5 | 확장 | OUTLINE → DRAFT |
| 6 | — | 확장 (나머지 152개) |

**왜 template보다 재료·개념이 먼저인가.** template을 먼저 만들면 44개 실물을 보기 전에 필드를 추측해서 짜게 된다. 재료와 개념을 먼저 모으면 template은 이미 확인된 내용을 담는 틀이 되어 빠진 필드가 줄어든다.

**Ji가 명시하지 않아 가정으로 정한 것 3개** (course_plan.md에 반영, 다르면 정정 필요):
- `spec_done`(필드 10개 채우기)은 template이 있어야 하므로 STEP 4 Schema 뒤로 배치
- 2026-09-11에 승인된 L2-01 관통 테스트는 STEP 4의 dry-run으로 이동
- 옛 "발췌 전용 2차 테스트"(Ji_draft 없는 5개 레슨) 항목은 삭제 — STEP 2에서 44개를 전부 발췌하니 그 5개도 자동으로 같이 시험된다

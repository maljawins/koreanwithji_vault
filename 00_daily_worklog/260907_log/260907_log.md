## raw `Mapped Ji Lesson` 필드 848건 삭제

**무엇이 문제였나.** `02_yt_md` 트랙 파일에 `- **Mapped Ji Lesson:** [값]` 형태의 메타 라인이 있는데, 이 값이 구 커리큘럼 번호라 V7 xlsx(정본)와 어긋났다. 예: Miss Vicky `6 Essential Particles`에 `2-21`, `2-22`가 적혀 있으나 Level 2는 레슨이 10개뿐이라 존재하지 않는 번호다. 848개 파일 전부에 이 필드가 있었다.

**왜 바로 안 지우고 먼저 물었나.** `01_raw.md`의 자료 사용 규칙과 CLAUDE.md 하드룰 3("`02_product/01_raw/`는 읽기 전용이다. 이 폴더 안에 쓰거나 고치지 않는다")이 이번 요청과 정면으로 충돌했다. 규칙을 고쳐 예외를 만들지, 이번 한 건만 예외로 둘지 Ji에게 먼저 확인했다.

**Ji의 답**: "지금은 raw를 쓰기 이전에 예전 vault 잔재를 지우는 것이니 이번 건에 한해 예외로 두고 진행." 규칙 문구는 그대로 두고 이번 실행만 예외로 처리했다.

**실행**: 삭제 전 해당 패턴이 848개 파일에 정확히 848회(파일당 1회) 나타남을 재확인한 뒤 일괄 삭제. 삭제 후 재검색 0건, 샘플 파일(`TTMIK_Learning Korean like a BABY.md`)에서 앞뒤 줄(빈 줄, `---`)이 정상 유지됨을 육안 확인.

**참고**: `02_product/01_raw/01_by_level_lesson/`이 git 미추적 상태라 이 수정은 git 이력에 diff로 안 잡히고 워킹 디렉터리에만 반영됐다.

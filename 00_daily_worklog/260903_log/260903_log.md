## `02_course_creation` 전면 재설계

이전 vault가 "자료 전체 → 개념 추출 → 레슨 조립" 순서로 작업해 개념이 레슨에 종속되지 않았고, raw 본문에 전역 백링크를 심어 그래프가 털뭉치가 됐다는 문제를 짚고, Ji가 제안한 "레슨 주제 먼저 정형화 → raw 매칭 → 레슨 단위 개념 추출" 순서로 뒤집는 재설계를 진행했다.

**조사로 발견한 것 3가지** (새로 만들 게 아니라 이미 있었던 것들)
1. 커리큘럼 맵 V7의 4번째 컬럼에 196개 레슨의 teaching point가 이미 Ji 손으로 적혀 있음
2. `01_by_level_lesson` 폴더 구조 자체가 이미 "레슨 ↔ raw" 매핑이라 링크 없이도 조준 가능
3. 레슨 설계 교수법(Skeleton → Flesh → Comprehensible Input → 줌인 → 실생활)이 `02_course_creation.md` 안에 이미 있었음(위치만 틀렸음)

**산출물**
- `brainstorm.md` (신규) — 진단, 3층 구조(raw / lesson_spec / outline·draft) 제안, lesson_spec 10필드 스키마 + Level 2-02 실제 예시, 개념 페이지 정책 3안(승격제 권장), 진행 순서 2안, Ji 결정 필요 5건(DP-2~DP-6)
- `work_plan.md` (신규) — 실행 계획
- `lesson_design_method.md` (신규) — 교수법 이관
- `02_course_creation.md` — 386줄에서 222줄로 재작성, mermaid 갱신, STEP 1·2 확정, STEP 3 이후는 자리만 비움

**검증**: raw 수치 실측(당시 기준 전체 1,794 / 레슨별 1,775 / 레슨 196 / 레벨 16 / 레슨당 최소1·중앙값7·최대30)으로 구 수치 교체. 세 번째 본보기 Draft 경로 오기 정정.

**Ji 결정 대기**: DP-2(3층 구조 채택) / DP-3(lesson_spec 필드) / DP-4(개념 페이지 정책) / DP-5(진행 순서) / DP-6(STEP 3~6 번호) — 이 5개가 정해져야 STEP 3 이후를 문서에 박을 수 있다.

## 유령 백링크(`concept_` 등) 전체 정리

예전 vault의 `backlinks.py`가 raw 본문·frontmatter에 자동으로 심었던 `[[concept_x]]` 링크가 concept 노트 자체는 새 vault로 넘어오지 않은 채 남아 있던 문제. Ji가 IDE에서 우연히 발견한 오매칭 사례(겸양 표현 "저"에 지시대명사 개념 링크가 걸려 있던 것)를 계기로 전체 정리까지 이어졌다.

1. **발견**: `concept_` 패턴 검색으로 37개 파일 372건 확인, concept 노트가 vault 어디에도 없어 전부 죽은 링크임을 검증(보고만, 미조치)
2. **진단 기록**: `brainstorm.md` §A-4 신설 — 오매칭 사례를 근거로 "이 링크 텍스트는 lesson_spec·concept 페이지 작성 시 참고자료로도 쓰지 않는다"고 명시
3. **범위 확정**: vault 전체(.md 1,820개) 정밀 스캔으로 깨진 wikilink 458건(고유 타겟 83개, 영향 파일 50개) 전수 확인. `01_raw` 밖은 전부 백틱 예시이거나 삭제 예정 폴더라 손댈 필요 없음을 확인하고, 수정 대상을 `01_raw` 84개 파일로 확정(frontmatter `concepts`/`ingest_cycle`/`ingest_date`/`ingest_status` 69개, 본문 인라인 링크 35개, Reddit `author` 필드 4개, 각주 아티팩트 4개)
4. **계획 승인**: plan mode로 0~5단계 계획서 작성 → Ji 승인(CLAUDE.md §2 하드룰 3 "`01_raw` 읽기 전용"의 1회 한정 예외로 진행)
5. **실행**: 84개 파일 백업 → 자동 변환 적용(본문은 표시텍스트만 남기고 링크 문법 제거, frontmatter 4개 필드 삭제) → 검증 중 3중 대괄호(`[[[concept_x|텍스트]]`, 원본 대괄호 표기법과 링크가 겹친 경우) 2건 발견해 수동 교정
6. **검증**: 백업본과 바이트 단위 대조로 84개 전부 텍스트 손실 0건, `01_raw` 전체 잔여 깨진 wikilink 0건, 파일 개수 불변 확인. Obsidian 그래프에서 `concept_` 노드 소멸을 Ji가 직접 확인
7. **마무리**: 파일 개수가 문서상 "1,728"과 1개 차이 났던 원인을 Ji가 직접 확인 — 트랙 밖에 있던 orphan 파일(가장 흔한 한국어 단어 5800개 링크 저장 파일)을 Ji가 삭제해 1,727이 맞는 수치로 확정. CLAUDE.md §10 gotcha 추가는 "raw에 wikilink를 넣을지 아직 미정, 문서 목적에도 안 맞음"이라는 이유로 Ji가 반려 — 미추가

**결과**: `01_raw` 84개 파일에서 총 446건(concept_ 링크 442 + 아티팩트 4) 제거. `brainstorm.md` §A-4에 정리 완료 기록.

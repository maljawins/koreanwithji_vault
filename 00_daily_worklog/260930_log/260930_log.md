## 결정과 근거

- `Ref_No`는 Raw 사본을 가리키는 번호이므로 이동·복사 자료에만 새 번호를 적용하고, 기존 번호의 빈자리를 채우려고 다른 자료를 재정렬하지 않았다.
- 자료 위치와 레슨 배정의 정합성을 먼저 맞춘 뒤, Ji가 정한 영상 설명 경계와 원문 줄을 확인한 9개 레슨만 `topic_raw`로 올렸다. Numbers-2의 `YT-Numbers-2-4`는 Sino-Korean, Numbers-3의 `YT-Numbers-3-4`는 Native/Pure Korean 설명만 발췌했다.
- Numbers-6은 사칙연산 명칭의 직접 근거가 부족하다. 외부 후보를 Agent가 임의로 새 매핑 자료로 확정하지 않았다.
- Level 3~12의 `사용 후보`와 `보류`는 1차 판정이다. 원문 문맥 재검증과 Ji의 설명 경계 결정 전에는 완료 상태로 보지 않는다. Level 5-6 카드는 만들지 않았다.

## 산출물과 검증 상태

- `02_yt_md_index.xlsx`의 대상 6행에서 상대경로·번호·레슨·제목·파일명을 저장 후 재대조했다. `range_set`과 tracking의 해당 경로·자료 수도 대조했다.
- Hangul 1~3과 Numbers 1~5·7의 9개 발췌문·검토 카드는 `Ref_No`·원문 링크·줄 번호를 정본과 대조했다.
- Level 3~12의 카드 149개를 포함해 `01_range_set` 검토 카드는 현재 193개다. `range_set_source_spans.xlsx`의 `파일판정`은 1,677개 `Ref_No`이며, tracking은 196개 중 `topic_raw` 12개·`raw_mapped` 184개다. 이 수치는 마감 시 파일을 다시 읽어 확인했다.
- Raw 원본은 Agent가 수정하지 않았다. 작업 중 나온 임시 검사 파일은 제거했다.

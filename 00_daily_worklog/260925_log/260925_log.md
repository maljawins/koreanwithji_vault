## workflow 변경 근거 기록

- [[260923_log]]에 concept index가 레슨별 teaching point를 정하기 전에 모호한 분류 판단을 늘린다는 점을 기록했다.
- 중복 자료는 Ji가 레슨별 원문 구간을 먼저 선택하고, 선택이 끝난 레슨만 `range_set`으로 올리는 순서로 정리했다.
- 레슨 제작 상태는 `raw_mapped → range_set → topic_raw → topic_shaped → lesson_spec → outline → draft`로 유지했다.

## 작업지시서·tracking 갱신

- `course_plan_update.md`에 맞춰 `02_course_creation`의 관련 index·지시서·용어·참조를 새 workflow로 갱신했다.
- tracking xlsx의 status validation과 lesson_spec 경로 header를 새 상태 체계에 맞췄다.
- concept 추출과 concept index workflow는 진행하지 않았다.

## 중복 자료 선별표 정리

- `duplicate_material_selection.xlsx`의 DMS-0001~0010에서 제외 내용은 원본 header로, 제외 사유는 해당 내용을 사용할 레슨으로 표시했다.
- 셀 안의 문법 용어를 English로 통일했고, DMS-0007의 SOV 설명은 `object`, `object marker`로 정리했다.
- xlsx XML 구조와 핵심 셀을 확인했다.

## 다음 위치

- DMS-0011부터 같은 방식으로 원문 검토와 선별안을 이어 간다.
- 확정된 레슨만 `range_set`으로 올린 뒤 `topic_raw → topic_shaped → lesson_spec → OUTLINE → DRAFT` 순서로 진행한다.

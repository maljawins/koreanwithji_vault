## 개념 조사 기준의 실패와 교정

첫 조사에서는 Hangul 1 Ji Draft 한 파일만 읽고 17개 개념·20개 근거를 등록했다. 이때 다음 문제가 드러났다.

- `Importance of Hangul`, `Hangul Creation`, `Rhythmic Hangul Practice`처럼 가르칠 내용이나 활동을 개념으로 등록했다.
- 원문에 없는 설명형 이름을 만들거나 이전 한국어 이름을 근거 확인 없이 별칭으로 남겼다.
- 파일 하나의 결과를 레슨 전체 조사처럼 다룰 위험이 있었다.

Ji의 피드백을 받아 개념을 **학생에게 무엇인지 설명해야 하는 용어**로 다시 정의했다. 문법 표현도 그 자체가 개념일 수 있으므로 일괄 제외하지 않고, 애매하면 확인 요청으로 넘긴다. 표준명과 별칭은 실제 조회한 원문에 등장하는 이름만 쓴다. 영어 명칭이 없으면 한국어를 유지하고 임의 번역이나 로마자화를 하지 않는다.

## Hangul 1 레슨 단위 재조사

- 조사 단위를 파일 한 개에서 **레슨 하나에 매핑된 자료 전체**로 변경했다.
- Hangul 1의 Ji Draft 1개, YouTube 13개, Amira 2개, 외부자료 1개를 확인했다.
- YouTube는 `Teaching Points`, Amira는 허용된 Script·통합본 설명, 외부자료는 기존 매핑 구간 286–432행만 읽었다.
- 기존 개념 번호 중 8개를 유지했다. 설명 주제로 잘못 만든 9개는 제거하고 번호를 재사용하지 않도록 기록했다.
- 최종 검토용 인덱스에는 개념 31개, 별칭별 행 32개, 자료별 근거 82개가 있다.
- `개념사전`에 `표준명 근거`와 `별칭 근거`를 추가했다. 이름 근거 42개가 실제 원문 구간과 연결된다.
- `레슨별범위`는 비어 있는 상태로 유지했다. 개념 등록이 곧 Hangul 1의 강의 범위 확정을 뜻하지 않는다.

## 확인 요청 관리

`concept_review_questions.md`에 다음 8건을 `확인 대기`로 기록했다.

1. compound vowels와 diphthongs의 관계
2. Basic Consonants의 범위
3. placeholder·Aspirator 같은 수업용 이름의 독립 개념 여부
4. 외래어 표기 규정의 음성학 분류 용어 등록 범위
5. Sino-Korean과 한자의 구분
6. denasalization 자료 간 설명 차이
7. Aspirated Consonants의 범위와 Sh 설명
8. `~아요/어요`를 별도 개념으로 볼지 여부

Ji는 질문이 생겨도 Hangul 1 전체 작업을 멈추지 말라고 지시했다. 확실한 항목과 독립적인 조사는 계속하고, 질문에 의존하는 통합·별칭·정의만 보류한다. 질문이 남아 있으므로 Hangul 1의 조사 상태는 `확인 대기`다.

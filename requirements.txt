# 세 변환 작업의 공통 도구: 엑셀 상태 기록, 이미지 처리, Gemini 호출, 받아쓰기.

# 화면 글자 인식: 기존 Korean / Tech와 같은 구조로 만들 Teaching에서 공용 사용.

# easy_install은 setuptools 80에서 제거됐으므로 호환 버전을 명시한다.

paddlepaddle==2.6.2
paddleocr==2.10.0

# Paddle 2.6의 NumPy 1.x 호환 계열. OpenCV 간접 의존성도 같은 버전으로 맞춘다.

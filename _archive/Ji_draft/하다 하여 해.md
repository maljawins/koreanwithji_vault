Now if you still want to know how 하다 becomes 하여 or 해 in short, I can tell you one “theory”.
Note that not even linguists know for sure so you should note that this theory is not entirely accurate. And this is a simplified version of it.

And again, this is not important, so, you can skip this part if you want to.

So, here it goes.

Back in the medieval days, 하다 used to be this [Show “ᄒᆞ다”]
This is old 한글, which we no longer use.
And supposedly, it was pronounced like 하이다.

Now, if you apply the 아/어 rule to 하이다, you get 하이어. And when you say 하이어 quickly, you get 하여. So, there it is.

And as for how 하여 became 해, this is how ***I*** see it personally.

If you combine 하 and 여 alphabetically, not phonetically, you get 햬.

Notice how hard it is to enunciate that ㅒ sound in 햬? I mean, it’s even hard for ME.

And there is 0 word that uses the spelling 햬. However, 혜, which sounds exactly the same, IS very common.

And 혜인 and 해인 are both popular names for women.

For example, 혜인 is a K-pop idol from the group called “New Jeans”

And this is 해인, a character from a K-drama “Queen of Tears”

If they were to tell me their name, I would HAVE to ask them how to spell it because they sound almost identical.

If someone asks:
**“오늘 헬스장 갈 거예요?”**
(“Are you going to the gym today?”)

You might say:
**“아니요, 오늘은 운동하기 싫어요.”**
(“No, I don’t feel like working out today.”)

It sounds very natural, and also slightly more **emotional** than simply saying **안 가고 싶어요**.

**Let’s look at some more examples using ~고 싶다 and ~기 싫다.**
We’ll also bring back some of the particles we learned earlier to show how these forms work in full sentences.

**1. 카페에서만 공부하고 싶어요.**

“I want to study only at a café.”

Let’s break this down:

* **카페에서** means “at the café.”
* **만** is added after **에서** to say “only at the café.”
* **공부하고 싶어요** means “I want to study.”

So together:

“I want to study **only at** a café.”
Maybe you don’t like studying at home or libraries—just cafés!

**2. 저도 한국어를 배우고 싶어요.**

“I also want to learn Korean.”

Here, we’re using **도** after **저** to mean “me too” or “I also.”

* **저도** → I also
* **한국어를 배우고 싶어요** → want to learn Korean

This is how you can politely express shared desire:

My friend is learning Korean “I also want to learn Korean.”

**3. 물밖에 마시고 싶지 않아요.**

“I don’t want to drink anything but water.”
[Literally: I don’t want to drink **outside of water**]

This one uses the **밖에 + negative** structure we learned.

* **물밖에** means “nothing but water.”
* **마시고 싶지 않아요** means “I don’t want to drink.”

So it doesn’t mean “I don’t want to drink water.”
It means:

“I only want to drink water.”
“I don’t want *anything else* except water.” This is a great way to express limited desire using both grammar forms at once.

**4. 집에서는 쉬고 싶어요.**

“I want to rest at home.”

Here we’re using the **에서는** contrast form.

* **집에서는** → “at home” (with contrast: at home, not elsewhere)
* **쉬고 싶어요** → “I want to rest”

So this sentence implies something like: “I want to rest **at home** (not work at home)”
or “At home, I just want to relax.”

It contrasts your behavior at home vs. outside. Maybe you work really hard outside but just want to chill at home.

**1. 월요일에는 정말 일하기 싫어요.**

“I really don’t want to work on Monday.”

Let’s break it down:

* **월요일에는** means “on Mondays” or “as for Monday” with contrast.
* **정말** adds emphasis: “really.”
* **일하기 싫어요** means “I don’t want to work.”

So the whole sentence means:

“I really don’t want to work on Mondays.” It sounds very relatable, right? Mondays are tough for most people, and this is a natural way to say it in Korean.

**2. 채소만 먹기 싫어요.**

“I don’t want to eat only vegetables.”

Here:

* **채소만** means “only vegetables.”
* **먹기 싫어요** means “I don’t want to eat.”

So, this means:

“I don’t want to eat only vegetables.”
Maybe you want some meat or rice with it!

You’re not saying you hate vegetables—you just don’t want **only** that.

**3. 주말에는 일만 하기 싫어요.**

“On the weekends, I don’t want to only work.”

Let’s go over this:

* **주말에는** = “on the weekend” (contrast emphasis)
* **일만** = “only work”
* **하기 싫어요** = “don’t want to do”

Put it all together:

“On the weekends, I don’t want to only work.”
The sentence implies that weekends should include rest or fun—not just work.

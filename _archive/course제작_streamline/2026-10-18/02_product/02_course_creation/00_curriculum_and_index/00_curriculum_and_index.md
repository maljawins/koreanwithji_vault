# 00_curriculum_and_index 인덱스

> 이 폴더는 **커리큘럼 정본과 자료 매핑 index**를 둔다. 이 파일은 위치만 안내한다.

---

## 파일 지도

| 파일 | 역할 |
|---|---|
| `Korean Course Curriculum Map_Final_V7.xlsx` | 레벨·레슨 순서·제목의 정본 |
| `01_Ji_Draft_index.xlsx` | Ji Draft 자료의 파일별 매핑 index |
| `02_yt_md_index.xlsx` | YouTube 변환 자료의 파일별 매핑 index |
| `03_Amira_index.xlsx` | Amira 실제 파일별 Ref_No 정본. Script·통합본·녹화 Part·Summary를 각각 기록 |
| `04_HTSK_index.xlsx` | How to Study Korean 자료의 파일별 매핑 index |
| `05_web_index.xlsx` | Web 자료의 파일별 매핑 index |
| `06_ext_sources_index.xlsx` | Hangul 1·3·4·6의 외부 한글 자료 복사본별 Ref_No·경로·사용 구간 index |

## 사용 규칙

- 레슨 수, 레벨, 제목, 순서는 `Korean Course Curriculum Map_Final_V7.xlsx`가 정본이다.
- 자료의 `Ref_No`와 원본 파일 매핑은 각 트랙의 index xlsx에서 확인한다. Hangul 외부자료 복사본은 `06_ext_sources_index.xlsx`에서 확인한다. xlsx는 열 순서가 아닌 헤더 이름으로 읽는다.
- 커리큘럼 맵과 실제 폴더가 다르면 xlsx를 기준으로 확인한다.
- 현재 `01_by_level_lesson`에는 1,711개 Markdown이 있다. `파일관리`의 기존 1,707개와 Hangul 외부자료 복사본 4개를 `외부자료` 시트에서 함께 관리한다. `02_ext_sources` 원본과 `03_original_PDF`는 이 예외 외에 일괄 등록하지 않는다.

`03_Amira_index.xlsx`의 `매핑 완성본`은 실제 파일 438개의 현재 목록이다. 기존 109개 주제 매핑은 같은 workbook의 `이전_매핑` 시트에 보존한다.

관련 작업 계획과 파일럿 범위는 [[course_plan]]에서 관리한다.

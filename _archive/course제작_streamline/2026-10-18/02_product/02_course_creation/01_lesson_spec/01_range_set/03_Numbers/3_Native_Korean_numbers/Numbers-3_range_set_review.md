## Agent가 확인할 사항

- 5개 Ref_No의 실제 파일과 9개 구간의 시작·끝 줄을 확인했다.
- Ji Draft는 원본 전체 사용 원칙에 따라 서수 대목도 원문 그대로 남긴다. Numbers-3 영상의 직접 설명에는 쓰지 않고 Numbers-5에서 다룬다.
- Go Billy 요약본의 고유어·서수 구간을 배정했다. 50 이상은 무조건 한자어로 바뀐다는 단정은 채택하지 않았다.

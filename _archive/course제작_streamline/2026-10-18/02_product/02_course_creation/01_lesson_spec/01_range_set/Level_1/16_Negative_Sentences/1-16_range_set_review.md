# 1-16 · Negative Sentences · 설명 범위 검토

> Agent가 매핑 원문과 구간을 대조해 사용 여부를 잠정 판정했다. Ji가 설명 경계를 검토하기 전이므로 tracking은 raw_mapped다.

## 판단 출발점

- **V7 제목:** `Negative Sentences`.
- **V7 brainstorm 참고:** 지 않다 (formal negation), 안 (short negation)  - restriction on 안 with Sino-Korean verbs  치 contraction (흔하지 않다 → 흔치 않다, 원하지 않다 → 원치 않다)  - ㄴ하지 → 치  지를/지는/지가 particle emphasis
- **Ji Draft:** Ji-1-16-1.
- **매핑 원문:** 14개 Ref_No. 사용 7개, 사용 안 함 7개, 선택 구간 16곳. 자료 판정의 정본은 [[range_set_source_spans.xlsx]]이다.

## Ji가 검토할 설명 경계

| 구분 | Agent 제안 |
|---|---|
| 이번 영상에서 직접 설명 | 안과 -지 않다로 부정문을 만들고 하다 동사 및 축약형의 위치·형태를 설명한다. |
| 앞에서 배운 내용의 짧은 복습 | 1-5의 동사 활용을 복습한다. |
| 다른 레슨에서 자세히 설명 | 못의 능력 부정과 아니다의 명사 부정은 별도 비교로만 짧게 다룬다. |

## Ji에게 필요한 답변

위의 **설명 경계 표**를 검토한 뒤 아래 질문마다 답하고, 마지막 `Ji 검토`에 전체 결정을 적는다. 원문 줄·사용 여부 검증은 Agent가 맡는다.

1. **Ji가 정할 내용:** 못·-지 못하다를 이번 부정문 영상에서 직접 설명할까, 안·-지 않다와의 비교 예시로만 둘까?
   - **Ji 판단이 필요한 이유:** 현재 카드에 비교 대상으로 있지만 V7 brainstorm의 중심은 안·-지 않다다.
   - **Ji 답변:**

2. **Ji가 정할 내용:** -치 축약과 -지는/-지가/-지를 같은 강조 표현까지 직접 가르칠까?
   - **Ji 판단이 필요한 이유:** V7에 두 확장 항목이 명시돼 있으나 현재 경계표는 안·-지 않다의 형성과 위치를 중심으로 제안한다.

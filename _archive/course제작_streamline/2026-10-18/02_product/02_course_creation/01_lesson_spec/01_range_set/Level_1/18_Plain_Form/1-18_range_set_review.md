# 1-18 · Plain Form · 설명 범위 검토

> Agent가 매핑 원문과 구간을 대조해 사용 여부를 잠정 판정했다. Ji가 설명 경계를 검토하기 전이므로 tracking은 raw_mapped다.

## 판단 출발점

- **V7 제목:** `Plain Form`.
- **V7 brainstorm 참고:** 언제 쓰이는지 알려주기  - 혼잣말로 쓰인다  - 누구한테 말할 때는 반말로 생각하면 됨  Plain form conjugation Present  - Action Verb Stem + ㄴ/는다 (ex: 간다, 먹는다)  - Descriptive Verb Stem + 다 (ex: 작다, 바쁘다)  - 이다 → (이)다 (ex: 사람이다, 커피다) Past Tense  - 았/었 + 다 (갔다, 먹었다)
- **Ji Draft:** 매핑 없음.
- **매핑 원문:** 10개 Ref_No. 사용 8개, 사용 안 함 2개, 선택 구간 22곳. 자료 판정의 정본은 [[range_set_source_spans.xlsx]]이다.

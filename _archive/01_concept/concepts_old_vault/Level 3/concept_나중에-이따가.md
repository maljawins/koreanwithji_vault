# concept_나중에-이따가

- 정의: 둘 다 "later"로 번역되지만 시간 범위가 다름 — 나중에는 **다른 날/불특정 먼 미래**, 이따(가)는 **오늘 안의 짧은 나중**.
- 핵심 형태/규칙:
  - **나중에**: 오늘이 아닌 다른 날, 막연한 미래. 지나가다 `나중에 봐요`라고 하면 상대는 "오늘 다시 볼 생각 없구나"로 받아들일 수 있음 — 꽤 먼 느낌.
  - **이따 / 이따가**: 오늘 안에서 "조금 이따가/잠시 후"라는 뜻. 가/이 붙어도 뜻 차이 없음(둘 다 자연스러움).
  - **나중 vs 나중에(품사 구분)**: `나중`은 명사("나중"이다=it is later, 잘 안 씀), `에`를 붙인 `나중에`가 부사(~할 것이다=나중에 할게요). 행동의 "때"를 말할 땐 반드시 `나중에`(부사형) 사용.
- 예문:
  - `나중에 봐요.` (오늘 말고 다른 날)
  - `이따가 할게요.` (오늘 안에서 조금 있다가)
- 주의/흔한 오류: 오늘 안에 다시 만날 생각인데 `나중에`를 쓰면 "오늘 안 볼 것"으로 오해받을 수 있음 — 그 경우 `이따가`.

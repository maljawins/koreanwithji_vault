# concept_게도록-so-that

- 정의: "so that" 계열 연결어미 `~게`/`~도록`과, 거기서 파생되는 사동(causative) 표현 `~게 하다`/`~게 만들다`/`~을/를 시키다`, 그리고 "결국 ~하게 되다"를 뜻하는 `~게 되다`까지 묶은 문형군. Amira 세션 22(L3-19 물리 폴더)에서 함께 다뤄졌으나, 내용상 "know/thought"(줄 알다/모르다)와는 별개 주제 — 사동 표현의 선행 개념.
- 핵심 형태/규칙:
  - **`~게`/`~도록`("so that")**: 동사/형용사의 **현재 어간**에만 결합(과거 어간 불가), 받침 유무 무관. 의미·용법상 거의 차이 없음(`아이도 이해할 수 있게/도록 설명을 쉽게 해주세요`) — `도록`이 `게`보다 격식체.
  - **형용사+게 = 부사화**: `~게`가 형용사 어간에 붙으면 부사를 만드는 방법 중 하나. 단, 모든 형용사에 자연스럽게 붙는 건 아님(많은 부사가 `이/리/히`로 끝나는 별도 형태를 가짐 — 많다→많이, 빠르다→빨리, 완벽하다→완벽히). 한국어 부사는 영어 "-ly"처럼 규칙적이지 않아 개별 단어로 암기 권장.
  - **동사+게 = "~할 수 있도록"(의도 함의)**: 행위동사에 `~게`가 붙으면 "그렇게 할 수 있도록"의 뜻, 의도(intention)를 내포. `~려고`와 비교: **주어가 달라야 함**(~려고는 주어가 같아야 함), **제안/명령문에 주로 쓰임**(~려고는 제안/명령 불가) — 용법이 정반대로 갈림. `모두가 보게 그림을 크게 그려주세요`(모두가 볼 수 있도록).
  - **`~게 하다`/`~게 만들다`("to make/let someone do")**: `~게`의 "so that" 뜻이 확장되어 사동(causative)으로 굳어짐. `만들다`(만들다=만들기 때문에 "강제로 만든다"는 느낌이 `하다`보다 살짝 강함)와 `하다`는 대체로 호환. `엄마가 아이에게 야채를 먹게 했어요`(엄마가 아이가 야채를 먹도록 시킴). **허락**의 뜻은 `~게 해주다`(선생님이 학생들에게 질문하게 해주셨어요=허락함). **강요**는 `억지로`/`강제로` 같은 부사를 추가.
  - **`~게 하다`는 사동 접미사(이/리/히/기/우/추)가 안 붙는 동사의 최종 수단**(last resort) — 사동 접미사가 없는 동사에 두루 쓸 수 있는 만능 사동 형태.
  - **`을/를 시키다`("to make someone do", 하다의 사동)**: 사전적으로 `시키다`="하게 하다". **목적어+동사로 분리 가능한 하다 동사**(운동하다=운동을 하다)일 때는 `~게 하다`보다 `시키다`가 훨씬 자연스러움 — `운동하게 하다`(문법적으로 맞지만 어색) vs `운동을 시키다`(자연스러움). `시키다`가 단독으로 "주문하다"(음식 배달 등)의 뜻으로도 쓰임(`배달 음식을 자주 시켜 먹어요`).
  - **`~게 되다`("to end up ~ing / to become")**: 의도가 아니라 **자연스러운/불가피한 결과**로 어떤 상태가 됐음을 표현 — `한국에 살다 보니 한국말을 잘 하게 됐어요`(직접 의도한 게 아니라 자연스러운 결과). 부정적 결과일 필요 없음(중립적 change-of-state).
  - **`~고 말다`(관련 대조어, "to end up ~ing")**: `게 되다`와 비슷하게 "결국 ~하게 되다"를 뜻하지만, `~고 말다`는 **원치 않던 나쁜 결과**가 노력에도 불구하고 결국 일어났음을 강조 — `게 되다`(중립)와 `고 말다`(부정적 뉘앙스)의 뉘앙스 차이.
- 예문:
  - `제가 앉을 수 있게 의자를 좀 당겨주세요.` = Please pull the chair a bit so that I can sit down.
  - `엄마가 아이에게 운동을 시켰어요.` = Mom made the child exercise.
  - `갑자기 비가 와서 집에 못 가게 됐어요.` = It suddenly rained, so I ended up not being able to go home.
- 주의/흔한 오류: `~려고`와 `~게`는 의미는 비슷해 보이나 문법 규칙(주어 일치 여부·명령문 가능 여부)이 정반대이므로 혼용 주의.

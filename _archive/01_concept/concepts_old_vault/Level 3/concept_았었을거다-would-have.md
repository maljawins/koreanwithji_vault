# Would Have / Assumption: ~았/었을 거다

The structure **Past Stem + ~ㄹ/을 거다** is used to express an assumption about a past event or to say "would have" in a hypothetical past scenario. It literally translates to "will have been" or "will have done". 

## Formation
Take the past tense stem of any verb (e.g., `하다` -> `했`, `가다` -> `갔`, `먹다` -> `먹었`), and attach `~을 것이다` (or `~을 거다` in conversation).
* 하다 -> **했을 거다** / **했을 거예요**
* 가다 -> **갔을 거다** / **갔을 거예요**

## Usages

### 1. Assumption about the ACTUAL past (Must have)
When you're guessing what likely happened in the past (when you were not there), it acts similar to "must have" or "I'm sure that...". It sounds fairly certain and neutral.
* 그건 아빠가 이미 **했을 거예요**. (Dad would have already done that / Dad must have already done that.)
* 재미있**었을 거예요**. (I'm sure that was fun.)

*Note: You usually do not use a 1st person subject ("I") or 2nd person ("You") with this usage, as you don't "guess" what you yourself did.*

### 2. Hypothetical Past (Would have)
When used with an "If" clause (`~면 / ~았/었으면`), it means "would have done" something in a hypothetical scenario.
* 철수가 했으면 더 잘 **했을 거예요**. (If Cheol-su had done it, he would have done it better.)
* 진작 알았으면 같이 **갔을 거예요**. (I would have gone together if I'd known beforehand.)
* 시간이 있었으면 (제가) **했을 거예요**. (If I had time, I would have done it - *I'm sure of it*).

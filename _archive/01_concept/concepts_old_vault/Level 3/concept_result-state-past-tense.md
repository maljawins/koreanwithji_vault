# Result State Past Tense

In Korean, certain verbs that describe physical appearance, condition, or a state of being are frequently used in the past tense to describe a **current present state**. This happens because the state is viewed as the result of an action or transformation that was completed in the past. 

For example, to say someone is currently handsome, Korean uses the past tense **잘생겼어요**, not the present tense *잘생겨요*.

## Core Logic

The logic is that the "process" or "action" (e.g., coming into existence, becoming crazy, drying up) has already happened. The subject is now in the continuing result of that past process. 

## Common Verbs

| Basic Form (Action) | Past Tense (Present State) | English Translation | Explanation |
| :--- | :--- | :--- | :--- |
| **잘생기다** | **잘생겼어요** | is handsome / good-looking | *생기다* means "to come into existence/be formed." They were "formed well" in the past, resulting in being handsome now. |
| **미치다** | **미쳤어요** | is crazy | *미치다* means "to go crazy." They "went crazy" in the past, so they are crazy right now. |
| **닮다** | **닮았어요** | looks like / resembles | The resemblance is a result of a past event (like inheriting traits), which continues today. |
| **마르다** | **말랐어요** | is skinny | Reflects a current condition of being thin. (*말라요* would mean actively drying, like hair). |
| **틀리다** | **틀렸어요** | is wrong / incorrect | The mistake occurred in the past, resulting in the current state of being incorrect. |
| **맞다** | **맞았어요** | is right / correct | The action of being correct happened, resulting in the current correct state. |

## Noun Modification

This logic extends to adjective forms modifying nouns. To say a "crazy person" or "handsome person", the past tense modifier **~ㄴ/은** is used, because the state is already achieved.
* **미친 사람** (crazy person) — not *미치는 사람*
* **잘생긴 사람** (handsome person) — not *잘생기는 사람*
* **틀린 주소** (wrong address) — not *틀리는 주소*

## Relation to Other Tenses
Understanding this base helps map out other timeframes:
* **Present State:** 잘생겼어요 (He is handsome)
* **Past State:** 잘생겼었어요 (He was handsome - double past tense)
* **Future/Assumption:** 잘생길 거예요 / 잘생겼을 거예요 (He will be handsome / must be handsome)

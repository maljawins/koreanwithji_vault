# concept_아무래도

- 정의: "아무래도"는 화자가 어떤 일이 일어날 것 같다고 "생각"할 때 쓰는 부사(probably) — 주로 `것 같다`와 함께 쓰임. 어원은 `아무` + `어떠하다`(형용사 `아무러하다`)의 활용형에서 옴.
- 핵심 형태/규칙:
  - **부사 용법 — "아마도/생각하기에"(probably)**: `것 같다`와 함께 쓰여 화자의 추측을 표현 — `아무래도 그녀가 우리를 만나러 안 올 것 같아요`(아무래도 안 올 것 같다 = She probably won't come), `아무래도 그가 벌써 떠났을 것 같아요`(아마도 벌써 떠났을 것 같다 = He probably already left).
  - **어원 — 형용사 `아무러하다`의 활용**: `아무`(무엇이든, [Lesson 25]에서 학습 — 명사 앞에 붙어 부정어미와 함께 "아무 것도 아니다" 등 형성) + `~하다` 계열 형용사 `아무러하다`("어떤 형태로도 ~않다"는 뜻, `아무런 소리도 안 냈어요`=어떤 소리도 안 냈다). `아무러하다`는 흔히 `아무렇다`로 축약(ㅎ불규칙 활용, [[concept_irregular-verbs]] 참조).
  - **`아무렇다` + `~아/어도` → `아무래도`(ㅎ불규칙 결합)**: `아무렇다`에 `~아/어도`("~하더라도")가 결합하면 ㅎ불규칙 규칙에 따라 `아무래도`로 변함 — 그 결과 "아무러해도"(어떤 형태이더라도=상관없이)라는 원래 뜻에서 "아무튼 ~할 것 같다"(probably, 상황이 어떻든 그렇게 될 것 같다는 확신)로 의미가 굳어짐.
  - **`아무렇게나`("carelessly/haphazardly")**: `아무러하다/아무렇다`에 부사화 어미 `~게`를 붙이고(`아무러하게`/`아무렇게`), 강조 조사 `~나`를 더해 "하는 대로 아무렇게나"(별생각 없이/막) — `일을 아무렇게나 하지 마!`(대충/막 하지 마라).
- 예문:
  - `아무래도 제과점이 이미 문을 닫았을 것 같아요.` = The bakery is probably already closed.
  - `일을 아무렇게나 하지 마!` = Don't do it carelessly!

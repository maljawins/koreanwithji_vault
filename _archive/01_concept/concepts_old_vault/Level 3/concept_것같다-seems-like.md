# Seems Like / Probably: ~(으)ㄹ / ~ㄴ/은 / ~는 것 같다

The grammar form **~것 같다** is one of the most common ways to express probability, assumptions, or that something "seems like" or "looks like" a certain way. It combines the noun-describing principle (`~는 것`) with the adjective `같다` (to be the same/like).

## 1. Future / Probability: ~ㄹ/을 것 같다
When attached to the future attributive modifier `~ㄹ/을`, it translates to "might," "probably will," or "seems like it will." It expresses a guess about the future.
* **비가 올 것 같아.** (It will probably rain / It seems like it will rain.)
* **우리는 늦을 것 같아요.** (We will probably be late.)

## 2. Present / Past Evidence: ~ㄴ/은 것 같다 & ~는 것 같다
When attached to past (`~ㄴ/은`) or present (`~는`) modifiers, it indicates an assumption based on some form of evidence the speaker has seen or heard.
* **선생님이 열심히 공부한 것 같아요.** (It seems that the teacher studied hard [based on hearing he got into a top university].)
* **엄마는 기다리고 있는 것 같아요.** (It seems as though mom is waiting now [based on a recent phone call].)

## 3. Difference in Past Assumptions
* **~ㄴ/은 것 같다** implies the speaker has some indirect evidence (e.g., seeing an empty plate -> *다 먹은 것 같다*).
* **~았/었을 것 같다** implies a more blind guess without direct evidence (e.g., *다 먹었을 것 같다* -> they probably ate it all).

## 4. With Adjectives & Nouns
* **Adjectives:** Use `~ㄴ/은 것 같다` (e.g., *아픈 것 같아요* - seems to be hurt / *비쌀 것 같아요* - seems like it will be expensive).
* **Nouns:** Use `~인 것 같다` (e.g., *학생인 것 같아요* - seems to be a student).

## 5. 그렇다 (To be so/like that) + 것 같다
It is very common to combine `그렇다` with this form to say "I think so," "Probably," or "It seems like it."
* **그럴 것 같아요.** (Probably / I think it will be so. - Future)
* **그런 것 같아요.** (Probably / It seems to be the case right now. - Present)

## 6. 불규칙 어간 + 것 같다 (L4-05 심화)
`것 같다` 앞의 관형형은 [[concept_descriptive-verb-modifier]]·[[concept_action-verb-modifier-는]]·[[concept_modifier-future-을ㄹ]]과 완전히 동일한 불규칙 규칙을 따른다.
* **ㅂ불규칙**: `맵다`→`매운 것 같아요`(매울 것 같아요=future), `춥다`→`추운 것 같아요`.
* **ㄹ불규칙**: `길다`→`긴 것 같아요`, `멀다`→`먼 것 같아요`.
* **동작동사 과거형은 묘사동사 현재형과 똑같이 생김(헷갈리기 쉬움)**: `찾은 것 같다`(동작동사 과거="찾았다고 생각")와 `작은 것 같다`(묘사동사 현재="작다고 생각")는 형태(은)만 보면 구분 안 됨 — 동사 종류로 판단해야 함.
* **있다/없다는 현재에서만 는**: `재미있는 것 같아요`(현재)이지만 과거·미래는 정상 규칙 — `있었던 것 같아요`(과거), `있을 것 같아요`(미래).

## 7. 부정형: "안 ~것 같다" vs "~것 같지 않다" (L4-05 심화)
영어는 "I don't think it's good"처럼 **think를 부정**하지만, 한국어는 반대로 **내용(형용사/동사)을 부정**하는 게 훨씬 자연스럽다.
* **자연스러움**: `안 좋은 것 같아요`(직역: 안 좋다고 생각) — 형용사를 안/못/지않다로 부정한 뒤 것 같다를 붙임.
* **~것 같지 않다는 강조 전용**: `좋은 것 같지 않아요`도 문법적으로 맞지만 훨씬 덜 씀 — 상대 의견에 강하게 반박·확신을 표현할 때만("나는 절대 그렇게 생각 안 해" 뉘앙스) 사용. 예: `그런 것 같아요?`(그렇게 생각해?) 질문에 강하게 부정할 때 `그런 것 같지 않아요`(전혀 안 그런 것 같아).

## 8. 시제 제약 — 왜 과거·미래로 잘 안 쓰나 (L4-05 심화)
`것 같다`는 사실상 **현재형(같아요)에서만** "I think"라는 의미로 자연스럽다.
* **과거(같았어요)**: 가능은 하지만("~인 것 같았어요"=그때는 그런 것 같았다) 흔하지 않음 — 과거의 생각을 말할 땐 [[concept_고생각하다-opinion|고 생각했어요]]가 더 자연스러움.
* **미래(같을 거예요)**: 거의 절대 안 씀 — "그것은 ~인 것 같을 것이다"는 논리적으로 어색("It will seem like..."). 대신 앞의 동사/형용사 자체를 미래형으로 바꿔서 표현(`매울 것 같아요`=현재형 같다+미래 관형형, 이게 정상 패턴).

## 9. ~것 같다 vs ~고 생각하다 (직접성 비교, L4-05 심화)
자세한 활용 비교는 [[concept_고생각하다-opinion]] 참고. 핵심 요지: **것 같다=간접·부드러움(회화체 기본값)**, **고 생각하다=직접·단정(강한 확신/문어체)**. 한국 문화가 "나(I)"를 강하게 내세우기보다 집단 조화를 중시하는 경향이 것 같다의 압도적 사용 빈도(사실 관계에도 것 같다를 쓰는 경우가 흔함)에 반영돼 있다는 문화적 해설이 Amira 세션에서 제시됨.
* **제 생각에는**: "In my opinion" — 문장 앞에 붙이는 대안, 동사 활용 변경 불필요.
* **같아 vs 같애 발음**: 표준 표기는 `같아요`이지만 실제 발음(특히 서울)은 `같애요`가 압도적으로 흔함 — 쓸 때는 반드시 같아요, 들을 때는 같애요도 정상으로 인지할 것.
* **이유는 이유, 때문 아님**: 이유를 관형절로 수식할 땐 반드시 `이유` 사용(`~기 때문인 것 같아요`처럼 때문을 이유 자리에 직접 명사로 놓지 않음).

## 10. 것 같다 vs 나 보다 (확신도 비교, Amira L3-19)
`~것 같다`와 `~나 보다`(동사) / `~은가/ㄴ가 보다`(형용사)는 둘 다 "추측"을 나타내지만 확신도(certainty)가 다르다.
* **것 같다 = 생각/의견**: 근거가 반드시 지금 눈으로 보는 것일 필요 없음 — 일반적 생각, 들은 얘기 등도 근거가 될 수 있음. 영어 "I think"에 가까움.
* **나 보다/은가 보다 = 추론/결론**: **지금 관찰 중인 사실**에 근거한 추측 — "It must be" / "It looks like"에 가까움. `것 같다`보다 **확신도가 높음**.
* 비교: `비가 오는 것 같아요`(비가 오는 것 같다는 생각, 확신 낮음) vs `비가 오나 봐요`(빗소리가 들리거나 바닥이 젖은 걸 보고 추론, 확신 높음).
* `나 보다`류는 **`보다`가 항상 현재형**이어야 함(`~은가/나 봤어요`는 틀림) — 관찰 시점이 "지금"이기 때문. 형태: 동사 어간 + `나 보다`, 형용사 어간(받침 유무) + `은가/ㄴ가 보다`.
* 예문: `내가 목소리가 작은가봐.`(아무도 못 들었으니 목소리가 작은가 보다 — 지금 관찰에 근거한 추론)

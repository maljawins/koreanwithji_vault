# concept_오래-오랫동안-오랜만

- 정의: "오래(전부터/동안)"를 축으로 하는 장기간 표현 가족 — 부사 오래, 결합형 오랫동안, 그리고 "오랜만에(오랫만에)"라는 별개 뉘앙스 표현.
- 핵심 형태/규칙:
  - **오래(부사, for a long time)**: 동사 앞에 놓음. 고정 짝꿍 동사: **오래되다**(시간이 오래 지났다 = 사물이 낡음/오래됨, `오래된 영화/카메라/책/차`), **오래 걸리다**(시간이 오래 걸리다).
  - **오랫동안(오래+동안 결합)**: 문자 그대로 "긴 기간 동안" — 오래와 거의 같은 뜻으로 대체 가능하나, `되다`와는 못 씀(`오랫동안 되다`(X) → `오래되다`만 가능).
  - **오랜만(오랫만, 오래간만의 준말)**: 명사 — "오랫동안 하지 않다가 처음"이라는 뜻. `오랜만이에요`(오랜만입니다/오랜만이다)=Long time no see(직역: 오랜만이다=오랜만에 만나는 거네). 부사형은 `오랜만에`("~하고 나서 처음으로" = doing something for the first time in a long while): `오랜만에 친구를 만났어요`.
- 예문:
  - `이 펜이 오래됐어요.` (낡음)
  - `한국어를 18년 넘게 오래 공부했어요.`
  - `오랜만이에요!` (오랜만에 만남)
  - `오랜만에 친구를 만났어요.`

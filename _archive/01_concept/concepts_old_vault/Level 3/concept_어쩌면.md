# concept_어쩌면

- 정의: "maybe/perhaps"라는 뜻의 부사. 사전적으로는 "만약"·"아무리"와 비슷하게 문장에서 빼도 큰 의미 변화가 없는 "느낌 부사" 계열이지만, 실제로는 두 가지 뚜렷이 다른 용법이 있다.
- 핵심 형태/규칙:
  - **용법 1 — 확신 없는 추측**: 화자가 어떤 상황을 확신 없이 추측할 때 씀. `~ㄹ/을지(도) 모르다`([[concept_ㄹ을지도-모르다]])와 함께 쓰이는 경우가 많음 — `어쩌면 그녀가 올지도 몰라요` = She might come / I don't know if she'll come / Perhaps she'll come.
  - **용법 2 — 놀라움/감탄 강조**: "어떻게 이렇게/그렇게/저렇게 ~할 수 있지?"처럼 놀라움을 강조할 때도 씀 — `어쩌면 이렇게 일찍 왔어요?` = How is it possible that you came this early? 이 경우 `어떻게`로 바꿔써도 뜻이 거의 같음(`어떻게 이렇게 일찍 왔어요?`)이 더 흔하게 쓰이는 표현.
- 예문:
  - `어쩌면 우리가 내일 갈 수 있을지도 몰라요.` = Perhaps we'll be able to go tomorrow.
  - `어쩌면 비가 저렇게 많이 왔어요?` = How is it possible that it rained that much?
- 주의/흔한 오류: 영어 번역("maybe"/"perhaps")에 얽매이지 말 것 — HTSK 저자는 "어쩌면"의 의미를 영어 번역보다 한국어 문맥(23과 그렇다/그렇게 계열, 30과 ~는지 계열)에 기반해 이해하라고 강조.

# concept_object-marker-for-locations

- 정의: [[concept_object-markers|목적격 조사 을/를]]이 예외적으로 **목적지/장소**를 마킹하는 특수 용법. 일반적으로 목적지는 [[concept_에-vs-에서|에]]나 (으)로를 쓰지만, 특정 범용 장소 명사군에 한해 을/를도 자연스럽게 쓰임.
  > ⚠️ 커리큘럼 맵상 이 개념은 원래 "L2-14 Object Marker for Locations"로 별도 코드가 배정돼 있으나, 실제 매핑 소스 파일은 물리적으로 `2-13 Object Marker for Locations` 폴더(구버전 번호, 리네임 누락)에 있어 coverage.py가 L2-13으로 집계함. → `_ambiguity_log.md` L2-14 skip 항목 정정 참조.
- 핵심 형태/규칙:
  - **3중 대비 — 에 / (으)로 / 을·를**:
    - 에: 그 지점으로 직접 이동("~에 가다"=직접 그곳으로).
    - (으)로: 그 방향으로("~쪽으로 가다"는 느낌 — 실제 이동 뉘앙스는 로가 에보다 자연스러운 경우도 많음).
    - 을/를: 그곳이 **명확한 목표/의도된 목적지**임을 강조("~을 가다"=그곳에 가는 게 확고한 목표).
  - **범용·일반 장소 명사에 한정된 관용 표현**: 아무 명사에나 붙는 게 아니라 **정해진 소수의 범용 장소**에만 자연스러움 — 집을 가다·병원을 가다·학교를 가다·유학을 가다·여행을 가다(에/으로보다 압도적으로 흔함)·산을 가다·시집을 가다/장가를 가다(결혼)·군대를 가다.
  - **특정·임시 장소엔 부적절**: "친구 집" "파티" 같은 구체적/일시적 장소엔 을/를 대신 반드시 에/으로 사용.
  - **을/를이 한 문장에 중복 등장 가능**: 원래 목적어(친구를 만났다)와 장소(학교를)가 동시에 을/를을 취해도 문법적으로 정상 — `학교를 가고 있었는데 친구를 만났다`.
- 예문:
  - `학교를 가고 있었는데 친구를 만났다.`
  - `여행을 가요.` (여행에/으로 가요보다 훨씬 흔함)
  - `군대를 가다.` / `유학을 가다.`
- 주의/흔한 오류: 목록에 없는 임의 장소(예: "친구 집을 가다")에 을/를을 붙이면 어색함 — 반드시 관용적으로 굳어진 범용 장소에만.

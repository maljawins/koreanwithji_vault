# concept_pronoun-particle-contractions

- 정의: 대명사(저/나/너)·지시대명사(이것/그것/저것)가 조사(을/를·은/는·이/가)와 결합할 때 흔히 줄어드는 고정 축약형. [[concept_particle-omission|조사 생략]]과 짝을 이루는 개념 — 아예 빼는 대신 "압축해서 말하기".
- 핵심 형태/규칙:
  - **목적격 축약(을/를)**: `저를`→`절`, `나를`→`날`, `너를`→`널`. 조사를 아예 생략하는 것보다 이 축약형이 더 안전(뜻이 명확히 유지되면서 발음만 빨라짐).
  - **주제격 축약(은/는)**: `저는`→`전`, `나는`→`난`, `너는`→`넌`. **맨 대명사(저/나/너)만 딱 말해도 원어민은 자동으로 "~는"(주제)이 생략된 것으로 해석** — 목적격(~를)로 오해하지 않음(단, 대화 맥락에 따라 "저 좋아해요"처럼 완전 생략은 여전히 애매할 수 있으므로 아래 "일반 원칙" 참고).
  - **것+은 → 건**: `이것은`→`이건`, `그것은`→`그건`, `저것은`→`저건`.
  - **것+이 → 게**: `이것이`→`이게`, `그것이`→`그게`, `저것이`→`저게`. **이 형태는 주격 조사를 아예 빼면 안 됨** — `이거`/`그거`/`저거`(조사 없이)라고만 하면 원어민은 자동으로 주제격 축약형(이건/그건/저건)으로 알아들음(주격이 아니라).
  - **것+을 → 걸**: `것을`→`걸`(목적격 축약). 것 단독은 `거`로도 줄지만(이거/그거/저거), 다른 형태의 것(예: `~는 것`)은 항상 거로 줄지는 않으므로 우선 이거/그거/저거 3개만 확실히 익히길 권장.
  - **에는 → 엔 (장소+주제 결합, 비격식)**: `여기에는`→`여기엔`류. 격식 상황엔 부적합.
  - **뭐 → 뭘(목적격)**: `뭐를`이 아니라 `뭐`+를이 `뭘`로 압축.
  - **~에게 → 제게/내게/네게(대명사+에게, 격식 살짝 있음)**: `저에게`→`제게`, `나에게`→`내게`, `너에게`→`네게`. 내게/네게는 발음이 거의 같아 문맥으로 구분.
  - **아이+지시사 → 얘/걔/쟤(비격식 3인칭 대명사, 극존칭 상황 절대 금지)**: `이 아이`→`얘`("이 애"), `그 아이`→`걔`, `저 아이`→`쟤`. "이/그/저 녀석" 같은 캐주얼한 3인칭 지칭.
  - **인용형 축약(하다 결합, 4종 문장 유형)**: `다고 해(요)`(평서)→`대(요)`, `냐고 해(요)`(의문)→`냬(요)`, `자고 해(요)`(청유)→`쟤(요)`, `라고 해(요)`(명령)→`래(요)`. `빨리 오라고 했어`→`빨리 오랬어`. **원래 인용 문법(다고/냐고/자고/라고) 자체를 아직 안 배웠다면 이 축약형은 나중으로 미뤄도 됨** — 원형을 알아야 축약형이 의미가 있음.
  - **하다 축약(하게→게, 하지→치)**: `~하게`→`~게`, `~하지`→`~치`. `그것을 원하지도 않아`→`그걸 원치도 않아`(을→ㄹ, 하지→치 동시 적용).
  - **`~하지 않다` 축약의 정확한 갈림 규칙(받침 소리 기준)**: `하` 앞 음절의 받침이 **ㄴ·ㄹ·ㅁ·ㅇ**이면 `~하지`→`~치`로 줄임(`예민하지 않아요`→`예민치 않아요`). 받침이 **ㄱ·ㄷ·ㅅ·ㅈ**이면 `~하지`→`~지`로 줄임(`넉넉하지 않아요`→`넉넉지 않아요`, `합격하지 못해서`→`합격지 못해서`) — 이쪽은 실제로 ㄴ/ㄹ/ㅁ/ㅇ+치 축약보다 훨씬 드묾.
  - **일반 원칙(언제 애매해지는가)**: 문맥상 화자가 누구를 말하는지 100% 명확할 땐(`저는 좋아해요`→`저 좋아해요`, "내가 좋아한다") 조사 생략이 안전. 하지만 목적어로도 해석될 여지가 있는 문맥에선(예: "메리가 누구 좋아해?"라는 질문에 답할 때) `저 좋아해요`가 `저를 좋아해요`(그녀가 나를 좋아한다)로 오해될 수 있어 **위험** — 초급 단계에선 애매할 것 같으면 조사를 다 유지하는 게 안전.
  - **하다 동사의 을/를 생략, 특히 이중 목적어일 때**: `공부를 하다`→`공부하다`(붙여쓰기로 전환, 띄어쓰기 제거 필수). 목적어가 이미 하나 더 있는 문장(`한국어를 공부를 해요`)에선 **두 번째(하다 직전) 조사를 빼는 게 자연스러움**: `한국어를 공부해요`. 반대로 **첫 번째를 빼면 뜻이 살짝 바뀜**: `한국어 공부를 해요`(="한국어 공부"라는 복합명사를 하나의 대상처럼 취급 — "나는 한국어 공부를 한다"는 뉘앙스).
  - **주격 조사가 생략 가능한 고정 표현**: `도움이 되다`→`도움 되다`(도움 되다가 더 흔함), `인기가 많다`→`인기 많다`(이쪽이 더 자연스러움) — 특정 관용구에 한정, 일반 규칙 아님.
  - **조사(markers) vs 순수 조사(particles)의 결정적 차이**: 은/는·이/가·을/를(marker, 문법적 역할 표시)은 생략 가능하지만, 에게·와/과·만·도 같은 **의미 자체를 담은 조사(particle)는 생략 불가**(빼면 뜻이 아예 사라지거나 바뀜).
  - **위치명사 4종(여기/거기/저기/어디)+에는 예외적으로 에 생략**: `여기(에) 오세요`처럼 에를 빼는 쪽이 오히려 더 자연스러움(다른 장소 명사는 이 예외에 안 들어감 — 마구잡이로 다른 장소에 적용 금지).
- 예문:
  - `절 좋아해요?` (저를 좋아해요?)
  - `이게 뭐예요?` (이것이 뭐예요?)
  - `한국어 공부해요.` (한국어를 공부해요)
  - `여기 오세요.` (여기에 오세요)

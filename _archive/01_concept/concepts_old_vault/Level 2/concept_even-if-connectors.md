# concept_even-if-connectors

- 정의: "even if / no matter (if)"를 뜻하는 한국어 양보 연결어미·표현 계열. 난이도순으로 기초(도)→격식/가정(더라도·지라도)→인용(다고 해도)→예시(만 해도)→무용(봤자·으나 마나)→선택무관(든지)까지 하나의 스펙트럼을 이룸.
  - ⚠️ 매핑 메모: 이 계열을 다룬 두 소스 파일 내부 frontmatter가 각각 "Mapped Ji Lesson: 9-07 More even" / "9-14 No matter"로 표시돼 있음 — 실제로는 Level 9 심화 레슨 매핑 대상인데 물리적으로 2-09 폴더에 위치해 L2 사이클 커버리지에 걸림(2026-08-11 `_ambiguity_log` 기록 대상). 지금 추출은 완료해두되, Level 9 사이클 때 이 페이지를 그대로 재사용/보강할 것.
- 핵심 형태/규칙:
  - **동사+도** (기초): 아/어/여 활용형 + 도 = "verb해도"(even if verb한다). `되다`/`괜찮다`와 결합해 허락 표현("~해도 돼요?")으로 자주 쓰임 → [[concept_아어도-되다]] 참조(허락 표현은 그쪽이 본 개념).
  - **이다/아니다 예외**: 이다→이라도(받침)/라도(모음), 아니다→아니라도. **이라도/라도의 추가 의미**: "적어도, ~라도"(차선 선택) — `이거라도 드세요`(적어도 이거라도).
  - **그래도**: 문장 시작에서 "그래도, 그럼에도"(연결어 아님, 두 문장을 잇는 부사). 고/지만/는데 뒤에도 붙어 대조 강화(`운동하고 그래도 살이 안 빠져요`).
  - **더라도**: 도보다 강조, **화자가 "가능성 낮다"고 생각하는 가정**에 씀. 동사 어간 직결.
  - **지라도**(을지라도/ㄹ지라도): 더라도의 격식/문어체 버전, 가능성 유무 상관없이 사용 가능.
  - **비록**: "비록"은 부사로 지라도·지만과 짝지어 강조 보조(비록 A일지라도 B).
  - **설사**: 부사, 오직 **부정적 결과** 문장에만 사용(더라도·다고해도·지라도와 결합). 명사 "설사"(diarrhea)와 동음이의어 — 문맥 주의.
  - **다고 해도**(라고 해도): 인용형+해도(말해도 축약). "~라고 말하더라도"라는 뜻으로, 남에게 들은 이야기나 가정에 반응할 때 씀.
  - **만 해도 / 만 하더라도**: [[concept_particle-만|만]]+해도. "예를 들어 ~만 봐도, 그저 ~만 해도"라는 예시 제시 표현. `의 경우만 봐도`도 같은 뜻의 대체 표현.
  - **봤자 / 봐야**: "해봤자 소용없다"(해봐도 의미 없음, 무용함 강조). 봐야는 봤자보다 덜 흔함.
  - **(으)나 마나**: 마나 ← 말다(그만두다)에서 파생. "~하나 마나(하든 안 하든) 결과가 같다"는 뜻.
  - **든지(든)**: "A든지 B든지"(A든 B든 상관없이), 의문사+든지(어디든지=wherever). 두 번 반복해 강조 가능.
  - **이고(뭐고)**: 든지의 명사 전용 비격식 버전. "A이고 뭐고"(A고 뭐고 관심없다, 화자의 무시/체념 뉘앙스).
- 예문:
  - `실패하더라도 포기하지 마세요.` (더라도)
  - `문제가 어려워 보일지라도 포기하지 마세요.` (지라도)
  - `이제 맞다고 해도 믿을 수가 없어요.` (다고 해도)
  - `1년 전만 해도 아무것도 없었어요.` (만 해도)
  - `지금 가봤자 다 팔렸을 거예요.` (봤자)
  - `보나 마나 우리 팀이 이기겠지.` ((으)나 마나)
  - `배추김치든 깍두기든 둘 다 좋아요.` (든지)
  - `공부고 뭐고 일단 좀 쉬어요.` (이고 뭐고)
- 주의/흔한 오류: 설사는 반드시 부정적 결과와만; 조차·마저(→[[concept_even-particles-까지-마저-조차]])와 혼동하지 말 것 — 이쪽은 명사가 아니라 절/동사에 붙는 연결어미 계열.

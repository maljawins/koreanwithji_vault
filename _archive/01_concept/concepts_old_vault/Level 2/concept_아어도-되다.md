# concept_아어도-되다

- 정의: "~해도 문제없다/괜찮다"는 뜻으로 **허락(may/is allowed to)**을 나타내는 문법. `되다`(여기선 "잘 되다/문제없이 돌아가다"는 뜻)를 `~아/어도`(~하더라도, regardless of) 뒤에 붙여 만듦.
- 핵심 형태/규칙:
  - **`되다`의 "문제없다" 용법**: `되다`는 본래 "되다(become)"·피동 `되다` 외에, "일이 잘 되다"(일이 잘 풀리다), "이제 됐어"(그만해도 충분해)처럼 **"문제없이 진행되다/충분하다"**는 뜻도 있음 — 이 lesson의 `아/어도 되다`는 이 세 번째 용법에서 파생.
  - **긍정 허락**: 동사 어간 + `아/어도` + `되다` = "~해도 돼(요)" = "you may/are allowed to ~." `네가 일찍 가도 돼` = 일찍 가도 문제없다 = 일찍 가도 돼(허락).
  - **질문형**: "~해도 돼요?" = "May I ~?/Is it okay if I ~?"
  - **부정(할 필요 없음)**: `안` 또는 `~지 않다`로 앞 동사를 부정 + `아/어도 되다` = "~하지 않아도 된다" = "you don't have to/need to ~." `~아/어야 하다`(해야 한다=must)의 정반대 표현.
  - **치환 가능 어휘**: `되다` 대신 `좋다`나 `괜찮다`를 써도 뜻이 같음(`열어도 돼요`=`열어도 좋아요`=`열어도 괜찮아요`).
  - **시제 변형 가능**: 과거(`~아/어도 됐어요`=그때는 괜찮았다), 미래(`~아/어도 될 거예요`=앞으로 괜찮을 것이다) 모두 자연스럽게 활용.
- 예문:
  - `지금 문을 열어도 돼요.` (지금 문 열어도 괜찮다 = 열어도 됨)
  - `제가 일찍 가도 돼요?` (제가 일찍 가도 되나요? = May I go early?)
  - `내일까지 다 안 해도 돼요.` (내일까지 다 할 필요 없다)
  - `그 시험을 합격하기 위해 공부를 안 해도 돼요.` (공부 안 해도 합격 가능 = 공부할 필요 없음)
- 주의/흔한 오류: `~아/어야 하다`(해야 한다=의무)와 정반대 뜻이므로 혼동 주의.

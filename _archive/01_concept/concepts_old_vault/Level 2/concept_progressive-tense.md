# concept_progressive-tense

- 정의: 영어 "~ing"에 해당하는 한국어 진행형 표현 2종. 둘 다 **동작 동사(action verb)에만** 쓰임(형용사·상태동사엔 사용 불가 — "예쁘고 있다" 같은 표현 없음).
- 핵심 형태/규칙:
  - **동사 어간 + 고 있다**: 넓은 시간대의 진행("요즘 ~하고 있어" 같은 습관적/지속적 상태 포함). 있다만 시제 변화(있어요/있었어요/있을 거예요).
    - 미래 promise형 예: `나만 알고 있을게`(나만 알고 있을게 = 비밀을 지키겠다는 약속 표현으로 자주 쓰임).
  - **동사 어간 + 는 중이다**: "~하는 중(中, middle of)"라는 뜻. 지금 이 순간 동작이 한창 진행 중임을 강조(고 있다보다 시점이 더 좁고 구체적).
    - **미래형 없음**: 이다를 "일 거야"로 바꿔도 미래를 뜻하지 않고 **추측**("~하는 중일 거야" = 아마 ~하고 있을 것이다, 짐작)이 됨. 진짜 미래 진행은 `고 있을 거예요`로.
    - **하다 동사는 "~하는" 생략 가능**: `운전 중이에요`(운전하는 중이에요의 축약형, 더 짧고 흔함). 표지판 `영업 중`(영업 중=OPEN)도 같은 패턴.
    - **하다 명사(공부·생각·회의 등) + 중이다는 는 것 없이 바로 결합**: `공부 중이야`(공부하는 중이야의 더 짧은 축약, ~는 것 명사화 단계 자체를 생략). 표지판·안내문에 이 축약형이 매우 흔함: `공사 중`(공사 중=under construction), `상담 중`, `회의 중`, `촬영 중`.
- 예문:
  - `한국에 살고 있어요.` (현재, 지속적 상태 — 고 있다)
  - `운전하고 있었어요.` (과거 진행)
  - `지금 가는 중이에요.` (지금 이동 중 — 는 중이다, 더 구체적인 이 순간)
  - `저녁 먹는 중이었어요.` (그 순간 저녁 먹고 있던 중이었다)
- 주의/흔한 오류: 는 중이다는 미래형이 없음(일 거야는 추측 의미로 변질) — 미래 진행은 반드시 고 있을 거예요 사용.

# concept_comparisons-더-보다-처럼

- 정의: 한국어에서 "더/덜(more/less)", "보다(than)", "같다/다르다/비슷하다(same/different/similar)", "처럼(like)", "가장/제일(most)"로 구성되는 비교 표현 체계.
- 핵심 형태/규칙:
  - **더(more)/덜(less)**: 동사·부사 앞에 놓는 부사. `제가 더 똑똑해요`(내가 더 똑똑함), `이게 덜 비싸요`(이게 덜 비쌈).
  - **명사 A + 명사 B보다 (+ 더/덜)**: "B보다"가 비교 기준("~보다"=than). **보다 단독으로 이미 "more than"을 내포**하지만, 명확성을 위해 더/덜을 같이 쓰는 게 훨씬 흔함. 비교 기준이 되는 명사(즉 "~보다"가 붙는 쪽)가 항상 영어의 "than X" 자리. `민우 씨는 선아 씨보다 귀여워요`(선아보다 민우가 더 귀여움), `원숭이는 저보다 덜 똑똑해요`.
  - **같다/다르다/비슷하다 + with 조사(랑/이랑/하고/과/와)**: "~와 같다"(같음)·"~와 다르다"(다름)·"~와 비슷하다"(비슷함) — 비교 대상은 with류 조사로 표시. `그 셔츠가 제 셔츠랑 같아요`, `그 영화는 책하고 많이 달라요`, `뉴욕은 엘에이와 조금 비슷해요`.
    - **`똑같다` = 완전히/정확히 같다(강조형)**: `같다` 앞에 `똑`을 붙이면 "완전히 똑같다/판박이"라는 강조. 완전히 같지는 않고 "비슷한" 정도면 `같다` 대신 `비슷하다`를 씀 — 같다(동일)와 비슷하다(유사)는 서로 다른 정도를 가리키는 별개 단어.
  - **처럼 + 동사/형용사 = "~처럼 …하다"**: 비슷하다가 "그 자체로 비슷하다"만 말하는 데 비해, 처럼은 **다른 동사/형용사를 수식**해서 "~처럼 구체적으로 어떠하다/어떻게 하다"를 표현 — `저 원숭이는 사람처럼 똑똑해요`(사람과 비슷한 게 아니라 "똑똑함"이 사람 같다는 것), `제 친구는 선생님처럼 잘 가르칠 수 있어요`.
  - **가장/제일(최상급, 완전히 교체 가능)**: 동사·부사 앞에 놓아 "가장/제일 ~하다"(the most). `이 아이스크림이 제일 맛있어요`, `제가 가장 빨리 했어요`.
  - **~한테는/에게는 + 비교 = 주관적 의견 표현**: `저한테는 배구보다 탁구가 더 재밌어요`("나에게는"이라는 조사로 개인적 의견/취향임을 명시).
  - **더는 생략 가능, 덜은 생략 불가(중요 비대칭)**: `보다` 자체가 이미 "more than"을 내포하므로 `더`는 빼도 뜻이 그대로("바나나가 사과보다 많아요"=더 있어도 없어도 "더 많다"는 뜻). 하지만 **덜은 빼면 안 됨** — `보다`만 있으면 자동으로 "더/more" 쪽으로 해석되기 때문에, "덜 예뻐요"에서 덜을 빼면 정반대 뜻("더 예쁘다")이 돼버림.
  - **어순 자유**: `[주어] [비교대상]보다 더 [서술어]` 순서에서 주어와 "~보다" 어구는 자리를 바꿔도 뜻이 같음 — `바나나가 사과보다 더 많아요` = `사과보다 바나나가 더 많아요`.
  - **많이/오래는 더·덜과 쓸 때 생략 가능, 다른 부사는 불가**: `더 많이 먹어요`→`더 먹어요`(생략해도 "더 많이"란 뜻 유지, 양/기간을 다루는 문맥이라서). 하지만 `더 빨리`/`더 열심히`/`더 자주`/`더 느리게`처럼 양·기간이 아닌 다른 특성을 나타내는 부사는 생략하면 뜻이 아예 달라짐(예: "더 자주 가요"에서 자주를 빼면 "더 가요"=단순히 "더 많이 가다"는 양의 뜻으로 변질, 빈도의 뜻이 사라짐).
  - **가장/제일 + 많이/오래 생략 규칙(더/덜보다 더 까다로움)**: `좋아하다·싫어하다·잘하다·못하다` 이 4개 동사와 쓸 때만 많이/오래 생략 가능(`비빔밥을 가장 좋아해요`=자연스러움). 그 외 동사(일하다·운동하다 등)는 생략하면 어색 — 반드시 `가장/제일 많이`(`가장 많이 일했어요`) 또는 `가장/제일 오래`를 붙여야 함.
  - **낫다(irregular, 좋다의 비교 특화형)**: "더 좋다/preferable"의 뜻. ㅅ불규칙 — 요체는 `나아요`(ㅅ 탈락). 두 선택지 중 하나를 선호할 때 씀(예: 영화 고르기). 단순히 "이게 저것보다 좋다"는 `좋다`, "이게 더 마음에 든다/선택하겠다"는 `낫다`. 아플 때 "나았어"(다 나았다=회복했다)로도 매우 흔하게 쓰임(이땐 비교 아님).
  - **만큼("~만큼" = as much as, 정도의 동등 비교)**: 관형형(는/은-ㄴ/던/을-ㄹ) + 만큼으로 활용 — `먹는 만큼`(먹는 정도만큼), `했던 만큼`, `할 만큼`. 부정문과 자주 쓰여 "~만큼 …지 않다"(~만큼은 아니다) 형태로 "not as X as"를 표현: `저는 제 친구만큼 예쁘지 않아요`. 긍정문에서도 동등함을 표현(`제 친구만큼 예뻐요`=친구만큼 예쁨). `얼만큼`=how much(의문사형).
  - **평소/생각 + 보다 관용 조합**: `평소보다`(than usual, `요즘 평소보다 더 바빠요`), `생각보다`(than [I] thought, `도심은 생각보다 멀어요`) — 매우 흔한 굳어진 표현.
  - **조금 더 = a little bit more**: `조금`을 더 앞에 붙여 정도를 완화. `이 방은 조금 더 좁아요`.
  - **더 + 카운터 = "~개/명/번 더"(~more[개수])**: `펜 두 개가 더 있어`(two more pens), `두 번 더 갔어`(went two more times).
  - **덜 → 들 슬랭 발음**: 캐주얼한 자리에서 `덜`을 `들`로 발음하는 귀여운 슬랭 발음이 있음(HTSK 주석).
  - **훨씬 = much more(더의 강조형)**: `더`와 같은 자리에 쓰지만 뜻이 훨씬 강함 — `더` 없이 단독으로도(`훨씬 똑똑해`), `더`와 같이 써도(`훨씬 더 똑똑해`) 뜻 차이 없음.
- 예문:
  - `한국어는 영어보다 더 어려워요.`
  - `이 컴퓨터가 저 컴퓨터보다 더 싸요.`
  - `배구도 탁구처럼 재밌어요.` (배구가 탁구만큼 재밌음)
  - `한국어가 제일 어려워요.`
  - `가을이 겨울보다 더 따뜻해요.` / `이 옷은 저 옷보다 덜 비싸요.`
  - `저는 제 친구만큼 예쁘지 않아요.` (친구만큼은 안 예쁨)
  - `라면보다 밥이 더 나아요.` (밥을 선호)
- 주의/흔한 오류: `덜`을 생략하면 뜻이 반대로 뒤집힘(더의 생략 가능과 혼동 주의). `가장/제일`은 `더/덜`보다 많이/오래 생략 조건이 훨씬 좁음(4개 동사 한정).

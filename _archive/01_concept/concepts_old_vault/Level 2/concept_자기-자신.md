# concept_자기-자신

- 정의: 문장 안에서 이미 언급한 사람을 다시 가리킬 때 쓰는 재귀 표현. `자기` = 그/그녀(이미 언급된 3인칭을 반복 지칭), `자신` = 오직 문장의 주어와 목적어가 **동일 인물**일 때 쓰는 "자기 자신(oneself)".
- 핵심 형태/규칙:
  - **`자기`**: 한 문장 안에서 어떤 사람이 두 번째로 언급될 때(주어=목적어 관계가 아님) 그·그녀 대신 사용. `그는 자기(의) 외모를 좋아해요`(그의 외모를 좋아해요와 같은 뜻).
  - **`자신`**: 주어와 목적어가 완전히 같은 사람일 때만 사용(재귀대명사). 인칭에 따라 앞에 붙는 대명사가 달라짐: `나/내/저/제` + `자신`(1인칭), `너/네` + `자신`(2인칭), `그/그녀/자기` + `자신`(3인칭), `그들` + `자신`(복수). `저는 제 자신을 안 믿어요`(나 자신을 못 믿는다).
  - **`자신에 대해`/`자신에게`**: "자신 자체에 대해/에게"라는 뜻으로 자주 결합.
- 예문:
  - `우리 아들은 자기(의) 일을 항상 혼자 하고 싶어요.` (아들의 일 — 자기=아들 반복 지칭)
  - `그는 자기 자신을 안 믿어요.` (그가 곧 믿지 않는 대상 — 재귀)
  - `저는 한국에서 제 자신에 대해 많이 배웠어요.`
- 주의/흔한 오류: `자기`는 문장 내 주어=목적어 관계가 아닐 때, `자신`은 주어=목적어일 때 — 두 조건을 혼동하지 말 것.

# concept_부터-까지

- 정의: 범위의 시작(부터/from)과 끝(까지/until, up to)을 나타내는 조사 쌍. **기초 도입**만 다룸 — 더 깊은 의미 확장(까지의 "even" 뉘앙스 등)은 L2-13 "에·에서·부터·까지 추가 의미" 사이클에서 별도 보강 예정.
- 핵심 형태/규칙:
  - **부터 = 절대적 출발점("~서부터/이래로")**: `처음부터 우리는 항상 친구였어요`("애초부터"라는 어감, [[concept_에-vs-에서|에서]]의 단순 "from"보다 강함).
  - **시간 범위에는 에서 대신 반드시 부터**: 장소 범위는 에서/까지 둘 다 되지만(`A에서 B까지`), **시간 범위는 부터만**(`두 시부터 세 시까지`, `두 시에서` X).
  - **부터 + 명사 = "먼저/우선"**: `빨리 샤워부터 해`(다른 거 하기 전에 샤워부터/우선).
  - **까지 = "~까지"(도달점)**: 시간·장소 둘 다에 적용. `저녁까지 일하세요`(저녁까지), `학교까지 뛰어갔어요`(학교까지).
  - **A부터 B까지 / A에서 B까지 (범위 표현)**: 장소는 에서~까지, 부터~까지 둘 다 가능; 시간은 부터~까지만.
- 예문:
  - `서울역부터 부산역까지 세 시간 걸려요.` (범위, 장소)
  - `몇 시부터 시간이 되세요?` (몇 시부터=언제부터 시간 괜찮으세요)
  - `저는 세 시까지 시간이 있어요.` (~까지 시간 있다)
  - `집에서 회사까지 지하철을 타요.` (에서~까지, 장소)
- 관련 개념: [[concept_에-vs-에서]], [[concept_even-particles-까지-마저-조차]]

# concept_축약인용-대요-래요-냬요-재요-abbreviated-quoting

## Overview
구어체에서 간접인용 서술어 구문(`-다고 해요`, `-(이)라고 해요`, `-(으)냐고 해요`, `-자고 해요`, `-(으)라고 해요`)을 종결 어미 형태로 축약하여 **`-대요`**, **`-(이)래요`**, **`-냬요`**, **`-재요`**, **`-(으)래요`**로 간편하게 종결하는 표현이다.

## Summary Table

| 기존 간접인용 종결 | 구어 축약 종결 어미 | 예시 |
|---|---|---|
| `-다고 해요` | **`-대요`** / **`-ㄴ/는대요`** | `내일 비가 온대요.` |
| `-(이)라고 해요` | **`-(이)래요`** | `선생님이래요.` |
| `-(으)냐고 해요` | **`-냬요`** | `언제 가냬요.` |
| `-자고 해요` | **`-재요`** | `같이 영화 보재요.` |
| `-(으)라고 해요` | **`-(으)래요`** | `일찍 오래요.` |

## Example Sentences
1. **사장님이 지금 바로 사무실로 올라오래요.**
   - The boss says for you to come up to the office right now.
2. **친구들이 오늘 저녁에 삼겹살 먹으러 가재요.**
   - Friends suggest going to eat pork belly tonight.

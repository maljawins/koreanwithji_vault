# concept_인용명사절-다는것-quoted-fact

## Overview
**`-다는 것`** / **`-(이)라는 것`** / **`-자는 것`**은 간접인용 문절 전체를 명사구(Quoted Fact / Statement Clause)로 포장하여, 특정 주장이나 사실, 개념을 명사 형태로 수식 및 서술하는 구문이다.

## Usage & Distinctions

### 1. ~다는 것 (The fact/statement that...)
- 일반적인 사실이나 진술 내용을 명사절로 만듦.
  - `건강이 최고라는 것을 깨달았다.` (I realized that health is the best).
  - `그가 무사하다는 소식을 들었다.` (I heard the news that he is safe).

### 2. 단순 관형절 (~는 것) vs 인용 명사절 (~다는 것)
- **수영하는 것**: (직접적인 행위) Swimming itself.
- **수영한다는 것**: (수영한다는 사실/의미) The fact or concept of swimming.

## Example Sentences
1. **타인을 이해한다는 것은 결코 쉬운 일이 아닙니다.**
   - Understanding others is by no means an easy thing.
2. **우리가 함께 노력하자는 취지에서 이번 프로젝트를 시작했다.**
   - We started this project with the purpose that we work together.

# concept_가정조건-다면-hypothetical-if

## Overview
**`-다면`** / **`-(이)라면`**은 가정을 강하게 전제하거나 현실적으로 일어날 가능성이 낮거나 가상인 상황(Hypothetical If / Strong Condition)을 시뮬레이션할 때 사용하는 인용계 조건 어미이다.

## Structures & Usage

### 1. 어미 결합
- **동사**: `-ㄴ/는다면` (`내가 다시 태어난다면`).
- **형용사**: `-다면` (`시간이 충분하다면`).
- **명사+이다**: `-(이)라면` (`내가 너라면`).
- **과거 가정**: `-았/었단면` (`그때 조금만 일찍 도착했었다면`).

### 2. 일반 ~면 과의 비교
- **~면**: 일반적인 조건/시간적 계기 ("비가 오면 우산을 쓴다").
- **~다면**: 가상·비현실적·강한 가설 전제 ("다시 젊어진다면...").

## Example Sentences
1. **만약 나에게 10억 원이 생긴다면 여행을 떠날 것이다.**
   - If I hypothetically got 1 billion won, I would go on a trip.
2. **그때 좀 더 신중했었단면 이런 실수를 하지 않았을 텐데.**
   - If I had been a bit more careful back then, I wouldn't have made such a mistake.

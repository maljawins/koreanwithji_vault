# concept_셈치다-셈이다-치고는-supposition

## Overview
**`-셈치다`** / **`-셈이다`** / **`-치고는`** / **`-치다`**는 실제로 그런 것은 아니지만 그렇다고 간주하거나 해석하는 가정·추정·평가를 표현하는 구문이다.

## Key Structures

### 1. ~셈치다 / ~셈 치다 (Suppose that / Consider as if)
- 실제 상황은 아니지만 가정하여 행동하거나 처리함.
  - `잃어버렸다 셈 쳐.` (Just consider it lost / Write it off).

### 2. ~(ㄴ/은) 셈이다 (It's considered / effectively that)
- 최종 결과를 계산했을 때 결국 그런 셈이 됨.
  - `할인을 받아서 공짜로 산 셈이에요.` (With the discount, I effectively got it for free).

### 3. ~치고는 (For / Considering that it is — beyond expectation)
- 그 부류치고는 의외로 낫거나 못하다는 평가.
  - `초보치고는 정말 잘 하네요.` (For a beginner, you're really doing well).

### 4. ~치고 (Without exception / All)
- 같은 부류에서 예외 없이 모두.
  - `한국 사람치고 김치를 모르는 사람은 없다.` (Among Koreans, there is no one who doesn't know kimchi).

## Example Sentences
1. **그 비용은 투자라고 셈치고 아깝다 생각하지 않겠어요.**
   - I'll consider that cost as an investment and won't think of it as a waste.
2. **신인 작가치고는 문체가 상당히 세련됐습니다.**
   - For a debut author, the writing style is quite refined.

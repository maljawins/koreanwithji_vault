# concept_형식명사-바-formal-clause

## Overview
**`-는 바`** / **`-ㄴ/은 바`** / **`-(이)ㄴ 바`**는 **`것`**과 유사하지만 격식체·문어체에서만 쓰이는 형식명사(Formal Written Noun Clause)이다. 앞선 내용이나 사실을 지시하거나 근거로 삼아 뒤 절을 이어줄 때 사용한다.

## Structure & Comparison

### ~바 (Formal) vs ~것 (General)
| | ~것 | ~바 |
|---|---|---|
| 사용 등록 | 일상·격식 모두 가능 | 격식·문어 전용 |
| 예시 | `결정한 것을 따른다` | `결정한 바를 따른다` |

### 주요 패턴
- **알려진 바에 의하면**: According to what is known.
- **위에서 언급한 바와 같이**: As mentioned above.
- **있는 바**: The fact that there is.

## Example Sentences
1. **위원회에서 결정된 바에 따라 행사가 취소되었습니다.**
   - In accordance with what was decided by the committee, the event was cancelled.
2. **알려진 바와 같이 이번 사안은 매우 심각합니다.**
   - As is known, this matter is very serious.

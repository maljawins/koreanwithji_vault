# concept_이야말로-고서야-emphasis-only-after

## Overview
**`-(이)야말로`**는 다른 것들 중에서 바로 그것이 가장 적합하거나 진정한 것임을 강조(Exactly that / The one and only / If anything, it is...)하며, **`-고서야`**는 선행 행위를 완료한 후에야 비로소 다음 일이 가능함(Only after doing / Not until)을 나타낸다.

## Key Structures

### 1. ~(이)야말로 (It is exactly X / X is the one)
- 주어나 특정 대상을 다른 후보들보다 강하게 부각함.
  - `그야말로 기적이에요.` (That is truly a miracle).
  - `노력이야말로 성공의 열쇠입니다.` (Effort is the true key to success).

### 2. ~고서야 (Only after... / Not until...)
- 선행 행위가 완전히 끝난 다음에야 비로소 뒤의 일이 가능하거나 깨닫게 됨.
  - `직접 겪고서야 그 어려움을 이해했습니다.` (Only after experiencing it myself did I understand that difficulty).

## Example Sentences
1. **이 순간이야말로 내 인생에서 가장 소중한 기억입니다.**
   - This moment is exactly the most precious memory in my life.
2. **오랜 시간이 지나고서야 그 선택이 옳았음을 알게 되었다.**
   - Only after a long time had passed did I realize that choice was right.

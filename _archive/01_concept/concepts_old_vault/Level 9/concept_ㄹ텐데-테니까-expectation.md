# concept_ㄹ텐데-테니까-expectation

## Overview
**`-(으)ㄹ 텐데`**와 **`-(으)ㄹ 테니까`**는 `-ㄹ 터이다`에서 파생된 표현으로, 화자의 추측·예상을 전제로 하여 뒷말에 대한 배경 설명 또는 행동 촉구를 연결하는 구문이다.

## Key Structures

### 1. ~(으)ㄹ 텐데 (I presume / It would probably be the case that — setting up background)
- **연결절**: 화자의 예상을 제시하며 뒤 절이 대조·우려·제안·질문으로 이어짐.
  - `피곤할 텐데 좀 쉬세요.` (You must be tired, so please rest a bit).
- **종결형**: 말끝을 흐려 기대나 아쉬움을 표현.
  - `지금쯤 도착했을 텐데요.` (They would probably have arrived by now).

### 2. ~(으)ㄹ 테니까 (Since I / they will certainly do X — giving reason for instruction)
- 화자 자신의 의지나 확신을 근거로 상대에게 행동을 지시하거나 권유.
  - `내가 할 테니까 넌 쉬어.` (Since I'll do it, you rest).

## Example Sentences
1. **길이 막힐 텐데 지하철을 타고 오는 게 낫겠어요.**
   - The road will probably be congested, so it would be better to take the subway.
2. **제가 먼저 연락할 테니까 기다리지 마세요.**
   - I'll contact you first, so don't wait.

# concept_더라도-ㄹ지라도-ㄹ망정-concessive

## Overview
**`-더라도`**, **`-(으)ㄹ지라도`**, **`-(으)ㄹ망정 / -(으)ㄹ지언정`**은 모두 조건이 충족되더라도 뒷절의 내용에 영향을 주지 않음(Even if / Even though / No matter how)을 나타내는 양보 가정 어미이다. **`-더라면`**은 과거 가정(If it had been that way in the past...)을 표현한다.

## Key Structures

### 1. ~더라도 / ~(으)ㄹ지라도 (Even if — general concessive)
- `바쁘더라도 밥은 꼭 먹어야 해요.` (Even if you are busy, you must eat).
- `실패할지라도 도전해야 한다.` (Even if one fails, one must try).

### 2. ~(으)ㄹ망정 / ~(으)ㄹ지언정 (Literary: Even though, at least not that)
- 격식·문어체에서 최악의 경우를 전제하면서 반드시 피할 것을 강조.
  - `굶을망정 남의 것을 탐하지 않겠다.` (Even if starving, I will not covet what belongs to others).

### 3. ~더라면 (Hypothetical Past — If it had been...)
- 과거 상황에 대한 반사실적 가정.
  - `그때 포기하지 않았더라면 지금 달랐을 거야.` (If I hadn't given up then, things would be different now).

## Example Sentences
1. **아무리 힘들더라도 끝까지 해내고야 말겠어요.**
   - No matter how hard it is, I will see it through to the end.
2. **그때 조금만 더 주의했더라면 사고를 막을 수 있었을 텐데.**
   - If we had been a little more careful then, we could have prevented the accident.

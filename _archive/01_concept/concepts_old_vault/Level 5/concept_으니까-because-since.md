# concept_으니까-because-since

## Overview
**`-(으)니까` / `-(으)니`**와 **`~기 때문에`**는 이유·원인(Because / Since)을 나타내는 연결 표현이다.

## Differences & Rules

### 1. -(으)니까 / -(으)니 (주관적 이유 / 명령·청유 결합 가능)
- 화자의 주관적 판단, 인지, 또는 명령/청유 구문에 필수적으로 쓰임.
  - **명령/청유**: `날씨가 추우니까 옷을 입으세요.` (O) / `추워서 입으세요.` (X)
  - **과거 시제 결합**: `늦었으니까 빨리 가자.` (O)

### 2. ~기 때문에 / [명사] + 때문에 (객관적 이유 / 격식)
- 명확하고 객관적인 원인이나 이유를 객관적으로 전달함. (명령/청유 어미와 결합 불가).
  - `비가 오기 때문에 경기가 취소되었습니다.` (The match was canceled because it rained).
  - `시험 때문에 바빠요.` (I am busy because of exams).

## Example Sentences
1. **지금 바쁘니까 나중에 이야기해요.**
   - I'm busy right now, so let me talk later.
2. **독감 때문에 학교에 못 갔습니다.**
   - I couldn't go to school because of the flu.
3. **문을 열어 보니까 아무도 없었다.**
   - When I opened the door (and found out), there was no one.

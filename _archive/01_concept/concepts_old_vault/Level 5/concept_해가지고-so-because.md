# concept_해가지고-so-because

## Overview
**`~아/어 가지고`** (구어체 줄임말 **`~가지고`**)는 `-아/어서`의 대화체(Colloquial) 확장 표현으로, 앞선 상황이 뒤 행동/결과의 원인이나 과정이 됨(So / Because)을 친근하게 표현한다.

## Characteristics & Usage

### 1. 구어체 원인/이유 (Because / So)
- 실생활 대화(구어체)에서 매우 자주 쓰이며, 격식 문서나 공식 발표에서는 `-아/어서`를 사용함.
  - `어제 너무 바빠 가지고 전화를 못 받았어요.` (I was so busy yesterday, so I couldn't pick up the call).
  - `비가 많이 와 가지고 길막혔어요.` (It rained heavily, so the traffic was blocked).

### 2. 순차적 행위 유지 (And then with object)
- 물건을 가지거나 행위를 하여 뒤 동작으로 연결함.
  - `사과를 사 가지고 집으로 돌아왔다.` (Bought apples and brought them home).

## Example Sentences
1. **차거 막혀 가지고 늦었어요.**
   - The traffic was backed up, so I was late.
2. **배가 아파 가지고 조퇴했어요.**
   - Had a stomachache, so I left school early.
3. **음식을 만들어 가지고 친구들과 나눠 먹었습니다.**
   - Made food and shared it with friends.

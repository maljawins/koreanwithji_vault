# concept_위해-러-려고-purpose

## Overview
**`~위해(서)` / `~위한`**, **`-(으)러`**, **`-(으)려고`**, **`-게`**는 목적, 의도, 또는 목표 달성을 위한 행위(In order to / For / So that)를 표현한다.

## Structures & Usage

### 1. ~위해(서) / ~위한 (목적 - For / In order to)
- `[명사] + 위해(서)` 또는 `[동사] + -(으)기 위해(서)`. (명사 수식 시 `~위한`).
  - `가족을 위해 일을 합니다.` (Work for the sake of family).
  - `합격하기 위해 열심히 공부했다.` (Studied hard in order to pass).

### 2. -(으)러 (이동 목적 - In order to go/come)
- 오직 `가다`, `오다`, `다니다` 등 이동 동사와 결합함.
  - `밥을 먹으러 식당에 갔다.` (Went to the restaurant to eat).

### 3. -(으)려고 (의도적 목적 - Intending to / In order to)
- 주어의 의도나 계획된 목적.
  - `빵을 사려고 빵집에 들렀어요.` (Dropped by the bakery to buy bread).

### 4. -게 / -게 하다 (목적 및 사동 - So that / Make to)
- 뒤 행위의 목표 결과나 상태가 되도록 함.
  - `잘 들리게 크게 말씀해 주세요.` (Please speak loudly so that it can be heard well).

## Example Sentences
1. **건강을 위해 매일 운동을 합니다.**
   - Exercise every day for health.
2. **친구를 만나러 카페에 가는 길이에요.**
   - On my way to the cafe to meet a friend.
3. **아이들이 잘 잘 수 있게 불을 껐습니다.**
   - Turned off the light so that the children could sleep well.

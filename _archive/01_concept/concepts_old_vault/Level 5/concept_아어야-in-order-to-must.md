# concept_아어야-in-order-to-must

## Overview
**`-[아/어]야`**는 뒤 절의 결과를 이루기 위해 앞 절의 조건이 필수적임을 나타내는 필수 조건 연결 어미이다. (Only if / Must do A in order to do B).

## Structures & Usage

### 1. -아/어야 (선행 필수 조건)
- 뒤의 일이나 결과를 달성하려면 앞의 행동이 필수적임.
  - `비밀번호를 입력해야 들어갈 수 있어요.` (You can enter only if you enter the password).
  - `열심히 노력해야 성공한다.` (You succeed only if you work hard).

### 2. -아/어야만 (강조)
- `-만`을 덧붙여 앞 조건이 유일무이한 필수 조건임을 강하게 강조함.
  - `직접 경험해 봐야만 알 수 있다.` (Only by experiencing it yourself can you know).

## Example Sentences
1. **약을 먹어야 병이 낫지요.**
   - You'll get better only if you take medicine.
2. **신분증을 보여 줘야만 입장할 수 있습니다.**
   - You can enter only if you show your ID.
3. **충분히 쉬어야 건강을 유지할 수 있어요.**
   - Only by resting sufficiently can you maintain your health.

# concept_으려면-그러려면-conditional-intention

## Overview
**`-(으)려면`**은 의도(`-(으)려고 하다`)와 조건(`-(으)면`)이 결합하여, **"어떤 목적/의도를 이루려면"**(If you intend to / If you want to)을 나타내는 조건 연결 어미이다. 접속부사로는 **`그러려면`**이 쓰인다.

## Structures & Usage

### 1. -(으)하려면 / -(으)려면 (의도 조건 - If you want to)
- 뒤 문장에는 주로 필수 조건(`-아/어야 하다`), 방법/수단이 뒤따름.
  - `한국어를 잘하려면 매일 연습해야 합니다.` (If you want to speak Korean well, you must practice every day).
  - `공항에 일찍 가려면 택시를 타세요.` (If you want to get to the airport early, take a taxi).

### 2. 그러려면 (접속어 - To do so / If you want that)
- 앞 문장의 목표/의도를 받아 그것을 성취하기 위한 전제조건을 밝힘.
  - `시험에 합격하고 싶어요? 그러려면 공부를 열심히 해야 합니다.` (Do you want to pass the exam? To do so, you must study hard).

## Example Sentences
1. **좋은 집에 살려면 돈을 많이 모아야 해요.**
   - If you want to live in a nice house, you need to save a lot of money.
2. **건강해지고 싶으세요? 그러려면 식습관부터 바꾸세요.**
   - Do you want to become healthy? If so, change your eating habits first.

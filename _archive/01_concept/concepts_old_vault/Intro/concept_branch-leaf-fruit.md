# concept_branch-leaf-fruit

- 정의: Ji가 동사 어미(verb ending) 구조를 시각적으로 가르치기 위해 만든 식물 비유. 어간(Stem)에 어미들이 순서대로 붙는 것을 나무가 자라는 과정으로 설명: **Branch(가지) = Tense(시제)**, **Leaf(잎) = Context marker/Sentence type(문장 종류·뉘앙스 어미)**, **Fruit(열매) = Speech level(존댓말/반말)**.
- 핵심 형태/규칙: forms 비움(특정 형태소가 아니라 어미 전체 구조를 설명하는 메타-비유).
  - 어간(Stem) 위에 Branch(시제) → Leaf(context marker/문장종류) → Fruit(speech level) 순서로 쌓인다.
  - Ji가 명시적으로 "내가 만든 비유, 공식 문법 용어 아님"이라고 밝힘 — "구글에 'Korean verb branch' 검색해도 안 나온다."
- 예문: 어간 "먹-"에 시제(Branch)·context marker(Leaf)·speech level(Fruit)을 순서대로 붙여 최종 동사형을 만드는 과정으로 시연(Amira-03에서 TikTok 영상 자료로 보조 설명).
- Amira_Source_Intro-02.md 심화(5가지 어미 변화 유형 — Ji 원문 프롬프트 자료): Ji가 직접 GPT 프롬프트에서 동사 어미를 5종류로 분류 — ① Tense(Branch) ② Context marker/Sentence ending(Leaf) ③ Sentence Type(Statement/Question/Suggestion/Command) ④ Speech level(Fruit) ⑤ **Honorifics**(존경 대상에 대한 사회적 지위 반영, 어간 뒤 아/어 Branch 대신 시/셔를 사용하거나 완전히 다른 단어로 교체). Honorifics는 기존 Branch/Leaf/Fruit 3단 비유에 명시적으로 포함되지 않았던 5번째 축으로, 정리 단계에서 비유 구조에 추가할지 Ji 판단 필요.
- 주의/흔한 오류: 공식 문법 용어가 아니므로 학습자가 다른 자료(HTSK 등)에서 "tense", "sentence ending", "speech level"이라는 표준 용어를 만났을 때 같은 개념임을 연결해줘야 함.

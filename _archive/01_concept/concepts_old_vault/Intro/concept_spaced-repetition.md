# concept_spaced-repetition

- 정의: 뇌의 **망각 곡선(forgetting curve)**을 추적해, 단어를 막 잊어버리려는 순간에 다시 보여주어 장기기억으로 굳히는 복습 시스템 (SRS).
- 핵심:
  - 아무 flashcard 앱이나 안 되고 **SRS 기능이 있는 앱**(예: Anki류)을 써야 한다.
  - 앱이 각 단어의 복습 간격을 자동으로 벌려가며(간격 반복) 최적 타이밍에 노출한다.
  - 단어는 문장 속(in context)에서 외워야 오래 남는다.
- 관련 개념: [[concept_vocab-study-method]], [[concept_comprehensible-input]]

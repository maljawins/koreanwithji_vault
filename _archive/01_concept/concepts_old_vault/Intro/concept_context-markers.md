# concept_context-markers

- 정의: Ji가 "sentence endings"(공식 문법 용어)를 부르는 자신만의 이름. 단순히 문장 종류만 표시하는 게 아니라, 화자의 뉘앙스·감정·태도까지 전달하는 어미라는 점을 강조하기 위해 만든 용어. [[concept_branch-leaf-fruit]]의 Leaf(잎) 단계에 해당.
- 핵심 형태/규칙:
  - 예시 어미: "거든"(이유/배경 설명), "잖아"(상대도 아는 사실 강조), "을래"(의향 묻기), "지"(확인/동의 구함), "구나"(새로 알게 된 사실에 대한 감탄).
  - 같은 핵심 의미를 가진 문장도 context marker를 바꾸면 뉘앙스가 달라짐(High_context_nature_of_Korean.md: "그렇다/그렇네/그렇지/그렇잖아/그렇거든/그렇더라" 모두 "그래"라는 같은 핵심 뜻이지만 전달하는 느낌이 다름 — 전언 느낌, 조심스러운 어조, 청자에 대한 고려, 존대 여부 등을 어미 하나로 압축).
  - **반말/~요체 전용**: 대부분의 context marker는 반말·~요체에서만 씀. `~ㅂ/습니다`(formal) 자체가 이미 "formal"이라는 하나의 context marker이므로, formal체엔 다른 context marker를 겹쳐 쓸 수 없음(단 `잖습니까`는 예외 — 아래 참고).
  - **`~네(요)`**: 방금·즉석에서 처음 알아챈 것에 대한 즉각적 반응("오!"에 가까움). 어간+`네요`(ㄹ받침은 ㄹ 탈락 후: `살다`→`사네요`). `여기 물고기가 있네요`(방금 봄).
  - **`~구나`/`~군(요)`**: `~네(요)`와 달리 곰곰이 생각한 뒤의 깨달음("아하!"에 가까움). 형용사는 어간+`구나` 직접, 동사는 `는`을 끼워 `~는구나`. 반말은 `구나·구만·군`(구만/군은 혼잣말투), 존댓말은 오직 `군요`.
  - **`~지(요)`**: 확인(confirmation)이 핵심. 질문형(`~지(요)?`)은 "그렇지?"처럼 청자의 동의를 구함(Yes/No 질문뿐 아니라 5W1H 질문에도 억양만 바꿔 사용). 평서형은 "당연하지"처럼 화자 스스로 확신을 표현. 존댓말 명령/제안형(`~(으)시죠`)은 "~하시죠"처럼 정중한 권유.
  - **`~겠지(요)`**: 추측+확인("아마 ~겠지?"). `늦었으니 가야겠지`처럼 `~아/어야` 결합형도 있음.
  - **`~아/어야지(요)`**: `겠지`보다 강한 결심·의무. 1인칭="~할 거야"(스스로의 결심), 2·3인칭="~해야 해"(의무 지적).
  - **`~잖아(요)`**: 청자도 이미 알(아야 할) 사실을 상기시킴("~잖아, 알지?"). 어간+`잖아(요)` 고정, 유일하게 formal체 예외형 `잖습니까`가 존재.
  - **`~거든(요)`**: 배경 정보 제시("~거든, 그래서"). 상대가 묻지 않은 이유를 먼저 깔아주는 용도. 상황에 따라 방어적/무심한 뉘앙스로도 들림.
  - **`~더라고(요)`**: 화자가 직접 경험·목격한 것을 회상. 형용사는 반드시 현재형 어간에만 결합(`더웠더라고요`✗, `덥더라고요`✓ — 경험 당시 그 성질이 지금도 유효하다고 느낄 때).
  - **`있다/없다` 예외**: `~나요?`(O), `~은가요?`(X) — 형용사인데도 동사 패턴(나요?)을 따르는 예외로 암기.
  - **`~니?`/`~냐?`**: 둘 다 반말 의문형. `~니?`는 부드럽고 여성적·손윗사람이 손아랫사람에게도 사용. `~냐?`는 남성적·터프한 어투로 친한 남자 사이에서만 무난.
  - **`을/ㄹ까(요)`**: 상대 의견을 구하는 부드러운 제안("~할까요?"). ㄹ 불규칙은 `까`만 추가, ㅂ 불규칙은 `우`+`ㄹ까`, ㅎ 불규칙은 ㅎ 탈락+`ㄹ까`.
- 예문:
  - "먹거든" / "먹잖아" / "먹을래" / "먹지" / "먹었구나" — 같은 동사 "먹다"에 다른 context marker를 붙여 뉘앙스 차이 시연(Amira-03).
  - "이 식당은 사람이 많네요" (방금 관찰) → "아~ TV에 나와서 그렇구나" (정보를 연결해 뒤늦게 깨달음) — 네요 vs 구나 대비.
  - "여기 강남이잖아요" (당연히 알 사실 상기) / "지금 한국 너무 덥거든요, 그러니까 가을에 오세요" (배경정보→조언).
- 주의/흔한 오류: 공식 문법서에서는 "sentence endings"라고 부름 — Ji의 "context marker"라는 명칭은 비공식 용어이므로 학습자가 외부 자료를 볼 때 연결 필요.
- 관련 개념: [[concept_branch-leaf-fruit]], [[concept_high-context-language]], [[concept_rule-of-three]] — Ji가 대화 중 직접 설명한 관계(2026-08-10, 정식 출처는 2-03 Draft 작성 시 보강 예정): context marker는 "느낌/생각을 직접 단정하지 않고 맥락적으로 암시"하는 기능이 있어, 1인칭이 아니면 내면 상태를 직접 서술 못 하게 막는 Rule of Three를 기능적으로 우회하는 수단이 됨. 예: "너는 슬퍼"(직접 단정, Rule of Three 위반) 대신 "너는 슬프잖아"(맥락적 암시로 우회).

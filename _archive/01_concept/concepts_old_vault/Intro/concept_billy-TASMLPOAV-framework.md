# concept_billy-TASMLPOAV-framework

## 정의
Go Billy가 제시한 한국어 어순 슬롯 공식. 문장의 각 요소를 슬롯(slot)으로 표현하여 어순 규칙을 명확하게 보여주는 방식. [[concept_korean-word-order]]의 자식 개념. Ji의 [[concept_STLOHV-framework]]와 본질적으로 유사한 어순 분석 도구이지만 명칭·슬롯 구성·강사가 다름.

## 프레임워크 슬롯 (영상별 표기 변형)
영상마다 단순화·변형되어 표기됨:

| 버전 | 슬롯 표기 | 출처 영상 |
|---|---|---|
| 풀 버전 | **T-A-S-M-L-P-O-A-V** | How to Make Korean Sentences |
| 간략 버전 | **T/S → L → N/O → V** | Korean Sentence Structure BROKEN DOWN |
| 화살표 버전 | **T-or-S → L → N/O → V** | Sentence Connectors #1 Sentence Structure |

풀 버전 슬롯 의미:
- **T** — Time (시간)
- **A** — Adjective / Adverb (형용사/부사)
- **S** — Subject (주체)
- **M** — Manner/Method (방식)
- **L** — Location (장소)
- **P** — Postposition / Particle (후치사/조사)
- **O** — Object (대상)
- **A** — Auxiliary verb (보조 동사)
- **V** — Verb (동사)

## 세부 규칙
- **시간(Time)은 큰 단위 → 작은 단위** 순 (예: 작년 겨울에 → 12월에 → 25일에)
- **형용사는 명사 앞, 부사는 동사 앞**에 위치
- **다중 형용사**를 나열할 때 -고로 연결해 확장
- **어순 변경**: 핵심 의미는 유지되나 강조(emphasis)·뉘앙스가 달라짐

## 원리
[[concept_korean-word-order]]의 "Big Picture to Details" 공통 로직(시간→장소→대상→동사 funnel)과 동일하게 작동하지만, 더 세분화된 슬롯 구조를 제시. [[concept_STLOHV-framework]], [[concept_vicky-TTPOA-framework]]와 본질적으로 같은 어순 논리의 변형.

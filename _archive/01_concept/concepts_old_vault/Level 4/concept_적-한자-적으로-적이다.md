# concept_적-한자-적으로-적이다

## Overview
한자어 명사 뒤에 접미사 **적(的)**을 붙이면, 해당 명사의 성격이나 속성을 가짐을 나타내는 성상 명사/관형사/형용사/부사로 문법적 기능이 확장된다. English: "-ic", "-al", "-ive" (e.g. cultural, economic, scientific).

> [!NOTE]
> 경험을 나타내는 순우리말 의존명사 `적`(`-(으)ㄴ 적이 있다/없다`)과 한자 접미사 `적(的)`은 완전히 별개의 형태소이다.

## Basic Structure & Transformations

### 1. Noun + 적이다 (서술어: ~하다)
- **[한자어 명사] + 적이다**
  - `문화적이다`: to be cultural.
  - `경제적이다`: to be economical / economic.
  - `낙관적이다`: to be optimistic.

### 2. Noun + 적인 + Noun (관형어: ~한)
- **[한자어 명사] + 적인 + [명사]**
  - `문화적인 차이`: cultural difference.
  - `경제적인 문제`: economic problem.
  - `역사적인 건물`: historical building.
  - `감동적인 영화`: touching / moving movie.

### 3. Noun + 적으로 (부사어: ~하게)
- **[한자어 명사] + 적으로**
  - `문화적으로`: culturally.
  - `경제적으로`: economically.
  - `과학적으로`: scientifically.

## Key Usage Notes
- 임의로 모든 한자어에 `적`을 붙일 수는 없으며, 한국어에서 관용적으로 합성되어 쓰이는 한자어에 한해 자연스럽게 사용된다.
- 서술어로 쓰일 때는 `적이다` 형태를 가지며, 명사 수시 시 `적인`, 부사적 수식 시 `적으로` 형태를 취한다.

## Example Sentences
1. **이 영화는 매우 감동적이에요.**
   - This movie is very touching.
2. **우리는 경제적인 문제를 해결해야 합니다.**
   - We need to solve economic problems.
3. **과학적으로 증명된 사실입니다.**
   - It is a fact proven scientifically.
4. **그 사람은 항상 낙관적이에요.**
   - That person is always optimistic.

# ~ㄹ/을 걸 그랬다 & ~지 그랬다 & ~았/었어야 했다 — "Should Have" (후회·격려·객관적 성찰)

- 정의: 과거에 일어났어야 했으나 실제로 이루어지지 않은 행위("should have, but didn't")를 표현하는 문형 집합. 한국어는 **화자(1인칭/후회)**, **청자(2인칭/지적·질책)**, **객관적 성찰(무감정)**, **부드러운 완곡 표현**에 따라 구조가 달라짐.
- 핵심 형태 및 3대 구분:
  1. **후회 (1인칭 "I/We should have") — `~ㄹ/을 걸 그랬다`**:
     - 동사 미래 관형형(ㄹ/을) + `걸` + `그랬다`(활용: 그랬어/그랬어요). 회화체에서는 `그랬다` 생략 가능(`~ㄹ/을 걸`).
     - **부정("shouldn't have")**: `안`이나 `~지 않다` 대신 **`지 말다`** 결합 필수 — `하지 말 걸 그랬어요`(I shouldn't have done that). (`안 할 걸`X)
     - 억양: 끝을 내리거나 평탄하게 발음(질문/추측형 [[concept_ㄹ을걸요-assumption|ㄹ/을 걸요]]와 구분).
  2. **지적/질책 (2인칭 "You should have") — `~지 그랬다` & `~았/었어야지`**:
     - **`~지 그랬다`**: 동사 어간 + `지 그랬다`. **`그랬다` 생략 불가**. "너도 하지 그랬어"(You should have done it too). 약간의 핀잔/질책 뉘앙스.
     - **`~았/었어야지`**: 과거 활용 + `어야지`. 청자에게 직접적으로 따지듯(sassy/harsh scolding tone) 핀잔을 줄 때 사용 — `조심했어야지!`(You should have been careful!).
     - **부정("You shouldn't have")**: `~지 말지 그랬어` 또는 `~지 말았어야지`.
     - **완곡한 대안(상처 안 주기)**: `-았/었으면 좋았을 텐데 / 좋았을 거예요` ("~했으면 좋았을 텐데"로 대안 제시).
  3. **객관적 성찰 (감정 배제 "should have") — `~았/었어야 했다 (됐다)`**:
     - `~아야 하다`(have to)의 과거 완결형. 화자/청자 구분 없이 "당시 마땅히 했어야 하나 안 한 사실"을 객관적으로 진술.
     - **부정("shouldn't have")**: `~지 말았어야 했어요` 또는 `~으면 안 됐어요`(금지형 활용).
- 예문:
  - `나도 파티에 갈 걸 그랬어.` / `더 일찍 잠을 잘 걸.` (1인칭 후회, 걸 그랬다/걸 단독)
  - `이걸 먹지 말 걸 그랬나?` (1인칭 부정 후회, 지 말다)
  - `너도 파티에 가지 그랬어.` / `내 말대로 우산을 가져오지 그랬어.` (2인칭 질책, 지 그랬다)
  - `조심했어야지!` / `미리 물어보지 그랬어.` (2인칭 강한 핀잔)
  - `날씨가 쌀쌀하네요. 옷을 더 두껍게 입고 왔어야 했어요.` (객관적 성찰, 았/었어야 했다)
  - `커피를 마시지 말았어야 했어요.` / `커피를 마시면 안 됐어요.` (객관적 성찰 부정)
  - `더 공부했으면 좋았을 텐데.` (부드러운 대안 제시)
- 주의/흔한 오류: 1인칭 후회(`걸 그랬다`)와 2인칭 질책(`지 그랬다`)의 주어 바꿈 금지. 부정문 작성 시 `안`이나 `지 않다` 대신 반드시 `지 말다` 계열(`지 말 걸`, `지 말지 그랬어`, `지 말았어야 했어요`)을 쓰는 것이 가장 자연스러움.

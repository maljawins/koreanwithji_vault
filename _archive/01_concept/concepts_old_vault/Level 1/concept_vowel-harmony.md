# concept_vowel-harmony

- 정의: 동사나 형용사의 어간에 모음의 성격(양성/음성)에 따라 어울리는 어미를 결합하는 국어학적 현상. 현재시제 아/어 요체 활용의 핵심 기준이 됨.
- 핵심 형태/규칙:
  - **양성 모음 (Bright Vowels - ㅏ, ㅗ)**: 밝고 가벼운 느낌의 모음. 뒤에 어미 **아**가 어울림.
  - **음성 모음 (Dark Vowels - ㅏ, ㅗ 이외의 모든 모음)**: 어둡고 무거운 느낌의 모음. 뒤에 어미 **어**가 어울림.
  - **결합 규칙 (아요/어요 분기)**:
    1. **어간의 마지막 모음이 ㅏ, ㅗ일 때 ➡️ 아(요) 결합**
       - 받침이 있는 경우: 단순히 결합 (예: `닫다` ➡️ `닫` + `아요` ➡️ **닫아요**)
       - 받침이 없는 경우: 모음 축약 또는 탈락 발생
         - 동일 모음 탈락: `가다` ➡️ `가` + `아요` ➡️ `가아요` ➡️ **가요**
         - 모음 합병: `보다` ➡️ `보` + `아요` ➡️ `보아요` ➡️ **봐요**
    2. **어간의 마지막 모음이 ㅏ, ㅗ가 아닐 때 (ㅓ, ㅜ, ㅣ, ㅡ, ㅐ, ㅔ 등) ➡️ 어(요) 결합**
       - 받침이 있는 경우: 단순히 결합 (예: `먹다` ➡️ `먹` + `어요` ➡️ **먹어요**)
       - 받침이 없는 경우: 모음 축약 또는 탈락 발생
         - 동일 모음 탈락: `서다` ➡️ `서` + `어요` ➡️ `서어요` ➡️ **서요**
         - 모음 합병: `배우다` ➡️ `배우` + `어요` ➡️ `배우어요` ➡️ **배워요** (ㅜ+어 ➡️ ㅝ)
         - 모음 합병: `고치다` ➡️ `고치` + `어요` ➡️ `고치어요` ➡️ **고쳐요** (ㅣ+어 ➡️ ㅕ)
         - ㅐ/ㅔ 뒤의 탈락: `보내다` ➡️ `보내` + `어요` ➡️ **보내요**, `세다` ➡️ `세` + `어요` ➡️ **세요** (구어체에서는 어가 거의 생략됨)
    3. **ㅡ 탈락 규칙 (ㅡ Verbs)**:
       - 어간 끝 모음이 `ㅡ`인 경우, `ㅡ`가 탈락하고 앞 음절의 모음에 따라 아/어를 결정함.
       - 예: `바쁘다` (바ㅃ + 아요) ➡️ **바빠요** (앞 모음 ㅏ ➡️ 아)
       - 예: `예쁘다` (예ㅃ + 어요) ➡️ **예뻐요** (앞 모음 ㅔ ➡️ 어)
       - 단음절 ㅡ인 경우: 항상 어 결합 (예: `끄다` ➡️ `끄` + `어요` ➡️ **꺼요**)
    4. **하다의 예외 규칙 (여 불규칙)**:
       - `하다`로 끝나는 동사는 유일하게 어미 `여`와 결합하여 `하여`가 되며, 구어체에서는 항상 **해(요)**로 축약됨. (예: `공부하다` ➡️ `공부해` / `공부해요`)
- 예문:
  - `창문을 닫아요.` (I close the window.) - 양성 모음 + 받침 있음 ➡️ 아요
  - `영화관에 가요.` (I go to the movie theater.) - 양성 모음 + 받침 없음 ➡️ 가요 (동일 모음 탈락)
  - `한국어를 배워요.` (I learn Korean.) - 음성 모음 + 받침 없음 ➡️ 배워요 (우+어 합병)
- 주의/흔한 오류:
  - `하다`는 절대 `하아요`나 `하여요`로 발음하지 않고 오직 **해요**로 축약해 쓴다는 예외 규칙과, `바쁘다`가 `바뻐요`가 아니라 `바빠요`가 되는 ㅡ 탈락 원리를 잘 혼동하므로 반복 연습이 필요함.

# concept_formal-speech

## 개념 정의
**Formal speech(하십시오체 / Formal High)**는 화계(Speech Levels) 체계 중 가장 격식 있고 정중하게 상대를 예우하는 최고 레벨의 존댓말입니다. 주로 공적인 장소, 뉴스 보도, 군대, 격식 있는 비즈니스 프리젠테이션 등에서 선호됩니다.

---

## 주요 내용 / 용법

### 1. 문법적 실현
- **어간 + `~(습)니다` / `~(습)니까?`**: 
  - 받침이 없을 때: `-ㅂ니다` / `-ㅂ니까?` (예: 가다 ➡️ **갑니다 / 갑니까?**)
  - 받침이 있을 때: `-습니다` / `-습니까?` (예: 먹다 ➡️ **먹습니다 / 먹습니까?**)
- **명사 + `입니다 / 입니까?`**: 이다(Copula) 결합 시 받침 유무와 상관없이 고정형태로 쓰입니다.
  - 예: 학생 ➡️ **학생입니다**
  - 예: 의사 ➡️ **의사입니다**

### 2. 사회적 어조 (다나까)
문장의 결미 어미가 `~다` 혹은 `~까`로 끝나기 때문에, 군대나 격식 사회에서는 속칭 **'다나까'**체라고 불립니다. 현대 일상 회화에서만 지나치게 이 체를 고집하면 매우 딱딱하고 거리가 있는 성격으로 비춰질 수 있으므로 상황에 맞게 `[[concept_polite-speech|Polite speech(해요체)]]`와 섞어 사용합니다.

# concept_plain-form

## 개념 정의
**Plain form(해라체 / Formal Low)**은 특정 독자나 청자를 앞에 두고 있지 않은 텍스트 매체나, 대화 시 상대방을 의식하지 않고 스스로 내뱉는 독백(혼잣말)에서 사용하는 기본 형태의 화계(Speech Levels)입니다.

---

## 주요 내용 / 용법

### 1. 문법적 실현
- **동사 어간 + `~ㄴ/는다`**:
  - 받침이 없을 때: `-ㄴ다` (예: 가다 ➡️ **간다**)
  - 받침이 있을 때: `-는다` (예: 먹다 ➡️ **먹는다**)
- **형용사 어간 + `~다`**: 어미 변화 없이 기본형을 그대로 유지합니다.
  - 예: 예쁘다 ➡️ **예쁘다**
  - 예: 좋다 ➡️ **좋다**
- **명사 + `이다/단`**: 이다(Copula) 결합 시 명사 뒤에 `이다` 또는 `다`로 종결됩니다.
  - 예: 책 ➡️ **책이다**
  - 예: 사과 ➡️ **사과다**

### 1-B. 과거·미래 평어형 (L4-07 보강, ~고 생각하다의 전제 문법)
- **과거**: 동사를 이미 과거로 활용한 형태(했어요 등)에서 `요`를 떼고 `다`를 붙임 — `하다`→`했다`, `가다`→`갔다`, `먹다`→`먹었다`. 규칙 단순: "과거 활용형 + 다".
- **미래**: 두 가지 방법. ① 어간+`겠다`(하겠다). ② `을/ㄹ 것이다`(더 흔함) — 흔히 `을/ㄹ 거다`로 축약(것→거, 이다→다).
- **이다/아니다 + 고 결합 시 예외(중요)**: `이다`·`아니다`는 평어가 각각 `이다`·`아니다` 그대로지만, 뒤에 `~고`가 붙는 문형([[concept_고생각하다-opinion|~고 생각하다]] 등)에 쓰일 때는 `다`가 `라`로 바뀜 — `이다`+고 → `이라고`(받침有)/`라고`(받침無), `아니다`+고 → `아니라고`. 미래형 `을/ㄹ 것이다`(=거다)도 `이다`를 포함하므로 같은 예외 적용 — `을/ㄹ 거다`+고 → `을/ㄹ 거라고`(`괜찮을 거라고 생각해요`=I think it'll be okay).
- 예문: `철수가 한국 사람이라고 생각해요`(이다→이라고), `영화가 짧다고 생각했어요`(과거 평어+고), `괜찮을 거라고 생각해요`(미래 거다→거라고).

### 2. 사용 환경
- **글을 쓸 때**: 책, 논문, 신문 기사, 온라인 백과사전(위키백과 등), 일기 등에서는 독자가 불특정 다수이므로 평어(Plain form)를 디폴트로 사용합니다.
- **말을 할 때 (독백)**: 자기 생각을 혼잣말로 표현할 때 씁니다.
  - 예: "아, 배고프**다**." (I'm hungry.)
- **주의**: 대화 중에 청자를 바라보며 이 형태를 사용하면 반말(Casual speech) 혹은 매우 무례하게 명령조로 느껴지는 하대(下待) 표현이 되므로 극도로 유의해야 합니다.

# concept_propositive

- 상위 개념: [[concept_sentence-types]]
- 정의: 화자가 상대방에게 함께 행동할 것을 제안·권유하는 문장 ("Let's~"). 한국어 4대 문장 유형 중 하나.
- 핵심 형태/규칙:
  - **-(으)ㅂ시다 (하십시오체 - 정중한 제안)**: 격식적 또는 정중한 상황에서 함께 행동을 권유.
    - 받침 있음 → **-읍시다** (예: `먹다` → `먹읍시다`)
    - 받침 없음 → **-ㅂ시다** (예: `가다` → `갑시다`)
    - 예: `도서관에 같이 갑시다.` (Let's go to the library together.)
    - 주의: 직장 상사나 연배가 훨씬 높은 윗사람에게는 다소 일방적 어감이 있어, 더 공손한 `-(으)실까요?` / `-(으)시겠습니까?`를 대신 쓸 것을 권장.
  - **-자 (해라체 - 반말 제안)**: 친한 사이나 아랫사람에게 함께 행동을 제안.
    - 예: `내일 만나자.` (Let's meet tomorrow.)
    - 예: `시간이 늦었으니 빨리 가자.` (It's late, so let's go quickly.)
  - **-(으)ㄹ까요? (해요체 - 제안/의견 유도)**: 상대방의 의사를 물어보며 제안을 부드럽게 유도.
    - 받침 있음 → **-을까요?** (예: `먹을까요?`)
    - 받침 없음/ㄹ → **-ㄹ까요?** (예: `갈까요?`, `만들까요?`)
    - 예: `커피 마실까요?` (Shall we drink coffee?)
    - 예: `오늘 같이 영화 볼까요?` (Shall we watch a movie together today?)
  - **해요체 구어 (비격식)**: 명확한 어미 없이 억양과 `같이`를 활용하여 표현하기도 함.
    - 예: `우리 같이 밥 먹어요.` (Let's eat together.)
- 예문:
  - `다 같이 노래합시다.` (Let's all sing together.) [격식]
  - `내일 공부하자.` (Let's study tomorrow.) [반말]
  - `뭐 먹을까요?` (What shall we eat?) [해요체]
- 주의/흔한 오류:
  - `-(으)ㄹ까요?`는 제안 외에도 가능성/추측 의미("~일까요?" = "I wonder if...")로도 쓰임 → [[concept_inquisitive]] 참조.
  - `-(으)ㅂ시다`는 상위자에게 쓰면 어감이 일방적일 수 있음 → `-(으)실까요?`가 더 공손.

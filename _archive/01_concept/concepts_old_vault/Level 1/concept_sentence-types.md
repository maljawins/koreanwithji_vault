# concept_sentence-types

- 정의: 화자의 말하는 의도나 태도에 따라 문장을 평서문, 의문문, 명령문, 청유문의 4가지 기본 범주로 나누어 분류하는 문법 체계.
- 자식 개념:
  1. **평서문 (Declarative)** → [[concept_declarative]]: 화자가 사실·상태를 진술하는 문장.
  2. **의문문 (Inquisitive)** → [[concept_inquisitive]]: 상대방에게 질문하여 대답을 구하는 문장.
  3. **청유문 (Propositive)** → [[concept_propositive]]: 함께 행동할 것을 제안·권유하는 문장 (Let's~).
  4. **명령문 (Imperative)** → [[concept_imperative]]: 청자에게 특정 행동을 요구·지시하는 문장.
- 핵심 통찰 — 해요체의 억양:
  - 해요체(`-아요/어요`)는 **억양(intonation)과 문맥**만으로 4가지 문장 유형이 모두 표현됨.
    - `한국어 공부해요.` ↘ → 평서문 / `한국어 공부해요?` ↗ → 의문문
    - `같이 공부해요.` (부드러운 어조) → 청유문 / `이거 공부해요.` (지시적 어조) → 명령문
  - 구어 교육 시 억양 훈련이 필수.

# concept_irregular-verbs

- 정의: 동사나 형용사가 어미와 결합하여 활용할 때, 일반적인 활용 규칙을 따르지 않고 어간이나 어미의 형태가 예외적으로 변화하는 불규칙 활용 현상.
- 핵심 형태/규칙:
  - **주요 7대 불규칙 활용 유형**:
    1. **ㅂ 불규칙**: 어간 끝 자음 `ㅂ` 뒤에 모음 어미가 오면 `ㅂ`이 `우` 또는 `오`로 변화함.
       - 예: `돕다` ➡️ `도` + `우/오` + `아요` ➡️ **도와요**, `춥다` ➡️ `추` + `우` + `어요` ➡️ **추워요**
    2. **ㄷ 불규칙**: 어간 끝 자음 `ㄷ` 뒤에 모음 어미가 오면 `ㄷ`이 `ㄹ`로 변화함.
       - 예: `듣다` ➡️ `들` + `어요` ➡️ **들어요**, `걷다` ➡️ `걸` + `어요` ➡️ **걸어요** (단, `받다` ➡️ `받아요` 등은 규칙 활용)
    3. **ㄹ 불규칙**: 어간 끝 자음 `ㄹ` 뒤에 특정 자음(`ㄴ, ㅂ, ㅅ` 등) 또는 모음 어미가 올 때 `ㄹ`이 탈락함.
       - 예: `살다` ➡️ `살` + `ㅂ니다` ➡️ **삽니다**, `살` + `으세요` ➡️ **사세요**
    4. **ㅅ 불규칙**: 어간 끝 자음 `ㅅ` 뒤에 모음 어미가 오면 `ㅅ`이 탈락함.
       - 예: `낫다` ➡️ `나` + `어요` ➡️ **나아요**, `짓다` ➡️ `지` + `어요` ➡️ **지어요** (단, `씻다` ➡️ `씻어요` 등은 규칙 활용)
    5. **르 불규칙**: 어간 끝 음절 `르` 뒤에 모음 어미 `아/어`가 오면 `ㅡ`가 탈락하고 `ㄹ`이 하나 더 추가되어 `ㄹㄹ` 형태로 변함.
       - 예: `모르다` ➡️ `몰` + `ㄹ` + `아요` ➡️ **몰라요**, `부르다` ➡️ `불` + `ㄹ` + `어요` ➡️ **불러요**
    6. **ㅎ 불규칙**: 주로 색채 형용사에서 나타나며, 어간 끝 자음 `ㅎ` 뒤에 모음 어미가 오면 `ㅎ`과 어미의 모음이 합쳐져 `애/얘` 형태로 바뀌고 `ㅎ`이 탈락함.
       - 예: `빨갛다` ➡️ `빨갛` + `아요` ➡️ **빨개요**, `그렇다` ➡️ `그렇` + `어요` ➡️ **그래요**
    7. **ㅡ 불규칙 (ㅡ 탈락)**: 어간 끝 모음 `ㅡ` 뒤에 모음 어미가 오면 `ㅡ`가 탈락함 (모음조화에 수반되어 일어남).
       - 예: `예쁘다` ➡️ `예ㅃ` + `어요` ➡️ **예뻐요**, `쓰다` ➡️ `ㅆ` + `어요` ➡️ **써요**
- 예문:
  - `날씨가 너무 추워요.` (The weather is very cold.) - `춥다` ㅂ 불규칙
  - `한국 노래를 들어요.` (I listen to Korean songs.) - `듣다` ㄷ 불규칙
  - `저는 서울에 삽니다.` (I live in Seoul.) - `살다` ㄹ 탈락
- 주의/흔한 오류:
  - 모든 해당 자음 자침 동사가 불규칙인 것은 아니며(예: `닫다` ➡️ `닫아요` (규칙), `좁다` ➡️ `좁아요` (규칙)), 규칙 형과 불규칙 형의 동형이의어를 잘 구분하는 것이 핵심적 문법 학습 포인트임.
  - **인식 팁(Amira 보강)**: ㅂ 불규칙은 서술형용사(ㅏ/ㅓ/ㅕ/ㅗ/ㅜ+ㅂ다)에서 흔하고 좁다가 예외(규칙); 동작동사 ㅂ다는 대개 규칙이나 눕다·돕다·줍다·굽다가 예외(불규칙). ㄷ 불규칙은 뚜렷한 패턴이 없어 암기 필요 — 받다·묻다(bury 의미)·걷다(collect 의미)는 규칙이나 묻다(ask)·걷다(walk)는 불규칙(동음이의어 주의). 르 불규칙 예외는 이르다·푸르다 단 2개뿐. 돕다·곱다는 ㅂ 불규칙 중에서도 유일하게 우 대신 아를 취해 도와요·고와요가 됨(발음상 ㅜㅏ→와).

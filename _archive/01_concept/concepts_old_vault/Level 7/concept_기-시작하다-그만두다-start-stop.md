# concept_기-시작하다-그만두다-start-stop

## Overview
동사 어간 뒤에 명사화 접미사 `-기`를 붙여 **`-기 시작하다`**(To start doing X) 및 **`-기(를) 그만두다`**(To stop/quit doing X)를 구성하여 동작의 시발점과 중단점을 표현한다.

## Structures & Usage

### 1. ~기 시작하다 (Start doing X)
- 특정 행위가 시작되는 시점을 표현함.
  - `비가 내리기 시작했어요.` (It started to rain).
  - `지난달부터 한국어를 배우기 시작했습니다.` (I started learning Korean from last month).

### 2. ~기(를) 그만두다 / 그만하다 (Stop/Quit doing X)
- 진행 중이던 행위를 중단함.
  - `불평하기를 그만두세요.` (Stop complaining).
  - `이제 게임하기를 그만하고 공부해라.` (Stop playing games now and study).

## Example Sentences
1. **아침 9시부터 눈이 내리기 시작했습니다.**
   - It started snowing from 9 AM in the morning.
2. **건강을 위해서 야식 먹기를 그만두기로 했다.**
   - For my health, I decided to stop eating late-night snacks.

# concept_게-히-이-adverbial-derivation

## Overview
**`-게`**, **`-히`**, **`-이`**는 형용사 어간이나 어근 뒤에 결합하여 용언을 뒤따르는 동사나 형용사를 수식하는 부사(Adverbial Forms)로 파생 또는 전환시키는 파생 접사 및 부사형 어미이다.

## Rules & Types

### 1. 부사형 어미 ~게 (Universal Adverb Form)
- 모든 형용사 어간에 생산적으로 붙어 '~하게', '~하는 방식으로'의 의미를 만듦.
  - `맛있다` -> `맛있게 먹다` (Eat deliciously).
  - `편하다` -> `편하게 앉다` (Sit comfortably).

### 2. 파생 부사 접사 ~히 / ~이 (Derived Adverbs)
- **-하다 형용사**: 주로 `-히`로 파생 (`조용하다` -> `조용히`, `솔직하다` -> `솔직히`).
- **받침 이/히 규칙**:
  - `ㅂ` 불규칙 및 `ㅅ` 받침 어간/어근, 중복 어근 뒤에는 주로 `-이`가 붙음 (`가깝다` -> `가까이`, `깨끗하다` -> `깨끗이`, `곳곳` -> `곳곳이`).

## Example Sentences
1. **아이들이 방에서 조용히 책을 읽고 있습니다.**
   - The children are quietly reading books in the room.
2. **손님들이 편하게 쉴 수 있도록 준비했습니다.**
   - We prepared so that guests can rest comfortably.

# concept_ㅡ-ㄹ-여-불규칙

## Overview
**`ㅡ 탈락/불규칙`**, **`ㄹ 탈락`**, **`여 불규칙`**은 어간 모음 `ㅡ`나 어간 받침 `ㄹ`이 특정 어미(모음 어미, ㄴ/ㅂ/ㅅ/ㄹ 어미)와 만날 때 탈락하거나 `하여(해요)`로 변경되는 활용 규칙이다.

## Rules & Conjugation

### 1. ㅡ 탈락 (ㅡ Drop)
- 어간의 `ㅡ` 모음이 모음 어미(`-아/어`)를 만나면 `ㅡ`가 탈락함.
  - `바쁘다`: 바쁘 + 아요 -> `바빠요` (앞 음절 `바`가 양성이므로 `아` 결합)
  - `예쁘다`: 예쁘 + 어요 -> `예뻐요` (앞 음절 `예`가 음성이므로 `어` 결합)
  - `크다`: 크 + 어요 -> `커요`

### 2. ㄹ 탈락 (ㄹ Drop)
- 어간 받침 `ㄹ`이 `ㄴ, ㅂ, ㅅ, 오` 등으로 시작하는 어미를 만나면 받침 `ㄹ`이 탈락함.
  - `살다`: 살 + 습니다 -> `삽니다` / 살 + 으세요 -> `사세요` / 살 + 는 -> `사는`
  - `만들다`: 만들 + 습니다 -> `만듭니다` / 만들 + 는 -> `만드는`

### 3. 여 불규칙 (하 -> 하여/해요)
- `하다`로 끝나는 동사/형용사는 모음 어미 `-아/어`와 결합 시 `하여`로 변하며 구어체에서는 `해요`로 축약됨.

## Example Sentences
1. **요즘 일이 많아서 너무 바빠요.** (바쁘다 -> 바빠요)
   - I have a lot of work these days so I'm very busy.
2. **어디에 사세요?** (살다 -> 사세요)
   - Where do you live?

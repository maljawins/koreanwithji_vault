# concept_ㅂ-ㄷ-불규칙

## Overview
**`ㅂ 불규칙`**과 **`ㄷ 불규칙`**은 모음으로 시작하는 어미를 만날 때 어간의 받침 `ㅂ` 또는 `ㄷ`이 변형되는 대표적인 한국어 불규칙 활용 패턴이다.

## Rules & Conjugation

### 1. ㅂ 불규칙 (ㅂ -> 우 / 오)
- 받침 `ㅂ`이 모음 어미를 만나면 `우`로 변함 (단, `돕다`, `곱다`는 `오`로 변함).
  - `춥다`: 춥 + 아/어 -> `추워요`
  - `어렵다`: 어렵 + 은 -> `어려운`
  - `돕다`: 돕 + 아요 -> `도와요` (특수)

### 2. ㄷ 불규칙 (ㄷ -> ㄹ)
- 받침 `ㄷ`이 모음 어미를 만나면 `ㄹ`로 변함 (단, `받다`, `닫다`, `믿다` 등은 규칙 활용).
  - `듣다`: 듣 + 어요 -> `들어요`
  - `걷다`: 걷 + 으세요 -> `걸으세요`
  - `묻다` (ask): 묻 + 었어요 -> `물었어요`

## Example Sentences
1. **날씨가 너무 추워서 코트를 입었어요.** (춥다 -> 추워서)
   - It was so cold that I put on a coat.
2. **음악을 들으면서 산책을 했어요.** (듣다 -> 들으면서)
   - I took a walk while listening to music.

# concept_input-process-output

- 정의: Ji가 [[concept_language-core]]를 단계적으로 짓기 위해 제시하는 3단계 학습 프로세스 모델.
- 핵심 형태/규칙: forms 비움(추상 프로세스 모델).
  - **Input**: 한국어 "문장"(단어·구가 아님). 짧고 단순한 문장에서 시작해 점차 길고 복잡한 문장으로. [[concept_comprehensible-input]] 근거.
  - **Process**: [[concept_STLOHV-framework]]를 활용한 3단계(VSL-01·02로 갈수록 단순화됨):
    1. 문장을 띄어쓰기로 분해
    2. 각 단어를 사전(번역기 아님)으로 찾기 — "전체 문장을 통째로 번역기에 넣지 말 것" 강조
    3. STLOHV(또는 STPOHV) 식별
    4. 문장 의미 추측(퍼즐 맞추기 비유)
    5. 문법 학습 + 각 단어가 어떻게 결합해 전체를 이루는지 분석
  - **Output**: 배운 문장을 소리 내어 말하기 → 같은 구조로 자기 문장 만들기 → 소리 내어 말하기. 몸이 문장을 physically 느껴야 기억에 남는다는 원리(근육 기억).
- 예문: "나는 지금부터 여기에서 한국어를 열심히 배울 거예요" — VSL-01·02 공통으로 Process 단계 설명에 사용되는 예문.
- 주의/흔한 오류: 없음.
- Intro-03 심화(어휘 학습 적용): [[concept_vocab-study-method]]가 이 Input-Process-Output 모델을 어휘 학습에 특화해 구체적 카드 형식으로 구현. "단어는 반드시 문장 속에서 봐야 하고(Input) 직접 써봐야 한다(Output)"는 원리를 Sentence-Input → Word → Meaning → Sentence-Output 4-section 플래시카드로 운영화.
- Intro-01 심화(레슨 구조에 실제 적용): 각 비디오 레슨 = Input+Process 단계. 레슨마다 첨부된 2개 PDF(레슨 요약·워크시트) 중 워크시트가 Output 단계를 담당하며 3개 섹션으로 구성:
  1. 해당 레슨 관련 추가 예문 + 문장 분해(breakdown)
  2. 단어 목록(완성 문장 아님)을 퍼즐처럼 조합해 문장 완성(연습 섹션)
  3. 학습자가 직접 자기 문장을 창작
  - "그래머를 맹목적으로 외우지 말고 USE하라"는 원칙이 이 워크시트 단계별 설계의 핵심 근거.
- 관련 개념: [[concept_language-core]], [[concept_comprehensible-input]], [[concept_STLOHV-framework]], [[concept_vocab-study-method]], [[concept_linear-scaffolding]]
- **L4-01 심화(팟캐스트 자습법 적용)**: Amira Day17 세션에서 Ji가 방학(자율학습) 기간 대비 팟캐스트 학습법으로 이 모델을 구체 적용 — **Input**: 전체 에피소드를 멈추지 않고 끝까지 들으며 맥락·분위기만 파악(디테일 몰라도 됨). **Process**: 다시 들으며 이번엔 의도적으로 멈춰 문장 분석(사전 사용, Papago 등 번역기 지양). **Output**: 화자의 속도에 맞춰 소리 내어 따라 말하기(shadowing). 3단계를 반드시 순서대로("맥락 먼저, 분석은 두 번째") 지킬 것을 강조.

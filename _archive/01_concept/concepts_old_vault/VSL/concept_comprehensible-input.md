# concept_comprehensible-input

- 정의: 언어학자 Stephen Krashen이 만든 개념. "메시지를 이해할 때만 언어를 습득한다"는 이론. Ji는 이를 [[concept_input-process-output]] 모델의 Input 단계 근거로 인용.
- 핵심 형태/규칙: forms 비움(외부 이론 차용, 한국어 형태 아님).
  - VSL-02가 Krashen 인용을 직접 명시: "We acquire language in one way, and only one way: when we understand messages."
  - Ji의 적용: 완전한 문장(단어·구가 아님)으로 시작해야 문맥(context)이 생기고, 그 문맥이 "noise"를 "message"로 바꿔준다.
  - VSL-01은 이름만 언급, VSL-02는 Krashen 인용 + "Noise → Message" 비유로 더 구체화됨(소스 간 상세도 차이, 모순 아님).
- 예문: 없음(이론 개념).
- 주의/흔한 오류: 없음.
- 제3자 corroborating 자료 심화:
  - Miss Vicky(Steve Kaufmann 폴리글랏 인터뷰): LingQ의 Mini-Stories 같은 입력 중심 자료 활용, "태도·시간·꾸준함"의 3 pillars를 입력 학습 지속의 조건으로 제시.
  - Miss Vicky(The Power of INPUT in Speaking Skills): "Two Pillars of Input Practice" = 꾸준한 노출(constant exposure) + 진짜 이해하려는 노력(genuine comprehension effort). 본인 레벨에 맞는 자료 선택의 중요성 강조.
- 관련 개념: [[concept_input-process-output]], [[concept_language-core]]

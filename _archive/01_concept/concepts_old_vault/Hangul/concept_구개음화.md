- 정의: 끝소리(받침)가 'ㄷ' 또는 'ㅌ'인 형태소가 모음 '이'나 반모음 '이[j]'(여, 야 등)로 시작하는 형식 형태소를 만나면, 입천장소리(구개음)인 'ㅈ' 또는 'ㅊ'으로 바뀌어 발음되는 현상입니다.
- 핵심 형태/규칙:
  - **ㄷ + 이/여** -> **[ㅈ]**으로 발음됨 (예: 굳이 -> [구지])
  - **ㅌ + 이/여** -> **[ㅊ]**으로 발음됨 (예: 같이 -> [가치], 붙여 -> [부쳐])
  - **ㄷ + 히/혀** -> ㄷ과 ㅎ이 결합하여 ㅌ이 된 후(격음화), '이'를 만나 **[ㅊ]**으로 발음됨 (예: 묻히다 -> [무치다])
- 예문:
  - 굳이 -> [구지] (구디 X)
  - 같이 -> [가치] (가티 X)
  - 해돋이 -> [해도지] (해도디 X)
  - 붙여 -> [부쳐] (부텨 X)
  - 묻히다 -> [무치다] (무티다 X)

# concept_ㅎ-pronunciation

- 정의: 한국어의 `ㅎ`은 영어 "H"보다 훨씬 약한 소리라, 실제 발음에서는 특정 환경에서 사라지거나 다른 소리와 합쳐지는 경우가 매우 흔함. 자음+ㅎ이 만나 거센소리로 축약되는 [[concept_격음화]]와는 별개로, 여기서는 **ㅎ이 단독으로 약화/탈락**하는 경우를 다룸.
- 핵심 형태/규칙:
  - **① ㅎ받침+ㅇ으로 시작하는 모음 어미 → ㅎ 탈락**: `좋아요` → [조아요]로 발음(ㅎ이 그냥 사라짐). ㅎ이 뒤따르는 모음과 만날 때 소리 자체가 없어짐.
  - **② 모음 사이(또는 특정 환경)의 ㅎ이 약화·탈락**: 단어 중간의 ㅎ이 완전히 사라지거나 거의 안 들리게 약화됨(정식 표준발음법 규정과 달리 실제 구어에서 매우 흔한 현상). 예: `전화`(phone call)가 [저나]처럼, `올해`(this year)가 [오래]처럼, `감히`(daringly)가 [가미]처럼, `한테`가 [안테]처럼 들림.
- 예문:
  - `좋아요` → [조아요]
  - `전화 왔어요` → [저나 와써요]처럼 들림
  - `한테` → [안테]에 가깝게 발음
- 주의/흔한 오류: 학습자가 표기 그대로 ㅎ을 또박또박 발음하면 오히려 부자연스럽게 들릴 수 있음 — 많이 듣고 따라하며 감을 익히는 게 최선(개별 규칙 암기보다 노출이 중요).

- 정의: 한 음절의 받침 자리에 서로 다른 두 개의 자음이 함께 쓰이는 받침 구조를 '겹받침'이라고 합니다.
- 핵심 형태/규칙:
  - 총 11개의 겹받침이 존재하나, 고어인 'ㄽ'을 제외한 **10개의 겹받침**이 현대 한국어에서 사용됩니다: `ㄳ, ㄵ, ㄶ, ㄼ, ㄾ, ㅀ, ㅄ, ㄺ, ㄻ, ㄿ`.
  - **대표음 결정 원칙** (단독 발음 또는 뒤에 자음이 올 때):
    - **첫 번째 자음 발음 (First-letter Dominant)**: `ㄳ`([ㄱ]), `ㄵ`([ㄴ]), `ㄶ`([ㄴ]), `ㄼ`([ㄹ]), `ㄾ`([ㄹ]), `ㅀ`([ㄹ]), `ㅄ`([ㅂ]).
    - **두 번째 자음 발음 (Second-letter Dominant)**: `ㄺ`([ㄱ]), `ㄻ`([ㅁ]), `ㄿ`([ㅂ] - ㅍ가 ㅂ 대표음으로 변화).
    - 예외: '닭'의 경우 두 번째 자음인 [ㄱ]으로 발음되어 ㄹ은 완전히 묵음 처리됩니다.
  - **연음 규칙** (뒤에 모음 'ㅇ'이 올 때):
    - 겹받침의 **첫 번째 자음은 제자리에 남고, 두 번째 자음이 다음 음절의 초성으로 연음**되어 발음됩니다. (예: 앉아 -> [안자])
    - 이때 'ㄶ, ㅀ'의 'ㅎ'은 모음을 만나면 탈락하여 무음 처리됩니다. (예: 않아 -> [아나])
  - **자음동화 및 경음화 적용**:
    - 뒤에 자음이 올 때, 겹받침의 대표음 자음과 다음 자음 사이에 경음화 또는 격음화 등의 자음동화 규칙이 그대로 적용됩니다.
    - 예: 앉다 -> [안따] (경음화), 않고 -> [안코] (ㅎ 격음화), 값만 -> [갑만] -> [감만] (비음화).
- 예문:
  - 넋 -> [넉] (단독) / 넋이 -> [넉시] (연음) / 넋만 -> [넝만] (비음)
  - 닭 -> [닥] (단독)
  - 삶 -> [삼] (단독) / 삶다 -> [삼따] (경음화)
  - 값 -> [갑] (단독) / 값이 -> [갑시] (연음) / 값도 -> [갑또] (경음화)

- 정의: 두 개의 단어(또는 형태소)가 결합하여 합성 명사를 이룰 때, 뒷말의 첫소리가 된소리로 바뀌거나 ㄴ 소리가 덧나는 사잇소리 현상을 표기상 받침 'ㅅ'으로 나타내는 맞춤법 규칙입니다.
- 핵심 형태/규칙:
  - **표기 조건**:
    - 앞말이 모음으로 끝나고 (받침이 없고),
    - 두 단어 중 최소 하나는 **순우리말(고유어)**이어야 합니다 (한자어+한자어 합성어는 원칙적으로 사이시옷을 쓰지 않으며, 예외적인 6개 단어: 곳간, 찻간, 툇간, 셋방, 숫자, 횟수만 허용).
  - **소리 변화 유형**:
    - **유형 1 (뒷말이 된소리가 됨)**: 뒷 단어의 예사소리(ㄱ, ㄷ, ㅂ, ㅅ, ㅈ)가 된소리(ㄲ, ㄸ, ㅃ, ㅆ, ㅉ)로 발음되는 경우. (예: 내+가 -> 냇가 [내까/낻까])
    - **유형 2 ('ㄴ' 소리 덧남)**: 뒷말의 첫소리 ㄴ, ㅁ 앞에서 ㄴ 소리가 덧나는 경우. (예: 이+몸 -> 잇몸 [인몸])
    - **유형 3 ('ㄴㄴ' 소리 덧남)**: 뒷말의 첫소리 모음(이, 야, 여, 요, 유) 앞에서 ㄴㄴ 소리가 덧나는 경우. (예: 나무+잎 -> 나뭇잎 [나무닙 -> 나문닙])
- 예문:
  - 냇가 (내 + 가) -> [내까 / 낻까]
  - 잇몸 (이 + 몸) -> [인몸]
  - 나뭇잎 (나무 + 잎) -> [나문닙]
  - 촛불 (초 + 불) -> [초뿔 / 촏뿔]

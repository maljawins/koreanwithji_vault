- 정의: 예사소리(ㄱ, ㄷ, ㅂ, ㅈ)가 목청소리 'ㅎ'을 만나면 두 소리가 합쳐져서 거센소리(ㅋ, ㅌ, ㅍ, ㅊ)로 축약되어 발음되는 현상입니다.
- 핵심 형태/규칙:
  - **결합 규칙**:
    - **ㄱ** + **ㅎ** (또는 **ㅎ** + **ㄱ**) -> **[ㅋ]** (예: 놓고 -> [노코], 박하 -> [바카])
    - **ㄷ** + **ㅎ** (또는 **ㅎ** + **ㄷ**) -> **[ㅌ]** (예: 좋다 -> [조타], 맏형 -> [마텽])
    - **ㅂ** + **ㅎ** (또는 **ㅎ** + **ㅂ**) -> **[ㅍ]** (예: 입학 -> [이팍])
    - **ㅈ** + **ㅎ** (또는 **ㅎ** + **ㅈ**) -> **[ㅊ]** (예: 낳지 -> [나치], 젖혀 -> [저쳐])
  - 'ㅅ'은 거센소리 파트너가 존재하지 않으므로 이 격음화 축약 규칙에서 제외됩니다.
- 예문:
  - 놓고 -> [노코]
  - 좋다 -> [조타]
  - 입학 -> [이팍]
  - 맏형 -> [마텽]
  - 젖혀 -> [저쳐]

# concept_korean-time

- 정의: 한국어에서 시간(시, 분, 초)을 읽을 때 사용하는 두 숫자 체계(Native vs Sino)의 하이브리드 조합 규칙.
- 핵심 형태/규칙:
  - **시 (時 / Hour)**: 시를 나타낼 때는 **Native Korean(순우리말 수)**을 사용합니다.
    - 이때 1, 2, 3, 4, 11, 12는 단위 수식형(한, 두, 세, 네, 열한, 열두)으로 변형해 사용합니다.
    - 예: 한 시, 두 시, 세 시, 네 시, 다섯 시... 열한 시, 열두 시.
  - **분 (分 / Minute) & 초 (秒 / Second)**: 분과 초를 나타낼 때는 **Sino-Korean(한자어 수)**을 사용합니다.
    - 예: 삼십 분, 오십 초
    - 11시 58분 38초 ➡️ 열한 시 오십팔 분 삼십팔 초
  - **24시간 체계 (Military / 24-Hour Clock)**: 12시를 넘어 13시부터 표기할 때는 고유어 대신 **Sino-Korean**을 사용하는 것이 자연스럽습니다.
    - 예: 13시 ➡️ 십삼 시 (열세 시 X), 14시 ➡️ 십사 시.
  - **기억 장치 (Mnemonic)**: 시(hour)는 서수적 성격("첫 번째 시간", "두 번째 시간")이 있어 순서 세기용인 고유어 수를 쓰고, 분/초는 단순 계량/수치용이어서 한자어 수를 쓴다고 이해할 수 있습니다.
